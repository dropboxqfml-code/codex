Keithley 6517A · NI GPIB-USB 시험용 프로그램 v0.7.0

1. GitHub Release의 6517A-USB-GPIB-Trial-0.7.0-Windows-x64.zip을 새 쓰기 가능한 폴더에 모두 풉니다. runtime/app/tools 폴더를 함께 둡니다. Python·uv는 따로 설치하지 않습니다.
2. Verify-Bundle.cmd -> Test-Simulation.cmd -> Start-GUI.cmd를 실행합니다. 두 검사 창은 중간 단계와 최종 PASS/FAIL을 표시합니다. Simulation은 전압 단계·판독·요약·OFF와 결과 폴더도 표시합니다.
3. 메인 화면 상단의 1 설정 -> 2 연결 -> 3 ARM -> 4 START 순서로 진행합니다. 기본 화면은 장비·주소·시험값·준비 상태·판독·그래프에 집중합니다. 상세 옵션은 '고급', 통신 시험·기록은 '진단·상세 기록' 탭에 있습니다.
4. GUI는 SIMULATION·0 V로 시작합니다. 실장비 준비는 '진단·상세 기록'에서 'NI 실장비 연결 시험 시작'을 선택합니다. NI MAX와 같은 주소를 사용하고 test panel은 닫습니다. 호환되는 기존 NI-488.2·NI-VISA 64-bit 설치를 사용합니다.
5. '1. 시험 설정'에서 전압·시간·trip을 입력합니다. 1 GΩ 저항은 사용자 관리 저전압 방식에서 '1 GΩ·1 V 시험값'을 사용할 수 있습니다. 사용자 연결 관리 확인, 잔류 전압 확인, resistive-limit ON/OFF 정책은 직접 선택합니다.
6. '측정 설정 적용'은 필수값을 검사합니다. 누락 항목을 누르면 해당 입력란으로 이동합니다. '초안 적용'은 미완료 입력을 보존하며 측정 준비 완료를 뜻하지 않습니다.
7. '2. 연결' -> '3. ARM' -> '4. START'를 누릅니다. 준비 상태에 ARM이 비활성인 이유와 다음 작업을 표시합니다. START는 ARM 완료 후 활성화됩니다. 설정 적용·연결·ARM만으로 출력 ON하지 않습니다.
8. 연결 후 미완료 항목이 있으면 출력 OFF 상태에서 '연결 종료 후 설정 수정'을 누릅니다. 연결을 종료하고 설정 창을 엽니다. 수정 후 다시 연결 -> ARM -> START로 진행합니다.
9. 결과는 run 폴더에 readings.csv, analysis.txt, summary.csv, raw_io.jsonl, run_status.json 등으로 저장됩니다. analysis.txt는 탭으로 구분한 Time (s), Resistance (Ohm), Voltage (V), Current (A) 네 열입니다. 첫 행에만 물리량·단위를 쓰고 이후에는 숫자만 기록합니다. 요약 제외 구간을 포함한 모든 판독과 STOP 전 취득값이 저장되며, 누락값은 nan입니다.
10. 이전 CSV를 변환하려면 Run-CLI.cmd export-analysis "결과폴더\readings.csv"를 실행합니다. 같은 폴더에 analysis.txt를 만들며 기존 파일은 덮어쓰지 않습니다. 전압 열은 source 설정 readback이며 독립 측정한 시료 단자 전압이 아닙니다. 품질 플래그는 readings.csv에서 확인합니다.

STOP으로 중지할 수 있습니다. 출력 OFF와 방전 완료는 별개이며 잔류 전압은 UNVERIFIED입니다.

사용자 관리 방식은 source 100 V 범위에서 절대 10 V 이하입니다. 기존 검증 fixture 방식은 정격·승인 기록과 현재 연결의 OFF 상태 lid 0 -> 1 확인을 유지합니다. 두 방식 모두 실제 장비 interlock 조회 0/실패·상태 오류에는 출력 ON을 차단합니다.
1 GΩ의 1 V -> 1 nA는 명목 계산값입니다. Software trip은 장비의 programmable compliance나 하드웨어 emergency stop이 아닙니다.
NI-VISA를 생략하는 @py 선택 확장은 Enable-NI-Only.cmd로 설치하며 NI-488.2 driver는 계속 필요합니다.
