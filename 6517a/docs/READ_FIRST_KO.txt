Keithley 6517A · NI GPIB-USB 기본 기능 통합 시험판 v0.9.0

v0.9.0은 기본 기능 통합 시험판이며, v1.0.0 정식 배포 전 사용자 시험을 위한 버전입니다.

1. GitHub Release의 6517A-USB-GPIB-Trial-0.9.0-Windows-x64.zip을 새 쓰기 가능한 폴더에 모두 풉니다. runtime/app/tools 폴더를 함께 둡니다. Python·uv는 따로 설치하지 않습니다.
2. Start-GUI.cmd 하나만 실행합니다. 시작 창이 Bundle 파일 검사 -> Simulation 동작 검사 -> GUI를 자동으로 진행합니다. 두 검사를 통과하면 메인 화면이 열립니다. 실패하면 해당 단계·기록을 확인하고 재시도합니다. 개별 CMD는 추가 점검용입니다.
3. 메인 화면 상단의 1 설정 -> 2 연결 -> 3 ARM -> 4 START 순서로 진행합니다. 기본 그래프는 R(t)이며 R(t) -> I(t) -> I-V -> R-V 순서입니다. 기본 화면은 장비·주소·시험값·준비 상태·판독·그래프에 집중합니다. 상세 옵션은 '고급', 통신 시험·기록은 '진단·상세 기록' 탭에 있습니다.
4. GUI는 '시뮬레이션 (가상 시험)'·0 V로 시작합니다. 이 모드는 6517A 없이 측정·그래프·저장을 시험합니다. 장비 사용은 'VISA · USB–GPIB'를 선택합니다. 자동 시작 검사도 장비에 연결하지 않으며 가상 결과는 diagnostics/startup-simulation에 저장합니다. NI MAX와 같은 주소를 사용하고 test panel은 닫습니다. 호환되는 기존 NI-488.2·NI-VISA 64-bit 설치를 사용합니다.
5. '1. 시험 설정'에서 전압·시간·trip을 입력합니다. 1 GΩ 저항은 사용자 관리 저전압 방식에서 '1 GΩ·1 V 시험값'을 사용할 수 있습니다. 사용자 연결 관리 확인, 잔류 전압 확인, resistive-limit ON/OFF 정책은 직접 선택합니다.
   시료 ID 아래의 길이 L·폭 W·두께 D는 mm 단위입니다. 전류 방향 L/W/D를 선택하면 ρ=R×단면적/전류경로길이로 비저항(Ω·m)을 계산합니다. D 방향이면 단면적=L×W, 경로길이=D입니다. 직육면체의 전체 단면에 전극이 접촉하는 모델이며 실제 전극 면적이 다르면 유효 면적이 필요합니다. 일부 치수나 방향이 미지정이어도 저항 측정은 가능하고 비저항은 비워 둡니다.
6. '측정 설정 적용'은 필수값을 검사합니다. 누락 항목을 누르면 해당 입력란으로 이동합니다. '초안 적용'은 미완료 입력을 보존하며 측정 준비 완료를 뜻하지 않습니다.
7. '2. 연결' -> '3. ARM' -> '4. START'를 누릅니다. 준비 상태에 ARM이 비활성인 이유와 다음 작업을 표시합니다. START는 ARM 완료 후 활성화됩니다. 설정 적용·연결·ARM만으로 출력 ON하지 않습니다.
8. 연결 후 미완료 항목이 있으면 출력 OFF 상태에서 '연결 종료 후 설정 수정'을 누릅니다. 연결을 종료하고 설정 창을 엽니다. 수정 후 다시 연결 -> ARM -> START로 진행합니다.
9. 결과는 run 폴더에 readings.csv, analysis.txt, summary.csv, raw_io.jsonl, run_status.json 등으로 저장됩니다. analysis.txt는 비저항 계산 조건이 없으면 Time (s), Resistance (Ohm), Voltage (V), Current (A) 네 열입니다. L/W/D와 전류 방향이 모두 있거나 기존 면적·경로 길이가 완성되면 Time (s), Resistance (Ohm), Resistivity (Ohm m), Voltage (V), Current (A) 다섯 열입니다. 열은 탭으로 구분합니다. 시료 ID만 있거나 치수가 일부만 있거나 방향 미지정이면 네 열입니다. 첫 행에만 물리량·단위를 쓰고 이후에는 숫자만 기록합니다. 요약 제외 구간을 포함한 모든 판독과 STOP 전 취득값이 저장되며, 누락값은 nan입니다.
   치수·전류 방향과 환산한 면적·경로 길이는 config.json/metadata.json에, 비저항은 readings.csv의 resistivity_ohm_m 열에 저장합니다. 열 수·헤더는 실행 시작에 고정하며, 완성된 기하조건에서 0 V 등으로 비저항 계산값이 없어도 다섯 열을 유지하고 비저항을 nan으로 기록합니다.
10. 이전 CSV를 변환하려면 Run-CLI.cmd export-analysis "결과폴더\readings.csv"를 실행합니다. 같은 폴더에 analysis.txt를 만들며 기존 파일은 덮어쓰지 않습니다. 전압 열은 source 설정 readback이며 독립 측정한 시료 단자 전압이 아닙니다. 품질 플래그는 readings.csv에서 확인합니다.


11. '저장 결과 분석'에서 이전 readings.csv를 엽니다. 장비 연결 없이 그래프를 다시 보고 시작·끝 시간(s)으로 구간을 선택해 전류·저항·비저항의 평균·표본 표준편차·유효 개수를 확인합니다. 비저항은 저장된 Ω·m 값만 사용하며 없으면 새로 계산하지 않습니다. v0.8.2 결과의 저장된 비저항도 분석할 수 있습니다. 선택 구간을 원본 실행에 맞는 네 열 또는 다섯 열 TXT로 따로 저장할 수 있으며 기존 파일을 덮어쓰지 않습니다.
12. 정상 완료, 사용자 STOP, 장비/통신 오류를 구분합니다. STOP 뒤 OFF·저장이 확인되면 stopped로 기록하고 저장된 판독 수와 결과 폴더를 표시합니다. 시험의 요약 구간 전에 멈춘 자료도 저장 결과 분석에서 직접 선택해 볼 수 있습니다.
13. 저장 결과 분석의 '비교 추가'로 최대 64개 readings.csv를 열어 I(t)·R(t)·ρ(t)를 겹쳐 봅니다. 각 실행의 측정 시작 후 경과 시간을 공통 축으로 사용하며 보간·시간 이동은 하지 않습니다. '통계·TXT 파일'에서 활성 파일을 선택해 해당 파일의 통계·선택 TXT를 확인합니다.
14. '분석 설정 저장'으로 JSON에 적용한 구간·비교 목록·순서·활성 파일·그래프 탭을 보관하고 '분석 설정 열기'로 다시 엽니다. 구간 편집 후에는 '구간 적용'을 누릅니다. 원본 데이터도 함께 보관합니다. 누락·변경된 원본은 오류로 안내하고 현재 분석은 유지합니다. 변경 자료는 다시 선택해 새 분석 설정으로 저장합니다. 측정 설정·장비 연결은 바꾸지 않습니다.
15. 측정 화면의 예상 남은 시간은 dwell·전압 단계·반복 횟수 기준입니다. 향후 통신·판독 지연과 종료 처리 시간은 포함하지 않습니다. 0초 표시가 출력 OFF나 저장 완료를 뜻하지 않습니다.
16. 진단·상세 기록의 '진단 ZIP 저장'으로 최근 측정·연결 진단·시작 검사 요약과 화면 로그를 로컬 ZIP에 묶습니다. 측정·준비 작업 중과 ARMED 상태에서는 사용할 수 없습니다. 원본·기존 ZIP을 덮어쓰거나 자동 업로드하지 않습니다. 포함·누락 파일은 manifest.json에서 확인하며 시료 정보·장비 일련번호·경로·통신 원문이 포함될 수 있습니다.

STOP으로 중지할 수 있습니다. 출력 OFF와 방전 완료는 별개이며 잔류 전압은 UNVERIFIED입니다.

사용자 관리 방식은 source 100 V 범위에서 절대 10 V 이하입니다. 기존 검증 fixture 방식은 정격·승인 기록과 현재 연결의 OFF 상태 lid 0 -> 1 확인을 유지합니다. 두 방식 모두 실제 장비 interlock 조회 0/실패·상태 오류에는 출력 ON을 차단합니다.
1 GΩ의 1 V -> 1 nA는 명목 계산값입니다. Software trip은 장비의 programmable compliance나 하드웨어 emergency stop이 아닙니다.
NI-VISA를 생략하는 @py 선택 확장은 Enable-NI-Only.cmd로 설치하며 NI-488.2 driver는 계속 필요합니다.
