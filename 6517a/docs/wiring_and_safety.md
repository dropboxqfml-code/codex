# 결선과 안전 정책

이 문서는 실장비 사용 승인서가 아닙니다. 첨부된 6517A 원문에서 아래 결선·장비 동작을 대조했습니다. 소프트웨어의 실행 승인은 물리적 안전 검증을 대신하지 않으며, 자격 있는 담당자가 실제 장비·fixture·규정에 맞춰 검증해야 합니다.

## 승인 가능한 1차 결선 범위

저측 전류 측정 FVMI만 대상으로 합니다.

```text
6517A V-Source HI → DUT → INPUT triax 중심 HI
                            → ammeter → meter LO → V-Source LO
```

승인된 결선에서 meter LO와 source LO의 연결은 METER CONNECT로 설정합니다(3-108). floating/high-side 결선은 지원하지 않습니다. DUT를 triax 중심과 inner shield 사이에 단순 연결한 뒤 V-source를 병렬로 추가하는 결선을 안내하지 않습니다. INPUT을 1000 V 전압계로 사용하지 마세요.

전류/저항 모드에서 triax inner shield는 input LO입니다. 전압 모드의 driven GUARD와 혼동하지 않습니다. outer shield/chassis·보호접지·signal LO는 역할이 다릅니다. 선 색상만으로 구분하지 말고 장비 및 케이블 원문 자료로 확인하세요. `GUARD ON`을 공통 필수 명령으로 보내지 않습니다.

Guard electrode는 전극 설계를 통해 표면·fixture 누설 경로를 분리하는 장치입니다. triax 케이블만으로 표면 누설이 사라지지 않습니다. guarded fixture가 없으면 결과를 ‘해당 전극/결선에서의 겉보기 저항’으로 해석하세요.

## 실험 기록

실제 실험 계획에는 다음 항목을 빠짐없이 기록합니다. 프로그램이 요구하는 주요 승인 필드 외의 상세 기록은 `note` 및 별도 승인 문서에 보존하세요.

- 시료 ID, 재료, 두께(m), 유효 전극 면적(m²), 전극 재료·형성법·구조.
- 예상 저항/전류, 허용 전압·전계·전력, 예상 capacitance, 이전 poling/전압/온도 이력.
- 케이블·커넥터·fixture의 실제 전압 정격, 절연 상태, 실제 triax 핀 역할과 결선.
- V-source HI와 ammeter INPUT HI 사이의 DUT 직렬 연결, 의도치 않은 source/input 단락 부재.
- 금속 보호 enclosure 접지·접근 차단·lid interlock, 시료 파괴/단락/충전 전류 보호.
- 독립적인 차단 수단, 외부 방전 경로, 잔류 전압 확인 절차 및 담당자.
- 교정 이력, 실제 장비 전원 투입 시각, 최소 1시간 warm-up 충족 여부. 앱 연결 시간은 warm-up이 아닙니다.
- 빛·온도·습도·진동·케이블 고정·건조·오염 조건.

소프트웨어 전압 상한의 초기값 10 V는 개발 제한일 뿐 안전 전압의 보증이 아닙니다. 상한은 `min(1000 V, software, sample, fixture, cable)`입니다. 미확정 정격으로 실장비 출력을 승인하지 않습니다. 정격이 확인되지 않은 커넥터·케이블이 1000 V를 견딘다고 가정하지 않습니다.

## 보호와 중지의 구분

`current_trip_A`는 측정값에 기반한 **software current trip**입니다. 임의 nA/µA 값을 장비의 programmable compliance로 설정하는 기능이 아닙니다. 6517A source 자체 current limit와 외부 하드웨어 보호는 별개입니다. native resistance에서 역산한 전류만으로 보호가 보장되지 않으므로 실장비 native 모드도 차단됩니다.

인터록 query=1은 케이블 미연결에서도 나타날 수 있다는 원문 3-137에 명시되어 있습니다. 설치 확인과 OUTPUT OFF 상태에서 lid-open=0 / lid-closed=1 전이를 확인해야 하며, query=1만으로 승인하지 않습니다. 연결·fixture 변경 시 commissioning을 다시 해야 합니다. 재폐쇄·재연결 후 출력 자동 복귀는 없습니다.

전류 trip·source limit·overload·인터록 이상·통신/저장 오류 시 더 높은 전압을 보내지 않고 중지합니다. 취소·abort·로그 단계가 실패해도 OFF 시도는 별도로 수행합니다. OFF 확인 실패는 `HV_STATE_UNKNOWN`이며 정상 완료로 표시하지 않습니다. 통신 단절 시 장비가 기존 출력을 유지할 수 있습니다. PC 종료·USB 분리·device clear·finally/atexit로 차단이 보장되지 않습니다.

## 출력 OFF와 잔류 전하

OFF는 출력 relay 상태입니다. 설정 전압 0 V 조회, 경과 시간, 낮은 전류, source OFF 후 열린 회로의 0 A는 DUT 방전의 증거가 아닙니다. 독립 외부 전압 모니터가 제공되지 않았으므로 `residual_voltage_state=UNVERIFIED`를 유지합니다. 유전흡수에 의한 전압 회복도 고려해야 합니다. 프로그램은 ‘접촉 가능’ 또는 ‘방전 완료’를 판정하지 않습니다.

결선 변경은 전원 차단·출력 OFF 및 실제 방전 확인 후 수행하세요. 외부 방전 relay/저항은 제공되지 않았으며 제어하지 않습니다. `CHARGE:ADISCHARGE`를 DUT 안전 방전 명령으로 사용하지 않습니다. 낮은 방전저항을 측정 중 병렬 유지하면 고저항 측정이 손상될 수 있습니다.

## 원문 확인과 남은 불일치

쪽 번호는 PDF 뷰어가 아닌 인쇄 쪽입니다. V-source 범위·분해능(2-46/2-49), 저측 FVMI(Fig. 2-9, 2-11 및 Fig. 2-31, 2-34), input/guard 역할(2-9~2-13), interlock(3-137), standby relay와 유전흡수(2-50)를 첨부 원문에서 확인했습니다. Resistive limit 값은 실제 원문에서도 2-49의 20 MΩ와 3-108의 1 MΩ가 상충합니다. 2-49의 100 V 범위 10 mA/1000 V 범위 1 mA 설명과 3-108의 제한 상태 설명도 구분해야 합니다. 어느 값도 보정 상수나 안전 보증치로 하드코딩하지 않습니다.

현재 연결의 출력 OFF 상태에서 open=0 → closed=1을 관찰한 기록과 fixture ID·승인자가 실행 승인에 연결됩니다. JSON의 과거 체크값만으로 현재 연결을 승인하지 않으며, 재연결·fixture 변경·fault에는 새 확인이 필요합니다. 이 관찰은 실제 인터록 접점의 정격이나 물리적 차단 성능을 인증하지 않습니다.

현재 연결에서 0 → 1 전이를 관찰해도 **이후 케이블이 계속 연결돼 있다는 증명은 아닙니다**. 3-137에 따라 케이블을 나중에 분리해도 `SYST:INT?`가 1을 반환할 수 있어 소프트웨어가 모든 분리 사건을 검출할 수 없습니다. 승인된 fixture의 케이블 고정·접근 관리와 독립적인 하드웨어 보호가 필요하며, 현재 연결 관찰을 하드웨어 인증이나 연속 감시 보증으로 해석하지 않습니다.
