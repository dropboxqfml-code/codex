# 계층과 상태 분리

WPF View는 ViewModel의 표시 속성과 명령에 바인딩합니다. ViewModel은 배터리 조회·설정 저장·진단 서비스를 사용하고, 하드웨어 제어는 `IChargeLimitController`로 분리합니다. View가 펌웨어를 직접 조작하는 경로는 두지 않습니다.

## 서로 다른 세 가지 상태

| 상태 | 출처 | 해석 |
| --- | --- | --- |
| 사용자 희망 모드 | 로컬 설정 파일과 화면 선택 | 사용자가 원하는 80%/100% 선택 |
| 실제 하드웨어 모드 | 검증된 제어 어댑터의 실제 장치 조회 | 현재 어댑터에서는 미지원/알 수 없음 |
| 배터리 잔량·충전 상태 | Windows 배터리 조회 API | 현재 잔량과 전원 상태 |

저장된 선택값이나 Mock 상태로 실제 하드웨어 모드를 대체하지 않습니다. 잔량 80% 또는 충전 중 아님 상태도 충전 제한이 적용되었다는 근거가 아닙니다.

## 어댑터

- `UnsupportedChargeLimitController`: 기본 실제 사용 경로입니다. 실제 제어를 지원하지 않으며 모든 모드 쓰기를 명시적으로 거부합니다.
- `MockChargeLimitController`: 개발용 메모리 시뮬레이션입니다. 장치·레지스트리·서비스·드라이버를 변경하지 않습니다. 화면에 시뮬레이션임을 표시합니다.

## 배터리와 설정

`GetSystemPowerStatus`는 상태 조회에만 사용합니다. Windows가 보고한 유효한 0%를 보존하고, 조회 실패나 값 없음은 알 수 없음으로 구분합니다. 주기적 조회는 앱 종료 시 정리합니다.

일반 사용자 설정은 `%LOCALAPPDATA%\ATIVBatteryGuard\settings.json`에 저장합니다. 설정은 스키마와 값 검증을 거치고, 임시 파일과 원자적 교체로 저장합니다. 손상된 설정을 읽더라도 실제 하드웨어 지원 상태를 승격하지 않습니다.

## 진단

기본 진단은 필요한 모델·BIOS·OS 정보만 읽습니다. 삼성 인터페이스 조사에는 `ROOT\WMI`의 정확한 클래스 이름 `WmiAcpiVersion`, `WmiAcpiMethod`, `DataBuffer`를 사용합니다. 클래스의 속성·메서드·입출력 파라미터 **정의**만 확인하며, 인스턴스 값 조회나 메서드 실행을 하지 않습니다.

메타데이터가 없거나 조회가 거부되거나 오류가 나면 그 상태를 기록합니다. 클래스 존재 또는 메서드 이름은 해당 노트북의 충전 제한 지원·명령 의미·안전성의 증거가 아닙니다.

삼성 파일 분석 자료 기능이 제공되는 경우 사용자의 명시적 실행과 확인 뒤 제한된 로컬 파일만 데이터로 복사합니다. DLL 로드·실행·자동 업로드와 분리하며, 자체 앱 배포물에는 OEM 파일을 포함하지 않습니다.

## 장래의 부팅 복원

현재 앱은 서비스·자동 실행·작업 스케줄러를 등록하지 않습니다. 사용자 희망 설정을 기억하는 것은 펌웨어 상태를 재부팅 뒤 복원하는 것과 다릅니다.

장래에 모델·BIOS별로 검증된 제어 경로와 별도 명시적 승인이 확보된 경우에만 Windows Service를 설계할 수 있습니다. 서비스는 권한으로 보호한 `%ProgramData%` 설정, 접근을 제한한 로컬 IPC, 엄격한 요청 검증, 장치 상태 read-back을 사용해야 합니다. 실행 시 저장값을 먼저 적용하지 않고 실제 상태와 지원 범위를 확인해야 합니다. 이 문서의 설계 설명은 해당 기능의 구현·설치·실행 승인이 아닙니다.
