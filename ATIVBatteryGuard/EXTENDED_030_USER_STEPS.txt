ATIV Battery Guard 0.3.0-rc.2 — 추가 자동 검사 v2

이 ZIP에는 기존 RC2 프로그램과 별도의 추가 검사 도구가 들어 있습니다.
기존 프로그램/v1 검사 폴더와 합치지 말고 쓰기 가능한 새 로컬 폴더에 전부 풉니다.
바탕화면에 새 폴더를 만들어 풀어도 됩니다. 바탕화면 자체를 실패 원인으로 단정하지 않습니다.
Windows 10 x64 / .NET Framework 4.8이 필요하며 개발 SDK·관리자 실행은 필요 없습니다.
기존 RC2 프로그램과 개인 기록은 바꾸지 않습니다.

실행 순서
1. 먼저 '빠른추가검사.cmd'를 더블클릭합니다.
   이번에는 시작 문제 수정 확인을 위해 빠른 검사부터 확인합니다.
   자동으로 두 개의 검증 창을 열고 한글 문자열 저장·다시 열기,
   실제 메모 저장 확인 대화상자의 취소·저장·저장 없이 진행,
   A/B 초안 유지, 같은 기록의 두 창 저장 충돌과 초안 묶음 백업,
   파일 잠금으로 인한 저장 실패·재시도, A/B 열기·저장·닫기 30회를 확인합니다.
   검증 창은 자동으로 움직일 수 있으니 완료될 때까지 직접 편집하지 않습니다.

2. 빠른 검사가 통과하면 '20분반복검사.cmd'를 실행합니다.
   같은 기본 검사 뒤 A/B 열기·저장·닫기를 20분 동안 반복합니다.
   메모리·핸들 수와 Dispatcher 응답 시간을 주기적으로 기록합니다.
   절전·최대 절전·잠금·원격 세션 종료 없이 실행하는 것이 좋습니다.
   30초가 넘는 반복 공백은 절전/정지 여부를 구분하지 않고 미통과로 기록합니다.
   시작과 끝의 메모리 차이만으로 누수 여부를 확정하지 않습니다.

3. 이 폴더의 extended-results에 있는 새 startup-*.json과 extended-*.json을 전달합니다.
   시작 실패 시 startup JSON만 생성될 수 있습니다. 실패 단계와 고정 오류 코드가 들어 있습니다.
   이번에는 빠른 검사 결과만 먼저 전달해도 됩니다. 시작이 안 되면 20분 검사를 반복하지 않습니다.
   빠른/20분 검사를 모두 했다면 각각의 결과를 전달합니다.
   결과를 자동 전송하지 않습니다. 개발 도구 설치나 PowerShell 정책 변경은 없습니다.

중단할 때
검증 창의 X 또는 콘솔 Ctrl+C를 누르면 다음 처리 지점에서 중단하고 미통과로 기록합니다.
기존에 사용하던 별도 프로그램 창을 닫거나 충전 제어 중인 helper를 종료하지 않습니다.
검사 도구가 응답하지 않으면 보고서의 Outcome이 running-not-passed인 중간 기록은 통과가 아닙니다.
강제 종료·전원 중단·결과 저장 실패에서는 완료 결과가 없을 수 있습니다.
결과 JSON에는 개인 경로/메모/장치 식별값을 넣지 않습니다.
시작 진단에도 예외 메시지·스택·전체 경로·입력 인수를 저장하지 않고 단계/오류 분류/HResult만 기록합니다.
startup-completed-see-validation-report는 시작 완료이며 본 검사 통과를 의미하지 않습니다.
폴더에 쓸 수 없거나 .NET이 Main 진입 전 실패하면 JSON이 없을 수 있습니다. 이때 화면 오류 코드를 전달합니다.

자동화 범위와 남은 한 가지 입력 확인
- 실제 RC2의 WPF 화면·버튼에 연결된 명령·메모 바인딩과 실제 저장 확인 대화상자를 검사합니다.
- 두 창은 같은 검사 프로세스에서 열립니다. 서로 다른 프로세스 경쟁까지 완료했다고 표시하지 않습니다.
- TXT/묶음 선택은 합성 예제로 대체하므로 실제 파일 선택 대화상자는 이번에 자동화하지 않습니다.
- 한글 문자열을 WPF에 넣어 저장하는 것과 실제 한글 입력기의 조합 중 처리는 다릅니다.
  실제 입력기로 마지막 글자에 조합 표시가 있을 때 메모 저장을 누르고 다시 열어 확인하는 항목은 남습니다.
  붙여넣기로만 대체하지 않습니다. 이 항목을 자동 검사 통과로 기록하지 않습니다.
- 마우스 좌표·키보드 입력을 다른 프로그램에 전송하지 않습니다. 물리적 클릭 적중 검사는 기존 결과를 인계합니다.

검사는 새 임시 폴더의 합성 배터리/예제만 사용하며 실제 배터리/OEM 조회·충전 쓰기·helper 실행이 없습니다.
검사 전후 프로그램 6파일의 버전/해시를 확인합니다. 해시는 게시자 인증 수단이 아닙니다.
이 도구는 미서명 개발 검증 도구입니다. Defender·서명·최종 출시는 자동 완료로 기록하지 않습니다.
클라우드에서는 컴파일/회귀 검사를 했지만 이 새 도구의 실제 Windows 실행은 아직 확인하지 않았습니다.
