# RC3 한글 조합 중 닫기 취소 결과

2026-11-26 한국 시간. 사용자 Windows 10 / 940X3G에서 받은 startup-d806… 및 ime-close-659… JSON은 시작/본 검사 모두 종료 0이며 닫기 전용 검사가 통과했습니다. [원본과 평가](reports/field-ime-close-rc3/assessment.json)를 보존합니다. 두 보고서의 모드·포함 시각과 RC3 소스 지문이 일치합니다. 실행 시각은 14:16:37~14:18:15입니다.

| 시점 | 관찰 |
| --- | --- |
| 제품 닫기 요청 직전 | 화면은 예상 문구와 일치하지만 VM은 아직 불일치. 조합 중이며 수정된 초안과 창이 존재 |
| 제품 확인 가드 진입 전 | 화면과 VM이 모두 예상 문구와 일치. 기존 저장값도 기준값과 일치 |
| 확인창 취소 후 | 창·수정 초안·화면/VM 문구·기존 저장값 모두 유지. 조합 종료 |

실제 한국어 IME 조합 시작 8회/갱신 17회, 닫기 요청 시 조합 중 상태, 사용자 직접 입력 확인이 기록됐습니다. 인위 문자열 주입은 없습니다. 실제 닫기 메시지 관찰·가드 차단·확인창 취소 1회, 실행 전후 파일 확인과 정리도 통과했습니다. 입력이 화면에서 VM으로 늦게 전달되는 상태와 RC3의 닫기 전 반영을 이번 실행에서 확인했습니다. 과거 v3 실패의 모든 원인을 이 결과만으로 소급 확정하지 않습니다.

이 모드는 저장 기준값을 미리 준비하므로 새 저장/재열기 시험은 실행하지 않았습니다. 이전 저장 통과 근거를 인계합니다. 배터리/OEM 조회·하드웨어 쓰기·Defender·서명 검사는 실행하지 않았고 최종 출시 승인은 false입니다. 같은 IME·빠른/20분·충전 시험을 반복 요청하지 않습니다.
