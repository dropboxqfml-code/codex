ATIV Battery Guard 0.3.0-rc.2 — 한글 입력 확인 (추가 도구 v3)

기존 RC2 프로그램과 개인 기록은 그대로 둡니다.
ZIP을 새 로컬 폴더에 모두 풀고 '한글입력확인.cmd'만 실행합니다.
이미 통과한 빠른추가검사.cmd / 20분반복검사.cmd는 반복할 필요가 없습니다.
Windows 10 x64 / .NET Framework 4.8 / 일반 권한으로 실행하며 개발 SDK는 필요 없습니다.

1. 화면 위 안내에 따라 기록 A 메모에 아래 문구를 직접 입력합니다.
   한글 입력 확인
   마지막 글자에 조합 표시가 남아 있을 때, 기록 메모의 '메모 저장'을 마우스로 클릭합니다.
   붙여넣기나 자동 입력은 사용하지 않습니다.
   도구가 실제 저장 내용과 기록을 다시 연 내용을 자동으로 비교합니다.

2. 안내가 두 번째 단계로 바뀌면 메모에서 Ctrl+A를 눌러 기존 글자를 선택한 뒤 아래 문구를 직접 입력합니다.
   종료 취소 확인
   마지막 글자 조합 중 창 오른쪽 위 X를 누릅니다.
   이때 나타나는 메모 저장 확인은 도구가 자동으로 '취소'합니다.
   도구는 마지막 글자와 초안이 남았는지, 기존 저장 메모를 덮어쓰지 않았는지 확인합니다.

3. 실제로 조합 표시가 있을 때 위 두 동작을 했다면 화면 위 확인 체크 항목을 직접 선택합니다.
   '결과 저장 후 종료'를 누릅니다. 체크 항목은 자동으로 선택되지 않습니다.
   시작/검사 실패나 문구 불일치가 있어도 결과 저장 후 종료할 수 있습니다.

결과 전달
이 폴더의 extended-results에서 이번 실행의 startup-*.json과 ime-*.json을 전달합니다.
보고서에는 입력 문구 자체, 키 입력 내용, 전체 경로, 계정·장치 식별값을 넣지 않습니다.
입력기 이벤트 횟수와 한국어 IME 켜짐 관찰, 저장/초안 일치 여부와 직접 확인 여부만 기록합니다.

결과 해석
- user-assisted-ime-checks-passed-release-pending: 직접 입력/입력기 증거/저장·취소 확인 통과. 최종 출시는 별도입니다.
- roundtrip-passed-ime-evidence-incomplete: 저장·취소는 정상이지만 입력기 이벤트나 켜짐 상태 증거가 부족합니다.
  프로그램 결함으로 단정하거나 입력기 조합까지 통과했다고 표시하지 않습니다.
- user-confirmation-pending: 직접 조합 중 동작을 확인했다는 체크가 없습니다.
- not-completed / not-passed: 단계 미완료 또는 검사 오류입니다. 결과를 전달합니다.
- stopped-not-passed: Ctrl+C, 안내 단계 이외의 X, 또는 10분 대기로 중단됐습니다.

이 창은 임시 예제만 사용합니다. 기존 개인 기록이나 충전 설정을 바꾸지 않습니다.
원래 프로그램에 새 화면을 추가한 것이 아니라 검사 호스트의 위쪽에만 안내를 붙입니다.
일반 프로그램 시작/배터리·OEM 조회/충전 제어/helper 실행/보안 정책 변경/자동 전송은 없습니다.
서명 없는 개발 검사 도구입니다. 코드 서명이나 Defender 검사를 완료한 것으로 기록하지 않습니다.
이 새 한글 확인 모드는 클라우드에서 컴파일·판정 회귀를 검사했으며 실제 Windows 실행은 아직 미확인입니다.
