ATIV Battery Guard 0.3.0-rc.3 / 검사 도구 v4 — 닫기 취소만 확인

이번에는 닫기취소확인.cmd만 실행합니다.
기존 RC2/v3 폴더와 합치지 말고 새 로컬 폴더에 ZIP 전체를 풉니다.
이미 성공한 한글 저장·재열기, 빠른 검사, 20분 반복, 충전 시험은 반복하지 않습니다.
Windows 10 x64 / .NET Framework 4.8 / 일반 권한이며 SDK는 필요 없습니다.

1. 닫기취소확인.cmd를 실행합니다.
   임시 예제와 미리 준비한 저장 메모가 표시됩니다. 이 저장 메모는 비교 기준이며 새 저장 시험이 아닙니다.
2. 기록 A 메모에서 Ctrl+A로 기존 글자를 선택하고 아래 문구를 직접 입력합니다.
   종료 취소 확인
3. 마지막 글자까지 입력한 뒤 스페이스·엔터·방향키를 누르지 말고 바로 창 오른쪽 위 X를 누릅니다.
   입력기에 따라 마지막 글자의 밑줄/사각형 표시가 보일 수 있습니다.
   클릭하면서 표시가 사라지는 것은 정상입니다. 저장 확인창은 도구가 자동 취소합니다.
4. 글자가 유지되는지 확인하고 화면 위 '직접 입력하고 조합 표시가 있을 때 닫기를 눌렀습니다'를 선택합니다.
   결과 저장 후 종료를 누릅니다.

이 폴더의 extended-results에서 새 startup-*.json과 ime-close-*.json을 전달합니다.
보고서는 닫기 요청 전, 확인창 진입 전, 취소 후의 창/초안/화면·내부 문구 일치/기존 저장값 일치를
각각 불리언으로 기록합니다. 글자 원문·키 입력·개인 경로·장치 정보는 기록하지 않습니다.
새 오류 코드가 나오면 값의 종류까지 구분되므로 같은 파일로 무작정 반복할 필요는 없습니다.

user-assisted-ime-close-checks-passed-release-pending은 이번 닫기 확인만 통과한 것입니다.
SaveRoundtripPerformedInThisRun=false는 저장 시험을 반복하지 않았다는 뜻이며 저장 실패가 아닙니다.
입력기 이벤트가 부족하거나 직접 확인 항목을 선택하지 않으면 미확인 상태로 기록합니다.
X는 '닫기' 단계에서 시험에 사용하고, 그 외 단계의 중단은 Ctrl+C 또는 결과 저장 후 종료를 이용합니다.
10분 동안 완료하지 않으면 중단으로 기록합니다.

초안은 저장 확인 이전에 보관하지만 디스크 저장은 사용자가 저장을 선택할 때만 합니다.
수정 후보의 실제 Windows IME 실행은 아직 확인하지 않았습니다.
화면 디자인/충전 제어·파일 형식은 유지했고 실제 배터리/OEM 조회·하드웨어 쓰기·helper 실행은 없습니다.
미서명 개발 검사 도구이며 Defender/서명/최종 출시를 완료한 것으로 표시하지 않습니다.
