## 버전과 시각의 의미

화면 위에 배포 버전을 표시하고 Windows 파일 속성에도 `FileVersion 0.2.0.2`와 `ProductVersion 0.2.0-beta.2`를 넣었습니다. 새 제어 TXT에는 같은 배포 버전, GUI 요청 시작 시각과 결과 기록 시각을 UTC로 남깁니다.

**마지막 보호 조회 결과 수신**은 정상 수용한 결과를 앱이 받은 시각이며 현지 시각과 UTC 오프셋으로 표시합니다. 개별 펌웨어 읽기의 정확한 시각이나 계속 조회 중인 현재 설정을 뜻하지 않습니다. 새 요청·시뮬레이션 전환·절전 복귀·불명 결과에서는 화면 시각을 비웁니다. 상태 초기화와 겹친 늦은 결과는 과거 보고서로만 보관합니다.

시각은 요청마다 한 번 기록하고 저장·저장 재시도에서 새로 찍지 않습니다. 시각을 읽지 못하면 미관측으로 남기며 실제 장치 결과나 정리 상태를 바꾸지 않습니다. 시각과 버전은 조회·쓰기 권한을 부여하지 않고, 외부에서 바뀐 장치 상태나 실행 바이너리 출처를 인증하지 않습니다.

같은 요청은 성공적으로 한 번 저장한 뒤 중복 저장을 막습니다. 서로 다른 요청이 내부적으로 같은 결과 객체를 반환하더라도 각 요청의 시각과 보고서는 별도로 보관할 수 있도록 정리했습니다. 저장 실패는 저장만 다시 시도할 수 있고 장치 동작을 반복하지 않습니다.

## 오류 안내와 사용 순서

취소, 지원 범위 불일치, 사전 확인 실패, 응답 불일치, 다른 작업 진행, 시간 초과와 불명을 구분해 다음에 확인할 항목을 안내합니다. 실제 종료 미확인에서는 추가 동작 차단과 앱·helper 강제 종료·재실행 금지 안내가 항상 우선합니다. 이 안내는 상태 초기화·늦은 결과·시뮬레이션 변경 시도·창 닫기 시도에서도 유지됩니다.

새 ZIP 하나를 새 폴더에 모두 풀고 **ATIVBatteryGuard.exe를 일반 권한으로 실행**합니다. 실제 보호 상태가 필요할 때 **보호 상태 확인**을 누릅니다. 같은 계정의 관리자 확인 뒤 정상 조회됐을 때만 필요한 켜기·해제를 직접 선택합니다. **제어 결과 TXT 저장 → 결과 저장 폴더 열기**에서 새 보고서를 확인할 수 있습니다.

이번 사용 확인은 화면 순서, 버전, 시각과 접힌 기능의 접근성을 보면 됩니다. 기존 [80% 억제·해제 후 충전 재개](PROTECTION_CONTROL_FUNCTIONAL_RESULT_AND_GUI_PLAN.md)와 [첫 GUI 해제 결과](MANUAL_CONTROL_BETA_RESULT.md)는 계속 유효합니다. 같은 충전 시험이나 기존 자료 재제출은 필요하지 않습니다. 새 베타2 조합의 실제 Windows 화면·DPI·키보드 동작은 아직 실기 확인 전입니다.
