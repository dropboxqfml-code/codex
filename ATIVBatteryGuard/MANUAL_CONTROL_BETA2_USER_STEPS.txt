ATIV Battery Guard 0.2.0-beta.2 — 수동 보호 제어
2026-11-10 한국 시간

1. 이 ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행하세요.
   예전 ZIP과 파일을 합치지 마세요. 삼성 원본 DLL을 추가할 필요도 없습니다.
   관리자 helper는 앱의 버튼으로 시작하므로 직접 실행하지 않습니다.

2. 위에서부터 현재 배터리, 수동 보호 제어, Windows 배터리 상태 관찰을 사용합니다.
   장치 정보·진단·사용자 선택값·시뮬레이션·과거 기록 검토는 아래 영역을 펼치면 나옵니다.
   화면 위쪽의 배포 버전은 0.2.0-beta.2입니다.

3. 실제 보호 상태가 필요하면 '보호 상태 확인'을 누릅니다.
   버튼을 누를 때만 같은 계정의 관리자 확인을 받고 고정 조회를 수행합니다.
   모델·BIOS·WMI 조건과 조회 모드가 정상 확인된 뒤 켜기·해제를 사용할 수 있습니다.
   지원 범위는 기존 Windows 10 x64 / 940X3G·930X3G / P05ACJ입니다.
   '마지막 보호 조회 결과 수신'은 앱이 결과를 받은 시각입니다.
   개별 펌웨어 읽기의 정확한 시각이나 계속 조회 중인 현재 설정을 뜻하지 않습니다.
   새 요청·시뮬레이션 전환·절전 복귀 뒤에는 새 결과를 받기 전까지 미관측으로 표시합니다.

4. 필요할 때만 '80% 보호 켜기' 또는 '보호 해제 · 일반 충전'을 선택합니다.
   켜기는 전후 조회 포함 최대7회, 해제는 최대3회이며 설정은 각각 최대1회입니다.
   이미 목표 모드이면 쓰지 않고, 조회는 최대3회이며 설정하지 않습니다.
   자동 적용·재시도·반대 방향 원복·부팅 자동 적용은 없습니다.
   이미80%를 넘은 잔량을 즉시80%로 낮추는 기능은 아닙니다.

5. '제어 결과 TXT 저장 → 결과 저장 폴더 열기'로 결과를 보관합니다.
   요청 상세는 펼쳐서 볼 수 있습니다. TXT에는 배포 버전과 GUI 요청·결과 기록 시각이 추가됩니다.
   저장 시각을 새 조회 시각으로 바꾸지 않으며, 같은 결과의 중복 저장을 막습니다.
   저장 실패라면 장치 동작을 반복하지 말고 저장만 다시 시도하세요.
   저장 위치는 기존 %LOCALAPPDATA%\ATIVBatteryGuard이며 manual-control-*.txt로 저장됩니다.

실제 종료가 미확인·Pending이면 추가 제어를 하지 말고 안내에 따라 기다리세요.
앱·helper 강제 종료나 작업 기록 삭제로 차단을 우회하지 않습니다.
오류 안내와 결과 TXT만으로 확인할 수 있으며 계정·보안 설정을 바꾸지 마세요.

기존 노트북에서 확인한80% 억제와 해제 후 충전 재개 결과는 유효합니다.
이번 확인에는 화면 순서·버전·시각·접힌 기능의 접근성만 보면 되고 같은 충전 시험은 필요 없습니다.
기존 진단·TXT·삼성 DLL·EXE를 다시 제출할 필요는 없습니다.
새 결과의 검토가 필요할 때만 그때 만든 manual-control TXT를 전달하면 됩니다.

이 배포는 미서명 Windows x64/.NET Framework 4.8 개발 베타입니다.
삼성 원본 DLL·firmware·예전 단발 시험 EXE는 포함하지 않습니다.
외부 네트워크·자동 업로드·드라이버/서비스 설치·보안 정책 변경·BIOS flash는 없습니다.
