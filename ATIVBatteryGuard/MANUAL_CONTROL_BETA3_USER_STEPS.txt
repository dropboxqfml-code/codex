ATIV Battery Guard 0.2.0-beta.3 — 작은 창과 화면 안 배치
2026-11-10 한국 시간

새 ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행하세요.
이전 ZIP과 파일을 합치지 않고 삼성 원본 DLL을 추가할 필요도 없습니다.
관리자 helper는 앱의 제어 버튼으로만 실행합니다.

이번 변경

- 기본 창을750×565로 줄였습니다. 이전1120×850의 약2/3이며 글자 크기는 유지했습니다.
- 이전 최대화 기억값과 관계없이 작은 일반 창으로 시작합니다. 필요하면 직접 최대화할 수 있습니다.
- 마우스 포인터가 있는 모니터에서 시작하고, 작업 표시줄을 제외한 화면 안에 제목 표시줄과 창 버튼을 배치합니다.
- 화면 배율·모니터·작업 표시줄 영역 변경이나 최대화/최소화 뒤 복원에서도 창을 화면 안으로 보정합니다.
- 창은 자유롭게 이동·크기 조절할 수 있으며 내용은 기존 세로 스크롤과 접힌 영역으로 봅니다.
- 폴더 열기 성공·실패를 저장 안내 옆에도 표시하며, 이미 저장한 파일명과 결과는 유지합니다.
- UAC와 helper 확인 취소, 해당 진단의 실패를 구분해 안내합니다.

사용 순서

1. 위에서 현재 배터리, 수동 보호 제어, 배터리 관찰을 사용합니다.
   장치 정보·진단·로컬 설정·시뮬레이션·과거 기록은 아래에서 펼칩니다.
2. 실제 보호 상태가 필요하면 '보호 상태 확인'을 누르고 같은 계정의 관리자 확인에 응답합니다.
   정상 조회 뒤에만 필요한 '80% 보호 켜기' 또는 '보호 해제 · 일반 충전'을 직접 선택합니다.
3. 마지막 조회 결과 수신 시각은 앱이 결과를 받은 시각이며, 계속 조회 중인 현재값이나 정확한 펌웨어 읽기 시각은 아닙니다.
4. 필요한 결과는 '제어 결과 TXT 저장 → 결과 저장 폴더 열기'에서 확인합니다.
   같은 요청의 중복 저장을 막고, 저장 실패는 장치 동작을 반복하지 않고 저장만 다시 시도합니다.
   저장 폴더를 열지 못해도 이미 저장된 TXT를 삭제하거나 저장 실패로 바꾸지 않습니다.
   기존 위치는 %LOCALAPPDATA%\ATIVBatteryGuard이며 manual-control-*.txt로 저장합니다.

실제 종료 미확인·Pending이면 앱이나 helper를 강제로 종료하거나 다시 실행하지 마세요.
작업 기록 삭제·보안 설정 변경·반대 방향 쓰기로 차단을 우회하지 않습니다.
보호 조회3회·켜기7회·해제3회, 설정 최대1회의 기존 제한을 유지합니다.
자동 제어·재시도·부팅 자동 적용·임의 임계값 기능은 추가하지 않았습니다.

Windows10 '다시 시작' 뒤 충전 제한이 유지됐다는 사용자 확인을 개발 기록에 반영했습니다.
기존80% 충전 제한·해제 후 충전 재개와 글자 크기·접힌 기능이 정상이라는 결과도 유지합니다.
이번에는 창 크기와 제목 표시줄의 최소화·최대화·닫기 버튼이 보이는지만 확인하면 됩니다.
같은 충전 시험·기존 진단·TXT·삼성 DLL·EXE 재제출은 필요하지 않습니다.

이 배포는 미서명 Windows10 x64/.NET Framework 4.8 개발 베타입니다.
삼성 원본 DLL·firmware·예전 단발 시험 EXE·PDB는 포함하지 않습니다.
실행 중 외부 네트워크·자동 업로드·드라이버/서비스 설치·보안 정책 변경·BIOS flash는 없습니다.
