ATIV Battery Guard — 수동 충전 보호 제어 베타
2026-11-10 한국 시간

이제 일반 GUI의 버튼으로 보호 상태 확인·80% 보호 켜기·보호 해제를 실행합니다.
앱은 일반 권한으로 열고, 버튼을 누를 때 필요한 관리자 helper만 실행합니다.
대상은 기존 Windows 10 x64 / 940X3G/930X3G / P05ACJ profile입니다.
다른 모델·BIOS는 지원 확인 실패로 호출하지 않습니다.
이 새 GUI/helper 조합은 빌드·오프라인 검증한 개발 베타이며 실제 노트북 실행은 아직 미검증입니다.

1. 새 ZIP 하나를 새 로컬 폴더에 모두 풉니다.
   기존 관찰 ZIP·단발 시험 ZIP과 파일을 합치지 않습니다. 삼성 DLL을 넣을 필요도 없습니다.
   ATIVBatteryGuard.exe를 일반 권한으로 실행하세요.
   함께 들어 있는 ManualProtectionHelper.exe는 직접 실행하는 프로그램이 아닙니다.

2. 시뮬레이션이 꺼진 상태에서 '보호 상태 확인'을 누릅니다.
   관리자 확인 창과 helper의 동작 안내를 확인합니다. 이 동작은 고정 조회 최대3회이며 설정하지 않습니다.
   같은 Windows 계정의 관리자 확인만 사용합니다. 다른 계정 암호나 보안 우회가 필요하면 중단합니다.
   상태 조회가 정상 완료되고 모델·모드가 확인되면 켜기·해제 버튼을 사용할 수 있습니다.
   '마지막 모드/상한/하한 후보'는 이번 조회 기록이며 배터리 잔량이나 계속 조회 중인 현재값과 다릅니다.

3. '80% 보호 켜기' 또는 '보호 해제 · 일반 충전'을 누릅니다.
   해당 동작을 설명하는 관리자 helper 확인 창에서 영향을 읽고 동의할 때 진행합니다.
   보호 켜기는 새 사전모드0일 때만 설정1 최대1회, 전후 조회 포함 최대7회입니다.
   보호 해제는 새 사전모드1일 때만 설정0 최대1회, 전후 조회 포함 최대3회입니다.
   이미 요청한 모드이면 첫 조회 뒤 설정 없이 종료합니다.
   모드1만 읽은 경우 상·하한은 미조회로 표시하며 임계값을 임의로 보정하지 않습니다.
   진행 중에는 다른 제어 버튼을 반복해서 누르지 않습니다. 앱은 중복 실행을 막습니다.

4. 화면에서 '관련 정리: Complete'와 마지막 저장 모드 후보를 확인합니다.
   켜기 정상 전환은 모드1·상한80·하한75의 사후 후보 일치입니다.
   해제 정상 전환은 모드0의 사후 후보 일치이며 임계값을100으로 바꾸거나 이전값으로 복원하지 않습니다.
   이미80%보다 높게 충전돼 있다면 그 잔량은 그대로 남고 이후 추가 충전이 억제될 수 있습니다.
   정상 설정 뒤에도 실제 충전 표시와 잔량 경과는 Windows 배터리 항목에서 따로 관찰합니다.
   80% 유지·NotCharging 한 표시만으로 전기적 결과를 확정하지 않습니다.

5. '제어 결과 TXT 저장'을 누르면 이번 요청의 정제된 결과를 보관합니다.
   저장 버튼 바로 아래에서 저장 완료·새 파일명을 확인하고 '결과 저장 폴더 열기'를 누르세요.
   저장 위치는 기존 %LOCALAPPDATA%\ATIVBatteryGuard이며 파일명은 manual-control-*.txt입니다.
   같은 결과는 중복 저장하지 않고, 새 작업 결과가 생겼을 때 다시 저장할 수 있습니다.
   저장 실패는 제어 재실행 이유가 아닙니다. 저장만 다시 시도할 수 있습니다.
   오류·불명 보고서도 가능하면 저장해서 전달하세요. 경로·계정·SID·작업 nonce·원시 frame은 넣지 않습니다.

6. 실제 충전 경과를 기록하려면 기존 '새 관찰 시작 → 관찰 중단 → 관찰 TXT 저장'을 사용합니다.
   관찰은 기존 약10초 주기 배터리 상태를 재사용하며 OEM 호출을 하지 않습니다.
   관찰 카드에도 완료·파일명·저장 폴더 열기를 제공합니다.
   같은 세션에 새 샘플이 없는 상태에서는 중복 저장하지 않습니다.
   새 관찰 시작은 이전 메모리 기록을 비우므로 필요한 기록을 먼저 저장하세요.

7. 이번 GUI 확인에서는 먼저 상태 조회 결과와 버튼·관리자 확인·저장 안내가 동작하는지 보세요.
   직접 켜기·해제를 선택한 경우 각 결과가 정상 readback과 Complete로 끝나는지 확인합니다.
   문제가 있거나 검토를 요청할 때 새 manual-control TXT를 전달하면 됩니다.
   충전 효과도 함께 비교했다면 그때의 새 battery-observation TXT를 덧붙일 수 있습니다.
   기존 진단·삼성 DLL·EXE·옛 결과를 다시 제출할 필요는 없습니다.
   테스트를 위해 강제 방전·100% 충전·재부팅을 반복할 필요는 없습니다.

불명·중단·통신 유실에 대한 안내

표시 시간 초과는 실제 펌웨어 종료가 아닙니다. 앱은 실제 호출·출력·입력 정리를 따로 기다립니다.
Pending/실제 정리 대기이면 helper나 앱을 강제 종료하거나 반대 방향 설정을 실행하지 마세요.
통신 유실·불명 상태에서는 자동 재시도하지 않고 새 작업을 차단할 수 있습니다.
새 manual 작업 원장의 active.operation이나 과거 시험 예약을 삭제·수정해 차단을 우회하지 않습니다.
UAC나 동작 확인에서 시작을 취소하면 새 firmware 호출 없이 종료합니다.
절전·복귀 뒤에는 과거 값을 현재 설정으로 사용하지 않고 다시 상태 확인이 필요합니다.

기존 Query65/A/Access1/Protection0To1/Protection1To0 단발 시험은 모두 종료됐습니다.
기존 EXE를 다시 실행하거나 그 목적·예약을 초기화·재사용하지 마세요.
이번 앱은 새 수동 작업 목적을 사용하며, 각 사용자 동작의 실제 종료·결과 확인 뒤에만 다음 작업을 허용합니다.

이 베타에는 서비스·자동 시작·부팅 자동 적용·자동 토글·원복·임의 임계값 설정이 없습니다.
삼성 원본 DLL/EXE·firmware·PDB는 포함하지 않았고 드라이버·보안 설정·BIOS flash를 변경하지 않습니다.
앱의 외부 네트워크 통신·자동 업로드는 없습니다. helper 연결은 현재 계정의 로컬 전용 pipe입니다.
같은 계정의 pipe 권한 설정에 SID를 내부 사용하지만 사용자 이름·SID·nonce를 결과나 로그로 보고하지 않습니다.
