**2026-11-06 원문 확보 후속:** [두 페이지의 버전·모델·주장 구분](SETTINGS_VERSION_SOURCE_REVIEW.md)을 완료했습니다. ## 확인 상태

공식 웹 자료의 내용을 아직 열람하지 못했습니다. 현재 개발 환경의 제한된 인터넷 허용 목록에는 삼성 도메인이 없습니다. 검색·브라우저 도구도 제공되지 않아 공식 문서나 Samsung Settings 2.2.0 사용권 조항을 확인했다고 주장하지 않습니다.

공식 사이트 조회용 네트워크 초안만 저장했습니다. 도구 결과는 `saved`, `requires_publish: true`입니다. 실행 중인 환경에는 아직 적용되지 않았고 환경 게시도 하지 않았습니다. 패키지 사이트 프리셋, 설치 스크립트, 시작 지침, 저장소 구성은 유지했습니다. 이 변경은 개발 환경의 문서 조회용이며 배포 앱의 오프라인 동작을 바꾸지 않습니다.

추가한 검토 대상 도메인은 다음 다섯 곳입니다.

- `www.nbrchive.net` — 사용자가 제공한 포럼 글 조회
- `www.samsung.com` — 공식 제품 지원·사용권 안내 탐색
- `www.samsungsvc.co.kr` — 삼성전자서비스의 PC 지원 자료 탐색
- `downloadcenter.samsung.com` — 공식 설명서 자료 탐색
- `org.downloadcenter.samsung.com` — 공식 다운로드센터의 설명서 자료 탐색

위 도메인들은 조회 대상이며, 특정 지원 설명이나 사용권 조항을 입증하는 인용 출처가 아닙니다. 실제 접근이 가능해진 뒤 원문 URL·문서명·버전·페이지·짧은 관련 인용을 기록해야 합니다.

## 기술 확인 대상

사용자는 Samsung Settings와 BIOS 양쪽에 해당 메뉴가 없다고 확인했습니다. 추가 메뉴 점검이나 OEM 파일 업로드를 요청하지 않고, 공식 지원 여부와 문서화된 제어 방법의 존재만 확인합니다.

- 실제 진단 모델: `940X3G/930X3G`, BIOS `P05ACJ.128.140819.dg`, Windows 10 Home 19045 x64, Samsung Settings 2.2.0.
- 이 모델·BIOS·OS 조합의 공식 충전 상한 기능 지원 여부, 지원한다면 공식 메뉴·패키지와 공개 사용 절차.
- 정확한 판매 모델 접미사가 필요한 경우 제품 모델 코드만 확인한다. 시리얼번호·UUID는 요청하지 않는다.
- 공식 제3자 제어 API/SDK 또는 읽기 전용 상태 조회 방법의 존재 여부.
- 기능이 지원되는 경우 앱 종료·재부팅·전원 차단 이후 유지 여부에 관한 공식 설명.

최신 Galaxy Book의 배터리 보호 설명, 다른 모델의 80%/85% 기능, Linux 구현, WMI 클래스 존재는 이 장치의 Windows 충전 제어 근거로 대신하지 않습니다. 메뉴 부재만으로 하드웨어 기능이 없다고 확정하지도 않습니다.

## 추가 단서와 비교 기준

사용자는 Windows 8에서 제공되던 충전 제한이 Windows 10/Settings 2.2 이후 사라졌다는 보고를 알려주었습니다. 출처와 동일 모델 여부는 아직 미확인입니다. 원문 URL/문서 제목이 확보되면 모델·BIOS·OS·Settings 버전·필요 드라이버·충전 상한·공식 자료 여부를 구분해 확인합니다. 단순 메뉴 제거와 하드웨어 기능 제거를 같은 것으로 취급하지 않습니다.

## 사용권 확인 대상

설치된 Samsung Settings 2.2.0에 실제 적용되는 계약 원문·배포 지역·개정본이 필요합니다. 다른 삼성 제품이나 삼성 계정의 일반 약관으로 대체하지 않습니다. 개인 보관 목적의 복제, 제3자 서비스에 파일 전달, 정적 분석/역분석, 제3자 앱에서의 인터페이스 사용을 각각 구분해 관련 조항과 허용 범위를 확인합니다. 법률상 예외의 적용 여부도 계약 문구만으로 단정하지 않습니다.

확인 전에는 삼성 실행 파일·DLL 추가 업로드 요청과 분석을 보류합니다. 기존 `Settings.exe` 전달 요청은 철회한 상태입니다. 이는 삼성의 금지 정책을 확인했다는 뜻이 아니라 아직 사용권을 확인하지 못했다는 뜻입니다.

## 삼성 문의 초안 — 미전송

> Samsung ATIV Book 9 Plus를 Windows 10 Home 19045 x64에서 사용 중입니다. WMI 모델명은 940X3G/930X3G, BIOS는 P05ACJ.128.140819.dg이며 Samsung Settings 2.2.0과 BIOS 설정 모두에 배터리 충전 제한·배터리 수명 연장 메뉴가 없습니다.
>
> 1. 이 모델·BIOS·OS에서 충전 상한을 제한하는 기능이 공식 지원되나요? 지원된다면 공식 프로그램 버전·설정 방법과 설명서 링크를 부탁드립니다. 80% 외의 상한만 지원한다면 그 값도 알려주세요.
> 2. Windows 8에서 지원되던 기능이 Windows 10/Settings 2.2 이후 사라졌다는 보고가 같은 모델에도 해당하나요? 해당 버전의 기능 변경·드라이버 호환성·지원 정책에 관한 공식 자료가 있나요?
> 3. 제3자 로컬 앱이 이용할 수 있는 공개 제어/상태 조회 API나 SDK가 있나요?
> 4. 이 버전의 사용권 계약 원문을 받을 수 있나요? 프로그램 파일을 제3자 서비스에 전달하여 정적 분석하는 행위와 제3자 앱에서 인터페이스를 사용하는 행위의 허용 범위를 어디에서 확인할 수 있나요?

이 초안은 저장만 했으며 삼성에 제출하거나 연락하지 않았습니다. 공식 답변이나 적용 가능한 원문이 확보되기 전까지 실제 충전 제어는 미지원으로 유지합니다.

## 사용자 제공 포럼 자료 — 본문 미확인

사용자가 제공한 자료는 NBRchive에 보관된 Samsung 게시판의 “Settings Easy Settings - what you need to know” 글입니다. 출처 URL: https://www.nbrchive.net/xfa/samsung.1011/Settings%20Easy%20Settings%20-%20what%20you%20need%20to%20know/

현재 실행 환경은 restricted이며 이 도메인과 삼성 도메인이 활성 허용 목록에 없습니다. 웹 검색/브라우저 도구도 없어 본문을 조회하지 못했습니다. 제목과 사용자 제공 URL만 기록한 상태로, Windows 8 충전 제한 지원 또는 Settings 2.2의 기능 제거를 이 글에서 확인했다고 인용하지 않습니다. 네트워크 우회는 하지 않았습니다.

사용자가 관련 문단이나 화면을 제공하면 게시 날짜, 적용 모델·OS·프로그램/드라이버 버전, 충전 제한 동작과 유지 여부를 확인합니다. 사용자 포럼 경험담과 공식 지원·사용권 근거를 구분합니다.

## 이번에 직접 수행한 작업

현재 허용된 GitHub에서 NBRchive 공개 저장소 및 배터리 관련 공개 프로젝트를 검색했습니다. `nbrchive`와 `BatteryLifeExtender` 저장소 검색 결과는 없었고, `notebookreview` 및 `samsung battery` 검색은 다른 대상도 섞인 목록이었습니다. 동일 모델의 Windows 10 공식 충전 제어 또는 사용자 제공 포럼 글의 본문은 확보하지 못했습니다. 이 결과를 지원 부재의 증거로 해석하지 않습니다. 검색은 GitHub에 이미 공개된 자료를 대상으로 했으며 차단된 사이트로 중계·우회 접속하지 않았습니다.

네트워크 검토 초안에는 사용자 URL의 정확한 호스트 www.nbrchive.net을 추가했습니다. 저장은 확인됐으나 requires_publish=true로 현재 환경에 적용되지 않았고 게시하지 않았습니다. 공식 웹 원문은 계속 미확인입니다.

그동안 프로그램의 OEM 수집기 연결을 해제하고 공식 문의문 미리보기·복사 기능을 구현했습니다. 공유 소스 테스트는 114개 통과했고 WPF 빌드도 성공했습니다. 추가 삼성 파일·본문 전달을 사용자에게 요구하지 않습니다. 현재 확인된 사실과 남은 공개 자료 검증을 구분해 유지합니다.

## 사용자 승인 후 적용 가능성 재확인

사용자는 네트워크 변경 적용을 승인했고 Samsung Settings에서 DLL을 추출할 수 없다는 조건을 명시했습니다. 도구와 설치된 Codex CLI 공개 도움말을 확인했으나 실제 환경 게시 기능은 없습니다. 초안을 저장한 것과 실행 환경에 적용한 것을 구분합니다. 활성 허용 목록에는 아직 삼성/NBRchive가 없습니다.

현재 허용된 GitHub의 MicrosoftDocs 공식 문서 다섯 개를 직접 읽고 Windows 배터리 설정 요청의 범위와 한계를 확인했습니다. 따라서 앞의 공식 자료 미열람 기록은 삼성/NBRchive 및 해당 사용권 원문에 대한 상태입니다. 새로 확인한 Microsoft 자료와 결론은 DLL_INDEPENDENT_RESEARCH.md에 기록했습니다. 삼성 파일의 추가 추출·업로드를 진행 조건으로 삼지 않습니다.
