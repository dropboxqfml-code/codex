# P04ACJ 원본 확보와 P05ACJ 배터리 경로 비교 — 2026-11-06

같은 940X3G 계열의 과거 공식 배포 목록에서 **P04ACJ 원본 패키지를 새로 확보**했습니다. 기존 P05ACJ와 SABI 등록 경로 및 Setup HII 데이터를 비교했지만, 검토한 범위에서 새 배터리 보호 처리자나 신뢰할 설정 조회 계약은 찾지 못했습니다. 실제 충전 제한은 여전히 **미구현·Unsupported**입니다.

이번 작업은 새로운 과거 버전의 비교입니다. 이전 P05 분석을 새 발견으로 계산하지 않았으며 앱 코드·실행 파일·기존 ZIP은 변경하지 않았습니다.

## 확보한 자료와 출처의 한계

저장된 제조사 W7 배포 목록 두 개에 Model `940X3G`, Project `Amor3-13T_Win7_Downgrade`, 표시 이름 `Amor3-13BIOS(TSP/Non-TSP) P04ACJ`인 항목이 있습니다. 두 항목은 **동일한 BAIN-A0010A03.ZIP 한 개**를 가리킵니다. Version 필드는 공백이고 항목은 INFORMATION / NoVerify입니다. 이는 현재 장치의 설치 버전·정확한 SKU·Windows 10 지원을 검증하는 메타데이터가 아닙니다.

목록의 날짜 2014-06-09는 목록 작성·배포 문맥의 날짜입니다. 실제 확보한 펌웨어 내부 표식 `P04ACJ125140411dg`와 구분합니다. 실제 목록에 기록된 위치에서 제조사 리디렉션을 따라 최종 HTTPS 200 응답으로 취득했으며 프록시와 TLS 검증을 유지했습니다. URL이나 파일 이름을 추측하지 않았습니다.

ZIP의 9개 항목·CRC·경로·중복 이름·심볼릭 링크 및 확장 크기 22,129,900바이트를 검사했습니다. P04 CAP는 BIN의 BIOS 영역 끝부분과 바이트 단위로 같고, Windows wrapper의 압축 payload와도 같습니다. **세 컨테이너에 들어 있는 한 펌웨어**이며 독립 버전 세 개가 아닙니다. SHA·CRC와 컨테이너 일치는 바이트 추적과 일관성 검사입니다. 제조사 서명 신뢰체인 검증이나 실제 설치 이미지 동일성의 증명은 아닙니다.

P04/P05의 7개 펌웨어 볼륨 중 앞의 4개는 해시가 같고 나머지 3개는 다릅니다. 아래는 그 안의 관련 모듈을 선택해 비교한 결과이며 새 전체 펌웨어 분석 완료를 뜻하지 않습니다.

## SABI 처리와 등록 경로

| 비교 대상 | 확인한 결과 | 배터리 기능에 대한 의미 |
| --- | --- | --- |
| SecSabiDispatch | 실행 코드·데이터·재배치 섹션과 초기화 포인터 21개가 정확히 같음 | 기존에 분석한 선택된 등록·조회·응답 경로를 재사용할 근거이며 새 처리자 발견은 아님 |
| SecLagacySabi / SecAlwaysOn / SecSwSmiDispatch | 실행 코드·데이터·재배치 섹션이 정확히 같음 | 새 배터리 등록이나 지원 flag 변경 근거를 추가하지 못함 |
| SecWirelessDev | 실제 코드가 달라 P04의 GUID → interface → 등록 호출을 새로 추적 | 동일 main `5843`, sub `12/13/69/6A`; 검토한 등록 경로에 `65/66`은 없음 |
| SecSetupWin | 크기·코드가 달라 P04 등록 경로를 별도 추적 | 동일 sub `7C`; callback은 협상·공유 구조 발견 경로이며 배터리 상태 조회가 아님 |

모듈 전체가 같다는 결론은 아닙니다. Provider의 전체 이미지 차이는 COFF timestamp 3바이트, 버전 문자열 1바이트, unwind 정보 545바이트입니다. 그 unwind 영역은 양쪽 모두 AMD64 UNWIND_INFO 52개로 구조를 확인했습니다. SwSmi의 추가 차이 190바이트도 같은 방식으로 22개 레코드로 해석됩니다. 정상 경로의 선택된 코드가 같다는 사실을 예외 처리·간접 별칭을 포함한 모든 실행 의미의 동일성으로 확대하지 않습니다.

SetupWin callback은 RIP 상대 전역 참조의 위치 이동을 제외한 명령이 같았습니다. 이 모듈의 로컬 조건을 provider의 배터리 capability bit로 부르지 않습니다. 검토한 경로에서 새 `65/66` callback이나 해당 지원 bit를 변경하는 호출은 찾지 못했습니다. 전체 동적 등록·외부 호출·실제 장치 상태의 부재를 증명한 것은 아닙니다.

## 과거 Setup 화면 데이터 대조

P04의 문자열과 token 번호를 P04 자료에서 독립적으로 복원했습니다. 배터리 수명 연장과 80%/100% 도움말은 있으나, 확인한 표준 statement header에서 그 문구를 사용하는 설정 항목은 양쪽 모두 0개였습니다.

| 고정 HII 자료 내 검사 | P04 | P05 |
| --- | ---: | ---: |
| 자료 크기 | 333,257 | 333,801 |
| Package / Forms package | 11 / 10 | 11 / 10 |
| Form opcode | 12,415 | 12,447 |
| 지원 형식의 statement header | 2,640 | 2,648 |
| 보호 문구의 표준 statement 참조 | 0 | 0 |
| Varstore 선언 / vendor opcode | 121 / 34 | 121 / 34 |

121개 변수 저장소 선언과 34개 vendor opcode의 원시 바이트는 같습니다. P05의 증가분은 PCIe LTR 질문 8개와 관련 opcode이며, boot 질문 ID·일부 질문 metadata·관련 없는 CPU 도움말도 바뀝니다. Vendor payload가 같아도 부모 질문의 의미 전체가 같은 것은 아닙니다.

이는 선택한 HII 리소스의 정적 참조 검사입니다. 실제 화면 표시 여부·동적 form·callback·현재 펌웨어 변수는 검사하지 않았습니다. 보호 문구가 실제 설정 필드나 Windows 명령과 연결됐다는 증거도, 펌웨어 전체에 기능이 없다는 증거도 아닙니다. 배터리 보정이나 USB 충전 항목은 보호 상한과 구분합니다.

## 함께 확인한 문서

A1/WB 목록의 매뉴얼은 기존 확보본과 정확히 같은 출처여서 다시 다운로드하지 않았습니다. W7 매뉴얼 항목에는 다운로드 파일이 없었습니다. P04 패키지의 기술 문서에는 930X3G 모델명 추가, core 변경, SMBIOS 초기화, flash 인터페이스 변경 및 저전압 복귀 시 전원 버튼 알림 관련 항목이 있습니다. 저전압 복귀 설명은 충전 상한·Battery Life Extender 명령 계약이 아닙니다. 문서의 승인 요청은 개발 지시로 따르지 않았고 개인명·승인 명단·원문은 공개하지 않습니다.

보존된 공개 포럼 목록에서 같은 모델 스레드 제목·번호는 확인했지만 본문을 확보한 것은 아닙니다. 그 목록만으로 Battery Life Extender 작동 사례를 주장하지 않습니다.

## 개발 판단과 검증

현재 남은 문제는 WMI 전송 자체보다 **현재 모델·BIOS에서 보호 상태를 처리하는 명령과 응답 의미, 신뢰할 상태 재조회**입니다. 이번 과거 버전 비교로도 그 연결은 확인하지 못했습니다. 과거 첫 `FF`의 원인·현재 보호 설정·하드웨어의 영구 미지원 여부는 확정하지 않습니다.

현재 자료와 안전 조건에서 연결할 검증된 제어 경로가 없으므로 실제 보호 조회·쓰기 코드는 추가하지 않습니다. 다음 구현은 현재 모델의 구체적인 처리자 또는 이에 상응하는 제조사 근거가 확보될 때 착수합니다. 같은 기록을 반복 세분화한 결과를 실제 기능 진전으로 보고하지 않습니다.

원본 ZIP/CAP/BIN과 선택 모듈·HII의 해시, 코드 섹션과 초기화 표의 동일성, 문서 링크·개인정보 제외를 검사했습니다. 요약은 [정적 검사 기록](reports/p04-p05-firmware-comparison-audit.json)에 저장했습니다. 원본 펌웨어·삼성 실행 파일·DLL·문서 원문·주소 및 식별자가 포함된 상세 출력은 저장소와 배포물에 넣지 않습니다.

앱·테스트 코드는 변경하지 않았으며 이번에는 빌드·단위 테스트를 반복하지 않았습니다. C# 436개 / Python 85개 통과와 빌드 경고·오류 0개는 코드 커밋 `750994c`의 이전 검증 기록입니다. 새 EXE·ZIP을 제공하지 않으며 기존 프로그램을 그대로 사용합니다. 추가 노트북 시험·자료 재제출·OEM 호출·예약 접근·BIOS 설치나 다운그레이드는 필요하지 않습니다. 하드웨어·드라이버·서비스·보안 설정·펌웨어 변수는 변경하지 않았습니다.
