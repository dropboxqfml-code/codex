ATIV Battery Guard — 보호 해제 1회 시험과 충전 동작 비교

이 도구는 보호 모드를 해제하는 설정 변경을 최대 한 번 수행합니다.
충전이 다시 진행될 수 있습니다. 자동으로 다시 켜거나 이전 임계값으로 복원하지 않습니다.
100% 충전·원복·재부팅 뒤 상태를 보장하지 않습니다.
현재 관찰 앱의 희망 설정 버튼은 실제 보호를 켜고 끄는 버튼이 아닙니다.

먼저 할 일 — 현재 상태에서 충전 관찰

1. 기존 ATIVBatteryGuard.exe 관찰 앱을 일반 권한으로 실행합니다.
   이번 새 해제 ZIP과 기존 앱 ZIP은 서로 다른 폴더에서 사용합니다. 파일을 합치지 않습니다.
2. 평소 쓰는 충전기를 연결하고 앱에 외부 전원 연결 상태가 표시되는지 확인합니다.
   실제 연결했는데 연결 안 됨/Unknown이면 해제 시험 전에 그 사실을 알려주세요.
3. '새 관찰 시작'을 누르고 평소처럼 사용하면서 잔량 상승과 80% 근처 동작을 지켜봅니다.
   80% 근처에서 충전 중 아님 표시가 이어지는지, 계속 충전하는지 모두 관찰 대상입니다.
   세션은 최대 2시간입니다. 강제 방전·재부팅·과거 ON 시험 재실행은 하지 않습니다.
   충전이 진행하지 않아도 상태를 기록하고, 이를 실패로 단정해 설정을 반복하지 않습니다.
4. '관찰 중단' 뒤 '관찰 TXT 저장'을 한 번만 누릅니다.
   %LOCALAPPDATA%\ATIVBatteryGuard의 새 battery-observation-*.txt를 해제 전 기록으로 보관합니다.
   예전 TXT나 삼성 DLL/EXE를 다시 제출할 필요는 없습니다.

그 다음 — 새 보호 해제 도구를 한 번 실행

5. 새 ATIVBatteryGuard-PROTECTION-1TO0.zip 하나를 새 로컬 폴더에 모두 풉니다.
   삼성 DLL이나 다른 ZIP을 넣지 않습니다. 이 ZIP에는 일반 관찰 앱은 없습니다.
6. 충전기를 연결한 채 같은 Windows 계정에서
   ATIVBatteryGuard.ProtectionDisableTrial.exe를 오른쪽 클릭해 '관리자 권한으로 실행'합니다.
   다른 계정 암호나 보안 우회가 필요하면 중단합니다. 자동 권한 상승은 하지 않습니다.
7. 목적 Protection1To0-v1과 현재 토큰 Elevated, 해제 영향 안내를 확인합니다.
   해제 전 AC 관찰 TXT를 먼저 보관했고 이 한 번의 해제에 동의할 때만 START를 입력합니다.
   START 전에는 예약·WMI·firmware method를 실행하지 않습니다.
8. 이번 실행은 새 목적의 준비 1회를 소모합니다. 실패·권한 거부·중단·시간 초과도 소모됩니다.
   사전 모드1 조회 → 의미상 설정0 최대1회 → 사후 모드0 조회의 최대3회 호출뿐입니다.
   사전 모드0이면 이미 해제된 후보로 설정 없이 종료합니다. 불명·오류에서도 설정하지 않습니다.
   임계값 조회/쓰기·재시도·다시 켜기·초기화·handshake·복원은 하지 않습니다.
9. 결과를 기다립니다. 10초 표시 시간 초과는 firmware가 멈췄다는 뜻이 아닙니다.
   Pending/정리 대기면 창·프로세스를 강제 종료하거나 다시 실행하지 마세요.
   '관련 정리: Complete' 또는 호출 전 종료 안내 뒤에만 Enter로 닫습니다.
   이 EXE가 있는 폴더에 새 protection-1to0-result-*.txt 한 개가 생성됩니다.
   파일 저장을 위한 추가 클릭은 필요 없습니다. 저장 실패도 재실행 이유가 되지 않습니다.

정상 해제 후보가 나온 뒤 — 같은 충전기 연결로 비교

10. 새 결과가 StoredReadbackMatchedCandidate, 사전 모드1·사후 모드0이며
    관련 정리가 Complete일 때, 기존 관찰 앱에서 '새 관찰 시작'을 누릅니다.
    별도 앱의 '해제 전 기록'은 새 관찰 시작 전에 저장해 두어야 합니다.
11. 같은 충전기 연결 상태에서 충전 표시와 잔량 상승을 관찰합니다.
    해제 전 80% 근처에서 멈췄다면 해제 뒤 충전이 재개되고 잔량이 그 위로 진행하는지 봅니다.
    강제로 100%까지 기다리거나 재부팅·ON 재설정을 할 필요는 없습니다.
    충분히 관찰한 뒤 '관찰 중단 → 관찰 TXT 저장'을 한 번만 누릅니다.
12. 새 protection-1to0-result TXT와 해제 전·후의 새 battery-observation TXT를 전달해주세요.
    기존 진단·삼성 DLL·EXE를 다시 올리지 않습니다.

사전 모드0·불일치·오류·시간 초과·Pending이면 성공한 해제로 간주하지 않습니다.
해제 도구를 다시 실행하거나 예약을 조회·수정·삭제·다른 계정/폴더로 우회하지 마세요.
관련 정리를 기다린 뒤 생성된 새 해제 TXT와 확보한 관찰 기록만 전달하면 됩니다.
기존 A/Access1/Query65/Protection0To1 도구와 예약은 이미 끝났으므로 다시 사용하지 않습니다.

결과의 의미

모드1→0 후보 일치는 저장 모드의 독립 비교 결과입니다.
설정 응답 ReceiptOnly나 SDK 진입은 독립 실행 성공 ACK·충전 재개 성공이 아닙니다.
해제 전후 Windows 표시의 변화는 충전 동작을 비교할 자료이며 전류·충전기 레지스터 측정은 아닙니다.
80% 유지나 NotCharging 한 항목만으로 성공을 확정하지 않습니다.
일반 앱의 상시 보호 조회·실제 충전 제어 지원은 아직 Unsupported입니다.

Windows 10 x64 / .NET Framework 4.8 / 기존940X3G/930X3G·P05ACJ profile 대상입니다.
미서명 개발 빌드이며 이 새 해제 도구의 실제 Windows SDK/노트북 실행은 아직 미검증입니다.
삼성 원본 DLL·firmware·PDB·다른 실험 EXE는 포함하지 않습니다.
실행 중 네트워크·자동 업로드·드라이버/서비스/보안 설정 변경·BIOS flash는 없습니다.
