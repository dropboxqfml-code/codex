2026-11-10 한국 시간. 요청에 따라 프로그램의 베타 표기를 제거하고, 보호 상태를 쉬운 문구로 바꿨으며 배터리 관찰 그래프를 추가했습니다.

## 충전 제한 상태 표시

| 마지막으로 수용한 조회 결과 | 화면 표시 |
| --- | --- |
| 제한 켜짐, 상한80·하한75 | **80% 충전 제한** |
| 제한 해제 | **충전 제한 해제 · 일반 충전** |
| 켜짐만 확인, 상한·하한 미조회/불명 | **충전 제한 켜짐 · 상한 미확인** |
| 켜짐과 다른 정상 범위의 상한·하한 | **충전 제한 켜짐 · 상한 N%** |
| 미조회·불명·정리 대기·시뮬레이션 | 각각의 미확인·진행·시뮬레이션 상태 유지 |

상태 앞에는 **마지막 조회**를 표시하고 기존 결과 수신 시각을 함께 보여줍니다. 모드1만으로80%를 추론하지 않습니다. 0·255 같은 부적절한 임계값이나 역전된 상·하한도 정상 상한으로 표시하지 않습니다. 원래 숫자 모드와 후보값은 접힌 요청 상세와 TXT에 보존하며, 새 문구로 읽기·쓰기 권한이나 실제 충전 효과를 판정하지 않습니다.

프로그램 버전은 `0.2.0`, Windows 파일 버전은 `0.2.0.0`입니다. 현재 화면·버전·동봉 사용 안내에는 베타 표기가 없습니다. 이전 배포 ZIP과 기록은 당시 바이트로 보존합니다.

## 관찰 시작 시 나타나는 잔량 그래프

**새 관찰 시작**을 누르면 그래프가 바로 표시되고, 첫 자료가 오기 전에는 다음 갱신을 기다린다고 안내합니다. 기존 약10초 배터리 갱신이 들어오면 실제 표본을 점과 선으로 그립니다. 가로축은 관찰 시작 후 경과 시간, 세로축은 잔량0~100%입니다.

처음 한 표본도 점으로 보여줍니다. 읽기 오류·알 수 없는 상태·배터리 없음·30초 초과 공백은 연결선을 끊습니다. 실제 표본에 마우스를 올리면 해당 경과 시간·잔량·전원 연결·충전 상태를 볼 수 있습니다. 표본 사이의 값을 측정하거나 만들어내지 않습니다.

**관찰 중단**은 그래프와 자료를 남기고, **관찰 지우기**는 메모리와 그래프를 초기화합니다. 새 관찰은 새 세션이므로 필요한 이전 기록을 먼저 TXT로 저장합니다. 시뮬레이션 중에는 실제 관찰 그래프를 숨깁니다. 기존 관찰 요약과 TXT·저장 폴더 열기도 유지합니다.

그래프는 기존 관찰 세션의 읽기 전용 복사본만 그립니다. 새 타이머·장치 조회·OEM 호출·네트워크·파일 저장을 추가하지 않습니다. 원래 세션의10초 이상 간격·최대2시간/721표본·CSV 형식은 그대로입니다. 화면에는 기존 글자 크기로 약180높이의 그래프를 표시하고 작은 창·화면 안 배치·접힌 기능을 유지합니다.

## 사용과 검증

ZIP 하나를 새 폴더에 모두 풀고 **ATIVBatteryGuard.exe를 일반 권한으로 실행**합니다. 보호 상태가 필요하면 기존 **보호 상태 확인**을 사용하고, 그래프는 **Windows 배터리 상태 관찰 → 새 관찰 시작**에서 봅니다. 이번 확인은 쉬운 상태 문구와 그래프 표시·중단·지우기입니다. 기존 충전 제한·해제·Windows10 다시 시작 후 유지 근거는 유효하며 같은 충전 시험이나 기존 자료를 다시 제출할 필요는 없습니다.

새21그룹(순수 그래프9·표시/VM12)을 포함해 **1140개 통과·실패0·건너뜀0**입니다. Portable과 실제 WPF/XAML 전체 net48 Release 빌드는 각각 경고·오류0개입니다. 알려진 상태/상한 미확인, 늦은 결과·시뮬레이션, 그래프 공백·불변 복사·시작/중단/초기화·추가 조회 없음 등을 검증했습니다. 새 WPF 그래프의 실제 Windows 렌더링·마우스·접근성 동작은 아직 실기 확인 전입니다.

기존 제품237개 중 VM·XAML·버전 상수3개만 수정하고234개를 보존했습니다. 새 파일은 순수 그래프·상태 문구와 WPF 그래프입니다. 기존 창 위치/DPI 보정·배터리 제공자·관찰 세션/CSV·하드웨어 Core·WmiInterop·helper·로컬 프로토콜·실제 정리·owner·quarantine·예약 코드는 바꾸지 않았습니다. 조회3·켜기7·해제3, 설정 최대1회와 명시적 사용자 요청 조건도 동일합니다. 기존 테스트98개와 ZIP71개를 보존했고 등록부/프로젝트·버전 기대값·친숙한 상태 문구 기대값만 별도로 갱신했습니다.

ZIP은 프로그램6개와 안내·BUILD-INFO·SHA의9항목입니다. 삼성 원본 DLL·firmware·PDB·과거 단발 EXE는 없으며 디지털 서명은 없습니다. 새 드라이버·서비스·보안 정책·BIOS flash·자동 적용·자동 재시도·외부 네트워크·자동 업로드는 추가하지 않았습니다. 대상 모델과 Windows10 x64/.NET Framework4.8 조건은 기존과 같습니다.
