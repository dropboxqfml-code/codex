충전 제한 상태

'보호 상태 확인'을 누르고 같은 계정의 관리자 확인에 응답합니다.
정상 조회 뒤 필요한 '80% 보호 켜기' 또는 '보호 해제 · 일반 충전'을 직접 선택합니다.

- 80% 충전 제한: 보호 켜짐과 상한80·하한75가 함께 확인된 마지막 조회입니다.
- 충전 제한 해제 · 일반 충전: 마지막 조회에서 제한 해제가 확인된 상태입니다.
- 충전 제한 켜짐 · 상한 미확인: 켜짐만 읽고 상한을 조회하지 않은 경우입니다.
- 다른 유효 상한이 읽혔다면 그 상한을 표시하며 임의로80%로 바꾸지 않습니다.

표시된 상태와 수신 시각은 마지막 조회 기록입니다. 계속 자동 조회하는 현재값이 아닙니다.
숫자 모드와 원래 후보값은 '요청 상세'와 제어 TXT에서 확인할 수 있습니다.
자동 제어·재시도·부팅 자동 적용은 추가하지 않았습니다.

잔량 그래프

1. 'Windows 배터리 상태 관찰'에서 '새 관찰 시작'을 누릅니다.
2. 그래프가 바로 나타나며, 다음 기존 약10초 갱신부터 점과 선이 추가됩니다.
   가로는 관찰 시작 후 경과 시간, 세로는 배터리 잔량0~100%입니다.
   한 개만 기록됐을 때는 점으로 표시하고, 읽기 오류·배터리 없음·긴 공백은 선으로 연결하지 않습니다.
3. 그래프의 실제 기록 점에 마우스를 올리면 해당 시각·잔량·AC·충전 상태를 볼 수 있습니다.
4. '관찰 중단'은 그래프를 보존하며 기록을 멈추고, '관찰 지우기'는 메모리 기록과 그래프를 비웁니다.
   '새 관찰 시작'도 새 세션이므로 필요한 이전 기록은 먼저 저장하세요.
5. '관찰 TXT 저장 → 관찰 저장 폴더 열기'로 개별 기록을 보관합니다.
   관찰 요약은 접힌 '관찰 기록 보기'에서 확인할 수 있습니다.

그래프는 기존 Windows 배터리 자료를 표시합니다. 추가 장치 조회·OEM 호출은 하지 않습니다.
그래프 표시나80% 정체만으로 현재 보호 설정을 새로 판정하지 않습니다.
시뮬레이션 중에는 실제 관찰 그래프를 숨기며 실제 장치 기록을 만들어내지 않습니다.

기존750×565 작은 창·글자 크기·화면 안 배치·접힌 기능은 유지합니다.
결과 저장 위치도 기존 %LOCALAPPDATA%\ATIVBatteryGuard이며 폴더 열기 안내와 중복 저장 방지를 유지합니다.
실제 종료 미확인·Pending이면 앱/helper를 강제 종료·재실행하거나 작업 기록을 삭제해 우회하지 않습니다.

기존 충전 제한·해제·Windows10 다시 시작 후 유지 확인 결과는 유효합니다.
이번에는 쉬운 상태 문구와 관찰 시작 후 그래프 표시를 확인하면 됩니다.
같은 충전 시험·기존 진단·TXT·삼성 DLL·EXE를 다시 제출할 필요는 없습니다.

대상은 기존 Windows10 x64 / .NET Framework4.8 / 940X3G·930X3G / P05ACJ입니다.
배포 파일에는 디지털 서명이 없으며 삼성 원본 DLL·firmware·예전 단발 시험 EXE·PDB는 포함하지 않습니다.
실행 중 외부 네트워크·자동 업로드·드라이버/서비스 설치·보안 정책 변경·BIOS flash는 없습니다.
