# ATIV Battery Guard 0.2.1

2026-11-25 한국 시간. 0.2.0의 프로그램 시작 창 크기가 적절하다는 사용자 확인을 반영했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.1-WIN10-X64.zip) · [사용 순서](RELEASE_021_USER_STEPS.txt) · [검증 기록](reports/release-021-validation.json)

관찰 그래프가 키보드 초점을 받도록 개선했습니다. 처음 Tab으로 접근하면 마지막 실제 표본을 선택하고, 좌우 화살표로 이전·다음 실제 표본을 확인합니다. Home과 End는 첫 표본과 마지막 표본으로 이동합니다. 다시 Tab 또는 Shift+Tab을 누르면 주변 컨트롤로 이동합니다. 초점 테두리와 선택 점, 그래프 아래의 경과 시간·잔량·전원 연결·충전 상태를 표시하며 UI Automation의 ItemStatus에도 선택 정보를 제공합니다.

0%와 100%를 포함해 실제 표본만 선택합니다. 누락·오류 구간은 다음 실제 표본으로 이동합니다. 새 표본이 추가되거나 관찰을 중단해도 선택한 표본을 유지하며, 관찰 지우기와 새 세션은 이전 선택을 초기화합니다. 자료가 없으면 조작 안내를 표시합니다. 선택은 기존 불변 그래프 자료만 사용합니다.

이번 실행에서 Portable Release 빌드와 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개였습니다. 빈 자료·경계·누락 구간 이동, 추가 갱신·중단 후 선택 유지, 지우기·재시작·변경 자료에서 선택 초기화를 검사하는 새 3개 그룹을 포함해 1143개 통과·실패 0개·건너뜀 0개입니다.

Windows GUI self-test에는 라우트 키 이벤트, 선택 텍스트 바인딩, 접근성 ItemStatus, 지우기 검사를 추가했고 WPF 빌드로 컴파일했습니다. 이번 Linux 환경에서 이 Windows 검사는 실행하지 않았습니다. 새 버전의 실제 Tab 초점 이동·렌더링·스크린 리더 동작은 Windows 확인이 남아 있습니다. 기존 사용자 노트북의 80% 충전 억제·해제 후 충전 재개·Windows 다시 시작 후 보호 유지 결과는 인수인계했습니다.

수정한 제품 파일은 그래프 컨트롤·새 순수 선택 모델·화면 XAML·WindowsSmokeTest·버전 상수입니다. 테스트 등록과 버전 기대값을 갱신하고 새 선택 회귀 테스트를 추가했습니다. 기존 릴리스 패키징 스크립트에는 0.2.1 버전 선택을 추가했습니다. 배포 ZIP의 9개 항목·프로그램 파일 6개·GUI 버전 0.2.1.0/0.2.1·내부 체크섬·CRC·빌드 바이트 일치를 검사했습니다.

ZIP SHA256은 `fd2927dea2f8b0f8b84a7c7201fc21de2ba0c2933197f0926d7800d6448689ec`입니다. 다음 검증 목표는 실제 Windows에서 키보드 표본 선택과 선택 정보 읽기입니다.
