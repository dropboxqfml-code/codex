# ATIV Battery Guard 0.2.10

2026-11-25 한국 시간. 사용자 피드백에 따라 화면의 세부 스타일과 중복 안내를 정리했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.10-WIN10-X64.zip) · [사용 순서](RELEASE_0210_USER_STEPS.txt) · [검증 기록](reports/release-0210-validation.json)

배터리/기록/도움말·진단 탭을 일반 버튼과 같은 반경 6의 둥근 테두리, 가로/아래 8 간격, 최소 높이 40으로 맞췄습니다. 선택·마우스·비활성 상태를 구분하고 키보드 초점 테두리와 기존 탭 선택 동작을 유지합니다. 전원·충전 상태 값은 배터리 %와 같은 SemiBold로 표시합니다.

‘처음 사용한다면’과 ‘배터리 변화를 확인하고 싶다면’ 카드를 제거했습니다. 설정 순서와 기록 이동에 필요한 내용은 기존 도움말에 있어 중복 문구를 추가하지 않았습니다. 평상시 하단의 준비 메시지와 정상 진단 완료 공지도 제거했으며, 표시할 내용이 없으면 안내 영역 전체를 접습니다. 실제 복사·저장 결과와 실패·설정 경고는 유지합니다. 기존 진단 결과와 충전 작업 경고는 해당 화면에서 계속 확인할 수 있습니다.

하단 메시지 회귀 1개를 추가해 총 1244개 통과·실패/건너뜀 0입니다. 진단 성공 후 공지 제거, 복사 결과·진단 실패·설정 경고 보존과 표시 변경 알림을 검사했습니다. 전체 기존 기능 검사도 함께 실행했습니다. Portable와 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개입니다. ZIP의 버전·구성·빌드 바이트·내부 해시·CRC를 검증했습니다.

이번 Linux에서 새 탭의 실제 Windows 모양·마우스/키보드 초점·고배율 화면은 확인하지 않았습니다. Windows self-test·Defender 검사는 미실행이며 서명 없는 개발 배포본입니다. 장치 제어 검증·통신·저장 형식은 변경하지 않았고 실제 OEM·펌웨어 작업은 0회입니다.

주요 변경은 App.xaml, MainWindow.xaml, MainViewModel의 안내 표시, 버전·회귀·패키징·문서입니다. 다음은 새 스타일을 실제 Windows에서 확인하고 0.3.0의 품질·배포 검증을 준비하는 단계입니다.
