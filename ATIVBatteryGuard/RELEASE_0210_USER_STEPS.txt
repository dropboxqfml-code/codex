ATIV Battery Guard 0.2.10 — 화면 세부 정리

Windows 10 x64 / .NET Framework 4.8 / Samsung 940X3G

ZIP을 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.

배터리·기록·도움말/진단 탭에 다른 버튼과 같은 둥근 테두리와 간격을 적용했습니다.
선택한 탭은 파란색으로 표시하며 키보드 초점 표시를 유지합니다.
전원과 충전 상태 값도 배터리 %처럼 굵게 표시합니다.

‘처음 사용한다면’과 ‘배터리 변화를 확인하고 싶다면’ 카드는 제거했습니다.
충전 설정 순서와 기록 이동 방법은 도움말·진단의 기존 사용 안내에서 확인할 수 있습니다.

하단의 준비·정상 진단 완료 공지는 제거했습니다.
알릴 내용이 없으면 하단 안내 영역도 보이지 않습니다.
복사·저장 결과와 오류·설정 경고는 작업 확인에 필요하므로 계속 표시합니다.
진단 결과는 도움말·진단 화면에서 확인할 수 있습니다.

기존 충전 제어·기록·메모·비교·불러오기와 데이터 형식을 유지합니다.
새 탭 스타일의 실제 Windows 모양·초점·고배율 확인은 남아 있습니다.
디지털 서명이 없는 개발 배포본입니다.
