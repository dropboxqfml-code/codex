# ATIV Battery Guard 0.2.11

2026-11-25 한국 시간. 사용자가 보고한 글자 미표시와 둥근 탭의 우측/하단 잘림을 대상으로 수정하고 요청 범위 밖 변경을 되돌렸습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.11-WIN10-X64.zip) · [사용 순서](RELEASE_0211_USER_STEPS.txt) · [검증 기록](reports/release-0211-validation.json)

0.2.10의 TabItem 선택 스타일은 Foreground=White와 FontWeight를 컨테이너에 설정해 선택한 페이지의 본문에도 상속될 수 있었습니다. 이 스타일을 제거하고 제목용 ContentPresenter 안에서만 글자 서식을 지정합니다. 선택 탭은 밝은 배경·어두운 글자·강조 테두리로 구분하며 본문은 기존 글자색과 굵기를 사용합니다.

기본 TabPanel의 헤더 전용 배치를 사용하지 않고 WrapPanel이 각 헤더와 여백 전체를 측정하도록 바꿨습니다. 선택한 페이지의 PART_SelectedContentHost와 기존 탭 선택 컨트롤을 유지합니다. 둥근 테두리와 간격은 헤더에만 적용합니다. 실제 사용자의 Windows에서 잘림이 해결됐다는 관측 결과는 이번 환경에서 확보하지 않았습니다.

0.2.9와 대조해 요청한 네 가지 차이만 본문에 남겼습니다. 두 카드 제거·전원/상태 SemiBold·정상 진단 완료 공지 제거와 알림 필요 시의 하단 영역 표시를 유지했습니다. 0.2.10에서 추가로 없앴던 시작 안내와 이전 모드 안내는 0.2.9 초기화 코드로 복원했습니다. 단순 문구 외의 저장/복사 결과·오류·설정 경고는 계속 제공합니다.

새 스타일 회귀 1개 포함 1245개 통과·실패/건너뜀 0입니다. 헤더 글자 스타일의 적용 대상, 일반 패널에서의 전체 헤더 배치, 선택한 콘텐츠 presenter 보존을 검사했습니다. 하단 메시지 검사도 초기 안내 복원을 반영하고 진단 성공/실패·복사·설정 경고를 검사합니다. Portable 및 전체 net48 WPF/XAML Release는 각각 경고 0개·오류 0개입니다.

Windows self-test에는 모든 탭의 본문/제목 글자 대비와 헤더 경계가 전체 배치 영역 안에 있는지를 검사하는 코드를 추가해 컴파일했습니다. 원래 창과 폭 480의 작은 창을 검사하도록 구성했으나 이번 Linux에서는 실행하지 않았습니다. 따라서 이 검사는 실제 Windows에서 통과한 기록이 아닙니다. GUI·IME·고배율·Defender 검사와 디지털 서명은 이번에 수행하지 않았고 OEM·펌웨어 동작은 0회입니다.

주요 변경은 App.xaml의 헤더 전용 스타일/탭 배치, MainWindow의 스타일 연결, MainViewModel의 초기 안내 복원, WindowsSmokeTest와 회귀·버전·패키징·문서입니다. 기존 장치 검증·통신·저장 형식을 유지합니다. ZIP의 9항목·GUI 버전·빌드 바이트·내부 해시·CRC를 검증했습니다.
