ATIV Battery Guard 0.2.1 — 그래프 키보드 접근 개선

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. Windows 배터리 상태 관찰에서 새 관찰 시작을 누릅니다.
3. 첫 갱신 뒤 그래프에 실제 배터리 표본이 나타납니다.
4. 처음 Tab으로 그래프에 초점을 옮기면 마지막 표본이 선택됩니다.
5. 왼쪽/오른쪽 화살표로 이전/다음 실제 표본을 선택합니다.
   Home은 첫 표본, End는 마지막 표본입니다.
   그래프의 테두리와 선택 점이 표시되며 아래에 경과 시간·잔량·외부 전원·충전 상태가 나타납니다.
6. Tab 또는 Shift+Tab으로 다음 또는 이전 컨트롤로 이동합니다.
7. 관찰 중단은 그래프를 보존하고, 관찰 지우기는 자료와 선택을 초기화합니다.

데이터가 없는 구간은 건너뛰어 실제 표본만 선택합니다.
화면의 기록은 관찰 당시 Windows 측정값이며 보호 상태는 마지막 조회 결과와 시각으로 확인합니다.
마우스 표본 확인, 기존 수동 보호 상태 확인·80% 켜기·보호 해제와 TXT 저장도 사용할 수 있습니다.
프로그램 시작과 관찰은 관리자 확인을 요구하지 않습니다.
수동 보호 버튼의 장치 작업에는 기존 관리자 확인이 적용됩니다.

0.2.0의 시작 창 크기가 적절하다는 사용자 확인을 반영했습니다.
기존 80% 충전 억제·해제 후 충전 재개·Windows 다시 시작 후 유지 결과를 인계했습니다.
이번 개선의 Windows 실제 키보드·스크린 리더 동작은 실기 확인 전입니다.
디지털 서명이 없는 배포본입니다.
