# ATIV Battery Guard 0.2.2

2026-11-25 한국 시간. 사용자가 0.2.1에서 Tab으로 그래프에 접근해 표본을 확인할 수 있다고 보고했습니다. 이번 버전에는 요청한 마우스 선택과 앞서 설명한 관찰 종료 상태·최종 저장 개선을 적용했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.2-WIN10-X64.zip) · [사용 순서](RELEASE_022_USER_STEPS.txt) · [검증 기록](reports/release-022-validation.json)

그래프를 클릭하면 키보드 초점을 받고, 데이터 포인트를 클릭하면 해당 표본을 선택합니다. 그래프 아래의 표본 정보와 강조 점, UI Automation 선택 정보가 함께 갱신됩니다. 클릭 뒤 좌우 화살표와 Home/End로 이어서 표본을 이동할 수 있습니다.

클릭과 마우스 표본 안내는 같은 좌표 판정을 사용합니다. 점 주변 14 DIP 안에서 가장 가까운 실제 표본을 선택하며 동거리에서는 뒤의 표본을 선택합니다. 축 경계의 0%·100% 점도 선택할 수 있습니다. 점에서 떨어진 빈 공간 클릭은 그래프에 초점을 주고 기존 선택을 유지합니다. 선택이 없는 첫 접근에서는 마지막 실제 표본을 선택합니다. 자료가 없는 구간과 표본 사이의 선은 새 표본으로 만들지 않습니다.

관찰 카드에 시작 전·기록 중·사용자 중지·샘플 한도 도달·시간 한도 도달·시간 순서 오류로 중지를 표시합니다. 기존 관찰 세션의 상태 문구를 화면에서도 재사용합니다.

저장 중복 판정에 세션·표본 수·관찰 상태를 사용합니다. 기록 중 저장한 뒤 새 표본 없이 중단해도 최종 중지 상태를 한 번 더 저장할 수 있습니다. 동일한 최종 내용은 반복 저장하지 않으며 실패한 저장은 다시 시도할 수 있습니다. 저장 성공으로 표시하는 상태는 실제로 내보낸 자료의 상태입니다.

이번 실행에서 새 회귀 7개를 포함해 1150개 통과·실패 0개·건너뜀 0개입니다. 기존 중단 후 저장 기대값은 새 동작에 맞춰 갱신했습니다. 검사에는 축 경계·허용 거리·가까운 점·빈 공간·창 크기별 좌표·마우스와 키보드의 선택 연결, 최종 저장의 상태·동일한 CSV 표본·중복 방지·실패 재시도·저장 중 상태 변경·각 종료 상태 표시가 포함됩니다.

Portable Release 및 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개입니다. Windows GUI self-test에 표시 중인 그래프의 좌표 선택·빈 공간 선택 유지·키 이동 연결 검사도 추가했고 컴파일했습니다. 이번 Linux 환경에서는 Windows self-test와 실제 마우스·스크린 리더 동작을 실행하지 않았습니다.

제품 수정 파일은 그래프 컨트롤·선택 모델·MainViewModel·관찰 세션의 상태 설명 속성·XAML·WindowsSmokeTest·버전 상수입니다. 회귀 검사와 패키징·안내·인수인계도 갱신했습니다. 기존 사용자의 창 크기·키보드 표본 확인과 충전 제한·해제·다시 시작 후 유지 결과를 인계했습니다.

배포 ZIP의 9개 항목, 프로그램 파일 6개, GUI 버전 0.2.2.0/0.2.2, 내부 SHA·CRC와 빌드 파일 바이트 일치를 검증했습니다. 새 마우스 클릭과 최종 상태 저장의 실제 Windows 사용 확인이 남아 있습니다.
