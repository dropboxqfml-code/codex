ATIV Battery Guard 0.2.2 — 마우스 표본 선택과 관찰 종료 기록

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. Windows 배터리 상태 관찰에서 새 관찰 시작을 누릅니다.
3. 첫 배터리 갱신 뒤 그래프에 실제 표본이 나타납니다.
4. 그래프를 마우스로 클릭하거나 Tab으로 접근합니다.
   처음 접근할 때는 마지막 실제 표본을 선택합니다.
5. 데이터 포인트를 클릭하면 그 표본을 선택합니다.
   점 주변 14 논리 픽셀 안에서 가장 가까운 점을 선택하므로 정확한 중심을 누를 필요가 없습니다.
   거리가 같은 점은 뒤의 표본을 선택합니다.
   점에서 떨어진 빈 공간을 클릭하면 초점을 받고 기존 선택을 유지합니다.
6. 선택한 표본의 경과 시간·잔량·외부 전원·충전 상태를 그래프 아래에서 확인합니다.
   왼쪽/오른쪽 화살표로 이어서 이전/다음 표본을 선택할 수 있습니다.
   Home과 End는 첫 표본과 마지막 표본으로 이동합니다.
   Tab 또는 Shift+Tab으로 주변 컨트롤로 이동합니다.
7. 관찰 상태에서 시작 전·기록 중·사용자 중지·시간/샘플 한도 도달 등의 종료 이유를 확인합니다.
8. 관찰 중 TXT를 저장했더라도 중단 후에는 최종 상태를 한 번 더 저장할 수 있습니다.
   기록 수와 상태가 같으면 중복 저장을 막습니다.
   저장 실패 시에는 관찰 기록을 보관하므로 저장만 다시 시도할 수 있습니다.
9. 관찰 지우기는 메모리의 기록과 선택을 초기화합니다. 이미 저장한 파일은 유지됩니다.

기존 0.2.1의 Tab 접근과 표본 확인은 사용자가 정상 동작을 확인했습니다.
0.2.2의 실제 Windows 마우스 클릭·초점 표시·스크린 리더 동작은 실기 확인 전입니다.
디지털 서명이 없는 배포본입니다.
