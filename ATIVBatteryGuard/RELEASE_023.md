# ATIV Battery Guard 0.2.3

2026-11-25 한국 시간. 저장한 관찰 TXT를 다시 열어 당시 그래프와 개별 표본을 확인하는 기능을 구현했습니다. 사용자가 확인한 0.2.2의 마우스 그래프 접근·표본 선택 결과도 개발 기록에 반영했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.3-WIN10-X64.zip) · [사용 순서](RELEASE_023_USER_STEPS.txt) · [검증 기록](reports/release-023-validation.json)

화면의 저장된 관찰 기록에서 관찰 TXT 열기를 누르면 로컬 파일을 선택할 수 있습니다. 파일명, 파일 저장 당시 관찰 상태, 표본 수, 마지막 표본의 경과 시간과 기록 공백 수를 표시하고 기존 그래프 컨트롤로 잔량 표본을 그립니다. 마우스 클릭·Tab·좌우 화살표·Home/End로 표본을 확인할 수 있습니다. 기록 닫기로 불러온 자료를 메모리에서 해제합니다.

불러온 그래프는 과거 파일의 관찰 기록으로 표시합니다. 파일이 기록 중 상태로 저장됐어도 화면은 파일 저장 당시 상태를 설명합니다. 현재 관찰을 진행하면서 파일을 열거나 닫을 수 있습니다. 파일 열기 실패와 선택 취소 시에는 이전에 열었던 기록을 계속 표시하고 결과 안내를 갱신합니다.

기존 0.2.0~0.2.2의 ExportText 구현이 현재와 같음을 소스에서 대조했습니다. 동일한 제목·요약·7개 CSV 열을 읽으며 UTF-8, UTF-8 BOM, Windows CRLF와 LF 줄바꿈을 지원합니다. 최대 256 KiB·721표본·7200초이며, 시간은 기존 관찰의 10초 이상 간격을 검사합니다. 요약과 표본 수·공백 수·마지막 시각의 일치, 범위·전원·충전 상태·품질·읽기 오류와 종료 상태를 검증합니다. 오류 메시지는 고정된 설명을 사용합니다.

잔량 미확인·배터리 없음·읽기 오류 표본은 잔량 점을 만들지 않으며, 기존 그래프 모델로 기록 공백의 연결선을 끊습니다. 파일 전체를 검증한 뒤에 불변 그래프를 게시합니다. 읽기는 바이트 수를 제한하고 파일을 수정하지 않습니다. 파일 선택 경로에는 기존 LocalPathPolicy의 로컬 드라이브·링크 검사를 적용했습니다.

새 회귀 13개를 포함해 1163개 통과·실패 0개·건너뜀 0개입니다. 실제 TXT 저장 후 새 ViewModel에서 파일을 다시 여는 검사, 원본 바이트 보존, 기존 형식 복원, 표본·공백·종료 상태·최대 세션·인코딩·손상·과대 스트림·취소·오류 복구·재진입·종료 후 늦은 반환을 검사했습니다. 현재 관찰·배터리 읽기 횟수·제어 상태와 파일 읽기의 연결도 검사했습니다.

Portable Release와 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개입니다. Windows GUI self-test에는 저장 기록 열기·바인딩·선택·과거 기록 접근성 설명·닫기 검사를 추가해 컴파일했습니다. 이번 Linux에서 Windows 파일 선택창과 실제 GUI·스크린 리더 검사는 실행하지 않았습니다.

제품 변경 파일은 새 SavedBatteryObservation 읽기·검증 모델, IUserInteraction과 LocalUserInteraction의 파일 선택 연결, MainViewModel, XAML, 그래프의 저장 기록 표시, WindowsSmokeTest, 관찰 상태 문구의 내부 재사용과 버전 상수입니다. 테스트·패키징·안내·인수인계 기록도 갱신했습니다. ZIP의 9개 항목과 프로그램 파일 6개, GUI 버전 0.2.3.0/0.2.3, 내부 SHA·CRC·빌드 바이트 일치를 검증했습니다.

다음 확인 항목은 실제 Windows에서 기존 관찰 TXT를 선택해 그래프를 열고 표본을 확인한 뒤 기록을 닫는 흐름입니다.
