ATIV Battery Guard 0.2.3 — 저장한 관찰 TXT 다시 열기

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. 저장된 관찰 기록에서 ‘관찰 TXT 열기’를 누릅니다.
3. 이전에 저장한 battery-observation-*.txt 파일을 선택합니다.
4. 파일명, 파일 저장 당시 상태, 표본 수, 마지막 경과 시간과 기록 공백 수를 확인합니다.
   0.2.0~0.2.2에서 저장한 기존 형식과 0.2.3의 관찰 TXT를 지원합니다.
5. 나타난 그래프에서 데이터 포인트를 클릭하면 당시 표본을 선택합니다.
   Tab으로 접근한 뒤 좌우 화살표 또는 Home/End로 표본을 선택할 수도 있습니다.
6. ‘기록 닫기’는 불러온 화면과 메모리를 닫습니다.
   저장된 TXT 파일은 그대로 보관됩니다.
7. 앱을 종료한 뒤 다시 시작해도 ‘관찰 TXT 열기’로 같은 기록을 확인할 수 있습니다.

불러온 그래프는 파일에 저장된 과거 관찰 기록입니다.
‘파일 저장 당시 상태 · 기록 중’은 저장 시점의 관찰 상태입니다.
현재 관찰은 위의 Windows 배터리 상태 관찰에서 시작·중단·저장합니다.
현재 관찰을 진행하면서 과거 TXT를 열어 볼 수 있습니다.

읽을 수 있는 파일은 로컬 드라이브의 UTF-8 관찰 TXT입니다.
BOM이 있는 UTF-8과 Windows 줄바꿈을 지원합니다.
최대 256 KiB, 721개 표본, 2시간 범위이며 원래 관찰 기록의 시간 순서와 표본 요약을 검사합니다.
잔량을 알 수 없거나 읽기 오류가 있는 표본, 긴 갱신 간격은 그래프의 공백으로 표시합니다.
파일이 손상됐거나 형식이 다르면 오류 안내를 표시합니다.
다른 파일을 여는 데 실패하거나 파일 선택을 취소해도 이전에 열었던 기록을 볼 수 있습니다.

기존 마우스 클릭·키보드 표본 선택은 사용자 실기로 확인했습니다.
0.2.3의 실제 Windows 파일 선택창·저장 기록 화면·스크린 리더 동작은 실기 확인 전입니다.
디지털 서명이 없는 배포본입니다.
