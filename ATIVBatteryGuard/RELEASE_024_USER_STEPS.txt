ATIV Battery Guard 0.2.4 — 미저장 관찰 보호와 최근 기록 목록

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. 관찰 기록이 생긴 뒤 새 관찰 시작·관찰 지우기·앱 종료를 요청하면
   저장 확인이 필요한 경우 확인 창이 나타납니다.
   예를 누르면 관찰을 중단하고 최종 TXT를 저장한 뒤 요청한 작업을 진행합니다.
   아니요를 누르면 저장 없이 작업을 진행합니다.
   취소를 누르면 현재 관찰 기록을 유지합니다.
3. 기록 중에 한 번 저장했더라도 종료 시 최종 상태의 저장을 확인합니다.
   중단된 기록의 현재 내용이 이미 저장됐거나 표본이 없으면 확인 창을 생략합니다.
4. 저장에 실패하면 새 관찰 시작·지우기·종료를 중단하고 기록을 보관합니다.
   관찰은 중단된 상태이므로 오류 안내를 확인하고 저장을 다시 시도할 수 있습니다.
5. 저장된 관찰 기록 아래의 ‘최근 저장·열기 기록’을 펼칩니다.
   저장하거나 정상적으로 열었던 파일을 최근 순서로 최대 10개 표시합니다.
   파일명·표본 수·마지막 경과 시간·저장 당시 관찰 상태를 확인합니다.
6. 목록에서 항목을 선택하고 ‘선택 기록 열기’를 누릅니다.
   파일을 다시 읽고 검증한 뒤 기존 과거 기록 그래프로 표시합니다.
   키보드와 마우스로 표본을 선택할 수 있습니다.
7. 앱을 다시 실행해도 최근 목록을 사용할 수 있습니다.
   파일이 이동·삭제됐으면 오류 안내를 표시합니다.
   ‘관찰 TXT 열기’로 파일의 현재 위치를 선택하면 새 위치를 최근 목록에 추가합니다.

최근 목록은 로컬 설정 폴더의 recent-observations.json에 파일 경로와 표본 요약을 저장합니다.
목록 갱신에 실패하면 별도 안내를 표시하며 완료된 TXT 저장 결과를 보존합니다.
현재 관찰과 과거 그래프의 기본 동작은 기존 사용 순서대로 이용할 수 있습니다.

0.2.3의 과거 TXT 그래프 표시와 키보드·마우스 표본 선택은 사용자가 확인했습니다.
0.2.4의 실제 Windows 저장 확인 창과 최근 목록 화면은 실기 확인 전입니다.
디지털 서명이 없는 배포본입니다.
