# ATIV Battery Guard 0.2.5

2026-11-25 한국 시간. 두 관찰 TXT를 같은 경과 시간 축에서 비교하는 기능을 구현했습니다. 사용자가 확인한 0.2.4의 최근 목록 선택·그래프 열기 결과도 인계했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.5-WIN10-X64.zip) · [사용 순서](RELEASE_025_USER_STEPS.txt) · [검증 기록](reports/release-025-validation.json)

저장된 관찰 기록 화면에서 현재 연 TXT를 A로 사용하고 비교 TXT 열기로 B를 추가합니다. 두 그래프를 위아래에 표시하고 같은 가로축 범위를 적용합니다. 각 관찰 시작 후 경과 시간으로 비교하며 세로축은 0~100%입니다. 공통 범위는 두 파일의 마지막 경과 시간 중 큰 값이며 최소 60초입니다. 각 파일의 파일명·저장 당시 상태·표본 수·마지막 경과 시간·공백 수를 표시합니다.

각 그래프에서 점 클릭과 Tab·좌우 화살표·Home/End로 실제 표본을 선택합니다. 두 선택은 각각의 경과 시간·잔량·전원 연결·충전 상태를 표시합니다. 공통 축에서 그리기와 마우스 표본 판정은 같은 표시 범위를 사용합니다. 시간 축 변경은 이미 선택한 실제 표본을 유지합니다.

두 파일의 원래 표본 시각·잔량·공백·종료 상태를 보존합니다. 첫 표본이 관찰 시작보다 늦으면 그 경과 시간 위치에 그립니다. 짧은 기록은 마지막 실제 표본에서 끝나며 이후 구간은 비어 있습니다. 읽기 오류·잔량 미확인·긴 간격은 기존 그래프 모델의 연결선 중단을 사용합니다.

관찰 TXT 열기와 최근 목록은 A를 교체하고, 비교 TXT 열기는 B를 교체합니다. 취소·잘못된 파일·읽기 실패는 앞서 수용한 두 기록을 보관하고 안내를 갱신합니다. 비교 닫기는 B를 닫고 A의 축을 복원합니다. 기록 모두 닫기와 ViewModel 종료는 두 파일의 화면·메모리를 해제합니다. 파일 선택의 재진입과 종료 후 늦은 결과 게시를 차단합니다.

새 회귀 7개 포함 1186개 통과·실패 0개·건너뜀 0개입니다. 공통 축 클릭 좌표·짧은 기록의 끝·지연된 첫 표본·2시간 축 경계·축 변경 후 선택 유지·파일별 독립 선택·공백과 미확인 꼬리·종료 상태·취소/오류 복구·A/B 교체·동일 파일·닫기·종료 후 늦은 반환을 검사했습니다. 비교 중 현재 관찰 자료와 배터리 읽기·시각·제어 실행 횟수도 검사했습니다.

Portable Release 및 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개입니다. Windows GUI self-test에는 두 그래프 바인딩·공통 축·키보드/좌표 선택·비교 닫기 후 축 복원 검사를 추가해 컴파일했습니다. 이번 Linux 환경에서 실제 Windows 비교 화면과 입력 장치 조작은 실행하지 않았습니다.
