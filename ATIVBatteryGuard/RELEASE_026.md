# ATIV Battery Guard 0.2.6

2026-11-25 한국 시간. 기록별 관찰 메모를 저장하고 최근 목록과 A/B 비교 화면에서 확인·편집하는 기능을 구현했습니다. 사용자가 확인한 0.2.5의 A/B 비교 결과도 인계했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.6-WIN10-X64.zip) · [사용 순서](RELEASE_026_USER_STEPS.txt) · [검증 기록](reports/release-026-validation.json)

저장 기록 A와 비교 기록 B의 파일 요약 아래에서 관찰 메모 편집을 펼칠 수 있습니다. 최대 1000자의 일반 텍스트와 줄바꿈을 지원합니다. 메모 저장과 다시 읽기 버튼, 글자 수, 수정 중·저장 결과 안내를 표시합니다. 저장한 메모는 그래프 위와 최근 목록에 최대 120자 미리보기로 표시합니다. 같은 기록을 A와 B에 열면 같은 편집 상태를 공유합니다.

파일 교체·B 닫기·전체 기록 닫기·앱 종료 시 저장하지 않은 메모를 검사합니다. 저장 후 진행·저장 없이 진행·취소를 선택하며, 기본 선택은 취소입니다. 저장 실패 시 작업을 중단하고 초안을 보관합니다. 뒤의 메모나 현재 관찰 종료 확인에서 취소해도 앞서 저장 없이 진행을 골랐던 초안을 보관합니다. 같은 기록을 다시 열거나 A/B 중 한쪽만 닫을 때는 남아 있는 편집 상태를 사용합니다. 수정 중인 초안이 없으면 재열기에서 최신 저장 메모를 읽습니다. 요청이 중단되면 기록 화면에도 안내합니다.

메모는 로컬 데이터 폴더의 observation-notes에 JSON으로 저장합니다. 식별 키는 파일 위치와 UTF-8 TXT 내용에서 계산하며, BOM과 줄바꿈 차이를 정규화합니다. 다른 위치의 파일이나 내용이 바뀐 파일은 별도의 기록으로 연결합니다. 메모 저장소는 최근 10개 목록과 독립적으로 보관합니다.

저장은 기록별 파일 잠금·수정 버전 검사·임시 파일과 원자적 교체를 사용합니다. 다른 창이 먼저 저장한 경우 충돌을 안내하고 현재 초안을 유지합니다. 손상·미지원 버전·크기 초과 메모는 원본을 보존하고 안내합니다. 기존 최근 목록 형식에는 선택적 메모 식별 키를 추가했으며 기존 항목을 읽고 파일을 다시 열어 연결할 수 있습니다.

새 회귀 15개 포함 1201개 통과·실패 0개·건너뜀 0개입니다. Unicode·줄바꿈·재실행 후 복원·메모 비우기·TXT 바이트 보존, 위치/내용 식별·최근 목록 제한 이후 보관·기존 목록 호환·수정 충돌·잠금·내용 제한·손상 파일을 검사했습니다. 최근 목록 미리보기, A/B 독립/공유 편집, 교체·닫기 취소·실패·재시도, 같은 기록 재열기·충돌 후 다시 읽기·읽기 실패 복구·종료 후 늦은 반환과 현재 관찰/실행 횟수도 검사했습니다.

Portable Release 및 전체 net48 WPF/XAML Release 빌드는 각각 경고 0개·오류 0개입니다. Windows GUI self-test에는 메모 바인딩·저장·최근 목록 미리보기·A/B 편집·닫기 취소·재열기 검사를 추가해 컴파일했습니다. 이번 Linux 환경에서는 실제 Windows 메모 UI와 확인 창을 실행하지 않았습니다.

제품 변경 파일은 새 ObservationNoteStore와 ObservationNoteViewModel, 메모 식별을 포함하는 SavedBatteryObservation 및 최근 항목, IUserInteraction·LocalUserInteraction, MainViewModel, XAML, WindowsSmokeTest와 버전 상수입니다. 테스트·패키징·사용 안내·인수인계도 갱신했습니다. ZIP 9항목·프로그램 파일 6개·GUI 버전 0.2.6.0/0.2.6·내부 SHA·CRC·빌드 바이트 일치를 검증했습니다.

다음 확인 항목은 실제 Windows에서 메모 입력·저장·다시 열기, A/B 메모와 최근 목록 미리보기, 수정 중인 메모의 닫기 확인입니다. 후속 개선 후보는 TXT와 메모를 함께 보관하는 내보내기·불러오기 기능입니다.
