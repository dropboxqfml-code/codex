ATIV Battery Guard 0.2.6 — 기록별 관찰 메모

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP 하나를 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. 저장된 관찰 TXT를 열거나 최근 목록에서 선택해 엽니다.
3. 파일 요약 아래의 ‘관찰 메모 편집’을 펼칩니다.
4. ‘보호 켜기 후 관찰’, ‘보호 해제 후 관찰’처럼 당시 상황을 최대 1000자로 적습니다.
   줄바꿈을 사용할 수 있습니다.
5. ‘메모 저장’을 누르면 로컬에 보관하고 최근 목록과 그래프 위에 미리보기를 표시합니다.
   메모를 수정하는 동안에는 ‘메모 수정 중’으로 표시합니다.
6. A/B 비교 화면에서는 각 기록의 메모를 편집할 수 있습니다.
   같은 파일과 내용의 기록을 A와 B에 열면 같은 메모를 사용합니다.
7. ‘메모 다시 읽기’를 누르면 저장된 내용을 다시 불러옵니다.
   다른 창이 먼저 메모를 저장했으면 변경 충돌을 안내하고 현재 입력을 보관합니다.
   최신 내용을 읽을 때 저장 확인 창에서 저장 없이 진행을 선택할 수 있습니다.
8. 기록 교체·비교 닫기·기록 모두 닫기·앱 종료 시 수정 중인 메모의 저장 여부를 확인합니다.
   예는 저장 후 진행, 아니요는 저장 없이 진행, 취소는 현재 메모 유지입니다.
   저장에 실패하면 요청한 작업을 중단하고 입력한 내용을 보관합니다.
9. 메모를 지우려면 입력 내용을 비우고 ‘메모 저장’을 누릅니다.

메모는 앱 로컬 데이터 폴더의 observation-notes에 보관합니다.
기록의 파일 위치와 TXT 내용을 기준으로 연결합니다.
TXT를 다른 위치로 옮기거나 내용을 바꾸면 별도의 기록으로 연결합니다.
최근 목록의 10개 제한을 넘어가도 메모 파일은 보관하며, 같은 기록을 다시 열면 불러옵니다.
이전 버전의 최근 목록 항목은 파일을 다시 열어 메모 연결을 갱신합니다.

기존 A/B 비교 동작은 사용자가 확인했습니다.
0.2.6의 실제 Windows 메모 편집·저장·확인 창과 최근 목록 미리보기는 실기 확인 전입니다.
디지털 서명이 없는 배포본입니다.
