# ATIV Battery Guard 0.2.7

2026-11-25 한국 시간. 관찰 TXT와 메모를 하나의 `.ativrecord` 파일로 내보내고, 새 위치에서 함께 복원하는 기능을 추가했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.7-WIN10-X64.zip) · [사용 순서](RELEASE_027_USER_STEPS.txt) · [검증 기록](reports/release-027-validation.json)

저장된 기록을 연 뒤 ‘이 기록 TXT·메모 내보내기’를 누릅니다. B에는 별도의 내보내기 버튼이 있습니다. 내보내기는 화면에서 연 TXT의 검증된 원문과 현재 입력한 메모를 사용합니다. 원본 TXT가 이후 이동·수정·삭제돼도 표시한 자료를 내보내며, 입력 중인 메모를 포함해도 로컬 메모의 미저장 상태는 유지합니다. 메모 읽기에 실패한 경우 빈 메모로 잘못 내보내지 않도록 차단합니다.

‘TXT·메모 묶음 불러오기’와 ‘비교 묶음 불러오기’는 검증한 TXT와 메모를 앱 로컬 데이터 폴더 `imported-observations/<새 식별자>/`에 복원합니다. TXT 파일명을 보존하고 새 위치·내용에 메모를 연결합니다. 같은 파일명이나 같은 묶음도 매번 독립된 위치에 복원합니다. 최근 목록·미리보기·A/B 그래프·기존 키보드/마우스 선택과 연결됩니다. 기존 화면의 미저장 메모 확인을 통과한 뒤 복원하며, 취소·실패 시 기존 그래프와 초안을 보존합니다.

묶음은 버전 1의 단일 UTF-8 JSON 문서이며, TXT 원문·파일명·메모·각 내용의 SHA-256을 담습니다. 원본 전체 경로와 로컬 메모 식별 키를 전송하지 않습니다. 최대 2 MiB, 깊이 8, 필수 멤버·형식·버전·해시·파일명·TXT 표본과 요약·메모 한도를 검증합니다. 문서 뒤의 추가 내용, 손상 UTF-8, 중복 필수 필드, 잘린 파일, 경로 탈출·절대 경로·예약 파일명·스트림 이름을 거부합니다. 내부 경로를 추출하는 압축 형식은 사용하지 않습니다. 해시는 손상 검사용이며 작성자 인증·전자서명·암호화를 제공하지 않습니다.

내보내기는 새 임시 파일에 쓰고 flush한 뒤 새 파일로 이동하며 기존 대상을 교체하지 않습니다. 불러오기는 새 폴더에서 TXT를 준비하고 메모 저장 성공 후 폴더를 게시합니다. 실패하면 해당 작업의 임시 자료를 정리하고, 메모는 잠금과 수정 버전 확인으로 해당 작업이 저장한 내용만 되돌립니다. 동시 수정이나 정리 실패 시 다른 자료를 삭제하지 않으며 원본 묶음으로 재시도할 수 있습니다. 강제 종료·장치 오류 중의 전원 차단 복구까지 보증하는 방식은 아니며 해당 경우의 안정화 점검은 0.2.8에서 이어갑니다. 최근 목록 갱신 실패는 완료한 복원 결과를 유지하고 별도 안내합니다.

새 회귀 18개를 포함해 1219개 통과·실패 0개·건너뜀 0개를 확인했습니다. 다른 데이터 폴더에서 내보내기·복원·최근 목록 재열기·재내보내기, BOM/CRLF 원문 바이트, Unicode·빈 메모·최대 크기, 입력 위조·재계산 해시·추가 문서·링크 경로, 이름 충돌·메모 저장 실패·재시도·수정 충돌 보호를 검사했습니다. ViewModel의 A/B 복원·초안 내보내기·미저장 상태·취소·실패·공유 메모·늦은 반환·종료와 재진입 차단도 확인했습니다. 기존 관찰 표본·시계·장치 호출 횟수는 유지되는 것을 검사했습니다.

Portable Release 및 전체 net48 WPF/XAML Release 빌드는 경고 0개·오류 0개입니다. Windows GUI self-test에는 새 버튼의 내보내기·불러오기·B 비교·취소 후 초안 보존 검사를 추가해 컴파일했습니다. 이번 Linux 환경에서 Windows GUI self-test와 실제 Windows 파일 대화상자는 실행하지 않았습니다. 실제 OEM·펌웨어 작업은 0회입니다. ZIP의 9항목 구성·GUI 버전·내부 해시·CRC·빌드 바이트 일치를 검증했습니다.

제품 변경 파일은 새 ObservationBundle, 원문과 내부 경로를 보관하는 SavedBatteryObservation, 가져오기 취소용 메모 수정 버전 처리, IUserInteraction·LocalUserInteraction, MainViewModel·ObservationNoteViewModel, XAML·WindowsSmokeTest와 버전 상수입니다. 테스트·패키징·사용 안내·개발 인계 문서도 갱신했습니다.

다음은 0.2.8의 기존 기능 전체 보안 검토·안정화·사용 편의성 개선입니다. 실제 Windows에서 묶음 내보내기 → 다른 위치에서 불러오기 → 메모 복원 → 최근 목록 → A/B 비교를 우선 확인하고, 권한 경계·저장 오류·동시 수정·한글 입력·키보드·고배율 화면을 점검합니다. 기존 충전 시험과 재부팅 유지 결과는 개발 근거로 인계합니다.
