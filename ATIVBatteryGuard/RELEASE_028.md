# ATIV Battery Guard 0.2.8

2026-11-25 한국 시간. 사용자가 확인한 0.2.7의 .ativrecord 저장·불러오기를 인계하고, 보안·저장 안정성·기록 화면 사용성을 개선했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.8-WIN10-X64.zip) · [사용 순서](RELEASE_028_USER_STEPS.txt) · [품질 검토](QUALITY_028.md) · [검증 기록](reports/release-028-validation.json)

설정·메모·최근 목록·묶음의 JSON 검사를 공통화했습니다. 문서 뒤에 붙은 추가 내용, 잘못된 UTF-8·깊이·중복 필수 필드를 거부하고, 기존 BOM·공백·스키마를 지원합니다. 원래 경로의 네트워크 접두사를 정규화 전에 검사하고 스트림·예약 이름·Windows의 별칭 파일명 처리도 강화했습니다.

설정 파일에 앱 간 잠금과 읽은 바이트의 수정 버전 확인을 추가했습니다. 여러 창의 변경이나 외부 수정·삭제를 오래된 창이 덮어쓰지 않습니다. 유효한 기존 설정은 잠금/권한 오류에서도 읽기 전용으로 불러옵니다. 손상 설정 복구는 잠금 안에서 수행하고 원본을 별도 파일로 보관합니다.

복원할 TXT·메모를 쓰기 전에 import-recovery.ativrecord를 준비하고 flush합니다. 복원 중단 폴더가 남으면 최근 기록 안내에서 재가져오기 위치를 알려 주며 자동 삭제하지 않습니다. 이 복구본을 새 위치에 불러와 TXT와 메모를 함께 복원할 수 있습니다. 정상 완료에서는 임시 복구본을 정리합니다. 실제 전원 차단 시험 결과나 여러 파일의 완전한 원자성 보증은 아닙니다.

메모 저장과 최근 목록 갱신 후 선택한 기록을 유지합니다. A/B와 최근 목록에는 같은 파일명을 구별할 수 있는 짧은 기록 표시를 추가했습니다. 메모가 비었거나 저장된 내용으로 되돌아온 경우에도 상태를 계속 표시합니다. 수동 제어·관찰 오류의 기존 고정 로그 코드는 분류를 유지하고 임의 개인정보 문자열은 제외합니다.

새 17개 포함 1236개 회귀 통과·실패/건너뜀 0입니다. 원본 보존·구버전 호환·설정 충돌/잠금/읽기 전용·경로 검증·선택/구분 표시·메모 상태·복구본 재가져오기·로그와 100회 반복 열기/비교/저장/닫기를 검사했습니다. Portable 및 전체 net48 WPF/XAML Release는 경고 0개·오류 0개입니다. 컴파일 소스 207파일의 지정한 HTTP/소켓 API 검색은 0건이며, 현재 GUI/helper 권한·IPC·명시적 요청·상태 분리·자원 정리 경계를 검토했습니다. 상세 범위와 한계는 품질 검토 문서에 구분했습니다.

Windows self-test에 최근 선택과 같은 이름 A/B 표시 검사를 추가해 컴파일했습니다. 이번 Linux에서 실제 Windows GUI·IME·고배율·Defender 검사와 전원 차단 시험은 실행하지 않았습니다. 실제 OEM·펌웨어 작업은 0회입니다. 디지털 서명이 없는 개발 ZIP이며, 9항목 구성·프로그램 6파일·GUI 버전·내부 해시·CRC·빌드 바이트를 확인했습니다.
