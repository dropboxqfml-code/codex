ATIV Battery Guard 0.2.8 — 보안·안정성·사용 편의성 개선

Windows 10 x64 / .NET Framework 4.8
기존 확인 모델 Samsung 940X3G/930X3G, BIOS P05ACJ 대상

1. ZIP을 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
   기존 로컬 TXT·메모·최근 목록은 계속 사용합니다.
2. ‘관찰 TXT 열기’나 최근 목록에서 기록을 엽니다.
   메모를 저장해도 최근 목록의 선택 항목을 유지합니다.
3. 같은 이름의 기록을 A/B로 열면 파일명 아래의 ‘기록 구분’을 확인합니다.
   같은 파일 위치·내용이면 같은 표시이고, 다른 위치/복원 기록이면 다른 표시입니다.
   이 표시는 화면 구분용이며 작성자나 장치를 인증하지 않습니다.
4. 메모 편집에서 비어 있음·저장된 내용과 같음·수정 중 안내를 확인합니다.
   메모를 수정했다가 원래 저장 내용으로 되돌리면 불필요한 저장을 요구하지 않습니다.
5. ‘이 기록 TXT·메모 내보내기’와 B의 내보내기는 현재 입력한 메모를 포함합니다.
   로컬 메모의 미저장 상태는 유지하므로 필요하면 ‘메모 저장’을 별도로 누릅니다.
6. ‘TXT·메모 묶음 불러오기’와 ‘비교 묶음 불러오기’로 .ativrecord를 엽니다.
   기존 파일을 교체하지 않고 새 위치에 복원합니다.
   취소나 저장 실패 시 기존 그래프·입력한 메모와 원본 묶음을 보관합니다.
7. 여러 창에서 사용자 희망 설정을 저장하면 오래된 창의 덮어쓰기를 차단합니다.
   다른 창의 저장 완료를 확인한 뒤 해당 창을 다시 열어 최신 설정으로 작업합니다.
   설정 잠금/권한 문제에서도 유효한 기존 선택은 읽기 전용으로 보여 줍니다.
   사용자 희망 설정 저장은 실제 하드웨어 적용과 별도입니다.
8. 복원 중단 자료 안내가 있으면 ‘관찰 저장 폴더 열기’를 누릅니다.
   imported-observations의 .import- 폴더에 있는 import-recovery.ativrecord를
   ‘TXT·메모 묶음 불러오기’로 열어 새 위치에 다시 복원할 수 있습니다.
   중단 자료는 자동 삭제하지 않습니다. 정상 완료한 복원의 임시 복구본은 정리합니다.
   0.2.8부터 복구본을 준비하며, 이전 버전의 중단 자료는 원본 묶음으로 다시 시도합니다.
9. 실패하면 원본 자료를 보관하고 로컬 공간·파일 잠금·읽기/쓰기 권한을 확인합니다.
   이미 있는 내보내기 파일은 다른 이름으로 저장합니다.

묶음은 TXT 본문·파일명·메모를 담은 일반 텍스트 JSON입니다.
개인 내용을 공유하기 전에 확인합니다. 암호화·작성자 인증 형식은 아닙니다.
묶음 2 MiB, TXT 256 KiB/721표본/2시간, 메모 최대 1000 UTF-16 코드 단위입니다.
설정·메모·최근 목록·묶음의 손상/추가 문서/비정상 UTF-8과 잘못된 로컬 경로를 검사합니다.
손상 메모·최근 목록은 원본을 보존하며 손상 설정은 별도 원본 복사본을 남깁니다.
여러 파일의 저장과 저장장치 오류/전원 차단을 완전히 보증하지 않으므로 원본 묶음을 보관합니다.

0.2.7의 .ativrecord 저장·불러오기는 사용자가 확인했습니다.
0.2.8의 Windows 새 표시·선택 유지·복구 안내, 한글 IME·고배율·Windows 보안 검사는 확인 전입니다.
기존 충전 시험을 반복할 필요는 없습니다. 작업 중인 helper를 강제로 종료하지 않습니다.
디지털 서명이 없는 개발 배포본입니다.
