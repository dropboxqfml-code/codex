# ATIV Battery Guard 0.2.9

2026-11-25 한국 시간. 940X3G 사용자와 처음 실행하는 사람을 기준으로 화면과 문구를 정리하고 기능을 분류했습니다.

[프로그램 ZIP](../downloads/ATIVBatteryGuard-0.2.9-WIN10-X64.zip) · [사용 순서](RELEASE_029_USER_STEPS.txt) · [기능 분류·화면 설계](USABILITY_029.md) · [검증 기록](reports/release-029-validation.json)

기본 배터리 탭에는 현재 잔량·전원·충전 상태와 충전 제한 확인/80%/해제만 중심으로 표시합니다. 첫 사용에는 상태 확인부터 안내하고 장치 확인 전 설정 차단을 유지합니다. 기록·메모·A/B 비교·TXT와 묶음 이동은 기록 탭에, 사용 예와 읽기 전용 진단은 도움말·진단 탭에 모았습니다. 상세 결과와 진단/로그는 필요할 때 펼칩니다.

실제 제어에 반영되지 않는 희망값 저장과 재부팅 희망 옵션, 시뮬레이션·모의 적용, 과거 실험 결과 검토, 문의문 생성과 삼성 파일 조사 UI를 제외했습니다. 기존 자료와 설정 형식, 관련 개발 소스와 안전 회귀 검사는 보관합니다. 기본/상세 진단과 로그, 사용자가 확인한 기록 기능은 유지합니다.

모델 표기는 창·안내·관리자 확인·진단에서 940X3G로 정리했습니다. 원본 장치 식별값과 실제 모델/BIOS 검증·호출 제한·불확실 상태 차단은 유지합니다. 진단이 실제 제어를 일괄 미지원으로 설명하던 문구를 해당 진단은 설정을 변경하지 않는다는 정확한 안내로 바꿨습니다.

세 탭과 짧은 버튼명, 강조 버튼·일관된 간격·초점 테두리를 적용했습니다. 기존 창 크기와 글자·DPI 배치 보정을 유지하고 세 탭 모두 스크롤을 지원합니다. 최근 작업과 설정 오류 안내는 공통 하단에 표시합니다.

새 7개 포함 1243개 회귀 검사와 Portable/전체 net48 WPF/XAML Release 빌드를 수행합니다. 탭 이동이 장치/배터리/저장 동작을 시작하지 않는지, 모델 표시가 원본 검증과 분리되는지, 상태 안내와 기능 보존·UI 제외를 검사합니다. 실제 결과와 배포 ZIP의 버전·바이트·해시·CRC는 검증 기록에 저장합니다. Windows self-test는 새 화면에 맞게 수정·컴파일하며 이번 Linux에서 실행하지 않았습니다. 새 Windows 모양·키보드 초점·IME·고배율과 보안 검사는 별도 확인 항목입니다.

주요 변경은 MainWindow/App XAML, MainViewModel, 모델 표시와 진단 formatter, helper 확인 문구, WindowsSmokeTest, 버전·회귀·패키징·문서입니다. 하드웨어 검증/실행 코드의 변경은 없으며 클라우드 OEM·펌웨어 실행은 0회입니다.

다음은 새 화면의 Windows 사용 확인과 피드백 반영, 0.3.0의 품질·배포 검증입니다. 기존 충전 시험과 재시작 유지 근거를 인계합니다.
