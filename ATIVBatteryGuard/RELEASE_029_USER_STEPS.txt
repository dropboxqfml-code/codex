ATIV Battery Guard 0.2.9 — 940X3G용 화면과 사용 흐름 정리

Windows 10 x64 / .NET Framework 4.8 / Samsung 940X3G

1. ZIP을 새 폴더에 모두 풀고 ATIVBatteryGuard.exe를 일반 권한으로 실행합니다.
2. 기본 ‘배터리’ 탭에서 현재 잔량·전원·충전 상태를 봅니다.
3. 충전 제한의 ‘현재 설정 확인’을 먼저 누릅니다.
   Windows 관리자 확인과 장치 확인이 끝나면 설정 버튼을 사용할 수 있습니다.
4. 전원을 자주 연결해 쓴다면 ‘80% 충전 제한’을 선택합니다.
   외출 전에 더 충전하고 싶다면 ‘제한 해제’를 선택합니다.
   상태는 마지막 확인 결과이며 충전 속도·완료량은 배터리와 충전기 상태에 따라 달라집니다.
5. 오류가 있거나 작업이 끝나지 않았다면 표시된 안내를 확인합니다.
   작업 중인 앱/helper를 강제로 종료하거나 같은 동작을 반복하지 않습니다.
   필요하면 ‘작업 결과와 문제 해결’을 펼쳐 결과를 저장할 수 있습니다.
6. 배터리 변화를 그래프로 보고 싶으면 ‘기록’ 탭에서 ‘기록 시작’을 누릅니다.
   약 10초마다 최대 2시간 기록합니다. 끝나면 중단하고 ‘기록 TXT 저장’을 누릅니다.
7. 예전 자료는 ‘TXT 열기’나 최근 기록으로 엽니다.
   두 번째 TXT 또는 묶음을 열어 A/B 비교를 사용할 수 있습니다.
   그래프의 점을 클릭하거나 Tab으로 접근한 뒤 좌우 방향키로 표본을 확인합니다.
8. ‘메모 쓰기’를 펼쳐 입력하고 ‘메모 저장’을 누릅니다.
   다른 위치로 옮기려면 ‘기록·메모 함께 내보내기’를 선택합니다.
   .ativrecord 하나에 TXT와 현재 입력한 메모를 함께 담습니다.
   내보내도 로컬 메모의 미저장 상태는 유지합니다.
9. ‘기록·메모 불러오기’로 묶음을 열면 새 로컬 위치에 복원합니다.
   기존 기록·메모와 파일을 덮어쓰지 않습니다.
10. 문제가 계속되면 ‘도움말·진단’ 탭에서 사용 예를 읽고 ‘장치 정보 확인’을 누릅니다.
    진단 복사·저장을 사용할 수 있으며, 더 필요한 경우 ‘추가 진단과 로그’를 펼칩니다.
    진단은 충전 설정을 바꾸지 않고 결과를 자동 전송하지 않습니다.

희망값 저장·재부팅 복원 희망·개발용 시뮬레이션·과거 실험 검토·문의문 생성·삼성 파일 조사 화면은 제외했습니다.
기존 기록·메모·설정 파일은 보존합니다. 부팅 자동 제어나 서비스를 새로 설치하지 않습니다.
모델은 940X3G로 표시하며 실제 장치와 BIOS 검증은 계속 수행합니다.

묶음에는 TXT·파일명·메모가 들어가므로 공유 전에 내용을 확인합니다.
원본 묶음을 보관하고 저장 실패 시 공간·잠금·권한 안내를 확인합니다.
기존 충전·재부팅 유지 시험을 반복할 필요는 없습니다.
새 탭과 디자인의 실제 Windows 화면·한글 IME·고배율 확인은 남아 있습니다.
디지털 서명이 없는 개발 배포본입니다.
