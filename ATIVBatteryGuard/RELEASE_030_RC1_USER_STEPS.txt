ATIV Battery Guard 0.3.0-rc.1 — 실사용 검증판 1

Windows 10 x64 / .NET Framework 4.8 / Samsung 940X3G
정식 0.3.0 출시 완료판이 아닙니다.

0.2.11의 화면·충전 제어·기록·메모 동작을 유지하고 버전 표시만 바꿨습니다.
사용자가 0.2.11에서 글씨가 정상 표시된다고 확인한 결과를 인계합니다.

실사용 검증에는 별도의 VALIDATION-KIT ZIP을 이용하세요.
1. 검증 키트 ZIP을 새 로컬 폴더에 모두 풉니다.
2. ‘검증시작.cmd’를 일반 권한으로 실행합니다. 개발 도구 설치는 필요하지 않습니다.
3. 자동 검사 후 validation-results 폴더의 결과와 ‘실사용 검증 순서.txt’를 확인합니다.

일반 프로그램만 사용하려면 ATIVBatteryGuard.exe를 실행합니다.
배터리·기록·도움말/진단과 기존 파일 형식을 유지합니다.
기존 충전 제한/해제와 Windows 재시작 후 유지 시험을 반복할 필요는 없습니다.

Windows GUI 자동 검사·한글 IME·실제 파일 대화상자·고배율·반복 사용·보안 검사는
클라우드 Linux 빌드만으로 완료했다고 판단하지 않습니다.
검증판은 디지털 서명이 없으며 결과를 자동 업로드하지 않습니다.
