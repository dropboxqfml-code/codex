ATIV Battery Guard 0.3.0-rc.2 — 실사용 검증판 2

Windows 10 x64 / .NET Framework 4.8 / Samsung 940X3G
정식 0.3.0 출시 완료판이 아닙니다.

RC1 자동 검사에서 발견한 최근 기록 선택 유지 문제를 수정했습니다.
화면 디자인·충전 제어·설정과 기록 파일 형식은 유지합니다.

다음 확인은 별도의 RC2 VALIDATION-KIT ZIP을 사용합니다.
1. 새 로컬 폴더에 키트 ZIP을 모두 풉니다.
2. 검증시작.cmd를 일반 권한으로 실행합니다. SDK는 필요하지 않습니다.
3. validation-results의 새 validation-*.json과 gui-*.json 결과를 전달합니다.

이미 확인한 글씨·테두리·크기 변경 클릭과 메모 이동 결과는 인계합니다.
이전 충전 제한/해제·재시작 시험이나 수동 1·2·3을 반복할 필요는 없습니다.
일반 프로그램은 ATIVBatteryGuard.exe로 실행합니다.

이 검증판에는 디지털 서명이 없습니다. 첫 실행 경고가 나타날 수 있습니다.
Defender 검사와 게시자/Windows 평판 경고는 별도로 확인합니다.
Windows 보안 기능을 끄거나 예외를 추가하지 않습니다.
RC2의 실제 Windows 자동 검사 결과는 아직 확인하지 않았습니다.
