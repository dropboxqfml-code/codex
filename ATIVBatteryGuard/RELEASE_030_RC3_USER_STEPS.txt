ATIV Battery Guard 0.3.0-rc.3 — 한글 조합 중 닫기 취소 수정 후보

Windows 10 x64 / .NET Framework 4.8 / Samsung 940X3G
정식 0.3.0 출시 완료판이 아닙니다.

창을 닫기 전에 현재 메모 입력칸에 보이는 글자를 초안에 먼저 반영합니다.
저장 확인창 진입 때 실제 글자가 바뀌지 않은 Text 갱신 알림을 보내지 않습니다.
화면 디자인·충전 제어·기존 설정/기록/메모 형식은 유지합니다.

이번 확인에는 별도의 RC3 EXTENDED-CHECKS-v4 ZIP을 사용합니다.
새 로컬 폴더에 모두 풀고 닫기취소확인.cmd만 실행하세요.
이미 확인한 저장·재열기와 빠른/20분/충전 시험은 반복할 필요가 없습니다.

메모의 기존 글자를 Ctrl+A로 선택하고 '종료 취소 확인'을 직접 입력한 뒤
스페이스/엔터/방향키를 누르지 않고 바로 창의 X를 누릅니다.
저장 확인창은 검사 도구가 자동 취소합니다.
화면 안내의 직접 확인 항목을 선택하고 결과 저장 후 종료를 누릅니다.
startup-*.json과 ime-close-*.json을 전달합니다.

일반 프로그램은 ATIVBatteryGuard.exe로 실행합니다.
이번 수정의 실제 Windows IME 확인은 아직 남아 있습니다.
미서명 개발 후보이며 실제 서명/보안 검사·최종 출시는 완료하지 않았습니다.
