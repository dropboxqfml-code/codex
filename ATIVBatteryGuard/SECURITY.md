# 보안과 개인정보

## 로컬 실행과 권한

앱 실행 중 네트워크 통신을 사용하지 않습니다. 로그인, 클라우드 연결, telemetry, 업데이트 확인, 원격 오류 전송, 외부 웹뷰·이미지·CDN이 없습니다. 개발 도구·참조 어셈블리를 설치하는 빌드 환경의 통신과 배포 앱의 실행 동작은 별개입니다.

앱은 일반 사용자 권한으로 실행합니다. 서비스·자동 실행·작업 스케줄러·드라이버·시스템 정책을 자동 등록하거나 변경하지 않습니다. Secure Boot 해제, Defender 예외, 드라이버 서명 우회, 테스트 서명 모드를 요구하지 않습니다.

## 하드웨어 경계

실제 제어 어댑터는 미지원 상태이며 모든 쓰기 요청을 거부합니다. 미확인 EC/BIOS/SABI/ACPI/UEFI 명령, 임의 포트 I/O·물리 메모리 접근·메모리 패치·BIOS 플래시를 구현하지 않습니다. Linux의 유사 기능이 있다는 사실을 이 노트북의 Windows 제어 안전성 증거로 취급하지 않습니다.

`wsabi.dll`은 정적 분석 대상일 뿐 앱이 로드하거나 호출하는 종속성이 아닙니다. 특히 `CallBIOSInterface`/`CallSabiFunction`은 읽기 전용 진단으로 실행하지 않습니다.

새 삼성 WMI 진단은 정확한 클래스의 메타데이터만 읽습니다. 인스턴스를 열거해 값을 수집하거나 메서드를 호출하지 않습니다. 메타데이터 확인 결과로 하드웨어 제어를 활성화하지 않습니다.

## 저장과 수집

설정·로그·사용자가 생성한 진단 파일은 로컬 사용자 폴더에 저장합니다. 기본 진단은 모델·BIOS 버전·Windows 버전·아키텍처·배터리 상태와 조사에 필요한 인터페이스 정의만 수집합니다. 시리얼번호·사용자 이름·장치 고유 식별자를 기본 로그에 기록하지 않습니다.

**Settings 분석 파일 만들기**는 OEM 실행 파일·DLL 복사본이 포함되는 기능입니다. 포함 내용을 설명한 확인 창은 기본 선택이 아니요이며, 동의 전에는 이 추가 분석을 위한 설치 경로 탐색·파일 복사를 시작하지 않습니다. 앱의 기존 장치 진단 조회와는 별개의 실행 동작입니다.

설치 위치는 HKLM 32/64비트 제거 목록의 정확한 Samsung Settings 등록 항목과 삼성 게시자 정보를 사용해 확인합니다. 각 view에서 최대 1,024개 항목을 확인하고, 두 view 합계에서 일치하는 등록은 최대 4개까지만 처리합니다. `InstallLocation` 또는 엄격히 파싱한 `DisplayIcon`을 읽으며, 제거 명령을 실행하지 않습니다. DisplayIcon에는 EXE 경로와 선택적인 정수 아이콘 인덱스만 허용합니다. 유효한 InstallLocation이 있으면 하위 폴더의 DisplayIcon이 있더라도 원래 수집 기준 폴더를 유지합니다. 허용 범위는 Program Files, Program Files (x86), ProgramData 아래의 `Samsung\Settings` 또는 `Samsung\Samsung Settings` 전용 설치 폴더입니다. 사용자 폴더·공유 경로·시스템 폴더·큰 삼성 공용 폴더를 탐색하지 않으며, 리파스 경로·상위 경로 탈출·대체 데이터 스트림·장치 경로를 거부합니다.

탐색은 기준 폴더에서 최대 깊이 2, 폴더 최대 16개·항목 최대 512개·파일 후보 최대 128개로 제한합니다. 최종 복사본은 최대 16개, 파일별 최대 16 MiB, 합계 최대 24 MiB이며 결과 ZIP은 32 MiB 미만입니다. EXE·DLL만 분석 데이터로 복사하고, 같은 기본 파일 이름은 하나만 보관하므로 설치 파일 전체를 복제한 자료는 아닙니다. 새 Settings 모드는 삼성 회사 표시 정보와 제한된 PE 형식 검사에 모두 통과한 파일만 복사합니다. 기존 서비스 모드에서 확인된 특정 wsabi.dll 참조에 적용하던 데이터 복사 예외는 Settings 앱 모드에 적용하지 않습니다. 회사 표시 정보와 PE 검사는 후보 선별 근거이며 전자서명 신뢰·실행 안전성·충전 기능 지원 증명이 아닙니다. 설정 파일·로그·개인 문서는 별도로 복사하지 않습니다. 정확한 Samsung Settings 등록이 확인되고 설치·아이콘 경로가 모두 비었을 때만 기존 허용 범위의 전용 폴더 최대 6곳을 확인합니다. 제공된 경로가 거부되면 이 대체 조회를 하지 않습니다. 위치나 파일을 확인하지 못하면 원인만 담은 보고서 ZIP을 생성할 수 있습니다.

분석 보고서에는 전체 원본 경로·서비스 명령행·등록 키 식별자를 기록하지 않습니다. 생성한 자료를 자동 전송하지 않으며 사용자가 직접 내용을 확인한 뒤 필요한 상대에게만 전달합니다.

자체 앱 배포 ZIP과 소스 백업에는 삼성 파일 또는 사용자가 업로드한 진단 ZIP을 포함하지 않습니다. 배포 전 파일 목록과 해시를 확인합니다.

## 실패 처리

배터리 조회 실패는 알 수 없음으로, WMI 접근 거부·클래스 부재·조회 오류는 각각의 진단 결과로 처리합니다. 오류나 설정 파일 내용이 실제 하드웨어 적용 성공으로 바뀌는 경로를 허용하지 않습니다.
