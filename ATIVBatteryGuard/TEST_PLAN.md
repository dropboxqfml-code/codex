## 이번 자동 검사

기존 1236개에 사용자 화면 관련 7개를 추가해 portable 회귀 1243개를 등록합니다. 설정·Mock/Unsupported·진단·장치 전송/수명·수동 helper·관찰·그래프 선택·TXT·최근 목록·A/B·메모·묶음의 기존 검사를 함께 실행합니다. 최신 실행의 통과·실패·건너뜀은 위 JSON에 기록합니다.

기존 0.2.8 추가 범위는 메모/최근/설정의 추가 JSON·UTF-8·깊이·중복 필드 거부와 원본 바이트 보존, BOM·공백·기존 스키마 호환, 설정 동시 수정·삭제·잠금·읽기 전용 복구, 네트워크 접두사와 예약/스트림 이름, 같은 이름 기록의 구분, 최근 선택 유지와 항목 삭제, 한글 줄바꿈과 저장 상태, 진행 중 복원과 중단 자료의 구분·복구본 재가져오기·링크 차단·원본 유지, 고정 로그 코드와 개인정보 제외입니다. 100회 열기·비교·메모 저장·닫기 뒤 파일/잠금의 배타적 재열기와 최근 목록 크기도 확인합니다.

Linux 심볼릭 링크 사례를 실제 실행합니다. Windows에서 테스트용 링크 생성 권한이 없으면 새 사례의 일반 경로/폴더 검사를 유지하고 링크 생성 부분을 수행하지 않습니다. 테스트 때문에 관리자 권한·개발자 모드·보안 정책 변경을 요구하지 않습니다. 해당 플랫폼의 링크와 파일 시스템 행위는 별도 확인이 필요합니다.

```powershell
dotnet run --project tests/ATIVBatteryGuard.PortableTests.csproj -c Release -- --report reports/portable-tests.json
```

전체 솔루션의 실제 net48 WPF/XAML Release를 빌드합니다. Linux에서 WindowsDesktop SDK를 이용한 교차 빌드는 Windows 실행 결과를 대신하지 않습니다.


Windows 개발 환경에서 Visual Studio 2022의 .NET 데스크톱 개발·.NET Framework 4.8 targeting pack과 .NET 8 SDK를 준비한 뒤 실행할 통합 검사입니다.

## 새 Windows 사용 흐름 확인

1. 일반 권한으로 ZIP을 새 폴더에 풀어 실행하고 버전 0.2.9와 기존 기록·메모 복원을 확인합니다.
