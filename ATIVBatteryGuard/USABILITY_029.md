# 0.2.9 기능 분류와 사용자 화면 정리

2026-11-25 한국 시간. 940X3G를 사용하는 사람이 처음 실행해 충전 제한을 설정하고 필요할 때 기록과 진단을 찾는 흐름을 기준으로 검토했습니다. 화면 구현은 0.2.9이며 기존 0.2.8의 파일 보호와 설정 충돌·복구 기능을 인계합니다.

## 기능별 판단과 반영

| 분류 | 기능 | 이번 반영과 이유 |
| --- | --- | --- |
| 일상 사용 필수 | 현재 잔량·전원·충전 상태와 조회 오류 | 배터리 탭 상단에서 확인. 약 10초 갱신과 필요 시 새로 고침을 유지 |
| 일상 사용 필수 | 충전 제한 상태 확인·80% 제한·제한 해제 | 배터리 탭에서 바로 사용. 최초에는 상태 확인부터 안내하고 확인 전 설정 버튼 차단을 유지 |
| 안전에 필수 | 마지막 확인 시각·실패·작업 중/정리 미확인 안내·명시적 관리자 확인 | 계속 표시. 장치 검증과 종료/추가 작업 차단은 시각 정리와 함께 유지 |

| 사용 목적에 따른 보조 | 최근 목록·A/B 비교·메모·묶음 내보내기/불러오기 | 사용자가 확인한 기능이므로 기록 탭에서 모두 유지. 기존 파일과 메모 형식도 유지 |

| 일반 화면에서 제외 | 실제 제어를 바꾸지 않는 사용자 희망 모드와 저장 버튼 | 실제 80%/해제 버튼과 혼동할 수 있어 제거. 기존 로컬 설정 데이터는 보존 |
| 일반 화면에서 제외 | 동작하지 않는 재부팅 복원 희망 옵션 | 자동 제어 기능이 있다는 오해를 줄이기 위해 제거. 서비스/자동 실행을 새로 등록하지 않음 |
| 일반 화면에서 제외 | 개발용 시뮬레이션·모의 적용 | 실제 장치 사용에 필요하지 않아 제거. Mock/Unsupported의 안전 회귀 로직과 테스트는 유지 |
| 일반 화면에서 제외 | 과거 실험 결과 붙여넣기·검토 | 이미 끝난 개발 단계의 기술 도구이므로 제거. 기존 자료를 삭제하거나 재실험하지 않음 |
| 일반 화면에서 제외 | 공식 문의문 생성·삼성 파일/연결 조사 화면 | 평소 충전 제한·기록 사용에 필요하지 않아 제거. 기본/상세 진단과 로그를 문제 해결 수단으로 유지 |

이번 제외는 사용자 GUI의 진입점을 제거한 것입니다. 과거 파서·시뮬레이션·관련 안전 로직과 회귀 테스트는 개발 소스에 보관합니다. 검증된 하드웨어 경로나 사용자 자료를 삭제하는 작업은 포함하지 않습니다.

## 처음 실행할 때의 흐름

배터리 탭이 기본 화면입니다. 처음 사용한다면 안내에 따라 ‘현재 설정 확인’을 누르고, 결과가 확인되면 ‘80% 충전 제한’ 또는 ‘제한 해제’를 선택합니다. 장치 요청은 해당 버튼을 직접 누를 때만 실행하며, 탭 이동·도움말 보기·배터리 갱신으로 관리자 확인이나 제어를 시작하지 않습니다.

상태는 ‘마지막 확인’임을 표시합니다. 배터리 잔량을 보호 설정으로 바꾸어 보여 주지 않으며, 상한을 확인하지 못한 결과를 80%로 표시하지 않습니다. 지원 조건을 확인하지 못한 경우에는 도움말·진단으로 안내합니다. 긴 기술 수치와 결과 저장은 작업 결과와 문제 해결 안에 둡니다. 불확실한 정리 상태의 안내는 숨기지 않습니다.

기록 탭에는 현재 기록과 저장한 기록을 모았습니다. TXT와 .ativrecord 용도를 짧게 설명하고 버튼을 기록 시작/기록 TXT 저장/기록·메모 불러오기/함께 내보내기로 정리했습니다. 도움말에는 전원을 자주 연결하는 경우, 외출 전 더 충전하는 경우, 기록을 옮기는 경우를 예로 들었습니다. 기존 충전 시험이나 과거 자료 제출을 다시 요구하지 않습니다.

## 모델 표기와 진단 문구

창 제목·제품 안내·도움말·제어 안내·관리자 helper 확인·기본/상세 진단의 모델 표기를 940X3G로 정리했습니다. WMI에서 얻은 복합 모델 문자열은 내부 원본 Model 속성에 보존하며, 화면과 진단에는 별도 DisplayModel을 사용합니다. 대상과 다른 장치는 ‘940X3G 대상과 다름’, 미확인 장치는 ‘알 수 없음’으로 표시합니다. 다른 장치를 940X3G로 허용하지 않습니다.

실제 모델/BIOS 검사·고정 프로필 비교·요청별 제한·자원 정리·불확실 상태 차단의 코드는 변경하지 않았습니다. 사용자용 문구를 줄이는 일을 장치 식별 조건을 느슨하게 만드는 일로 연결하지 않습니다.

현재 기능과 모순되던 진단의 일괄 ‘실제 충전 제어 미지원’ 문구는 해당 진단이 충전 설정을 변경하지 않는다는 설명으로 수정했습니다. 장치 진단 자체를 지원 확인 또는 충전 제한 성공으로 승격하지 않습니다.

## 디자인과 접근성

배터리/기록/도움말·진단의 세 탭, 짧은 제목, 중요 동작의 파란 버튼, 차분한 배경과 카드, 일관된 버튼 모서리·간격을 적용했습니다. 기존 750×565 시작 크기·480×320 최소 크기·글자 크기·모니터/DPI 배치 보정은 유지합니다. 각 탭은 세로 스크롤을 지원하며 작업 안내와 설정 오류는 공통 하단에서 볼 수 있습니다. 접근 키·키보드 초점 테두리·UI Automation 이름과 기존 그래프 조작도 유지합니다.

## 검증과 남은 확인

새 7개 포함 1243개 회귀를 실행합니다. 모델 표시와 원본/쓰기 권한 분리, 진단 문구, 탭 이동 시 장치/배터리/저장 호출 없음, 첫 안내와 설정 전 조건·실패 안내·상한 미확인, XAML의 필수 기능 보존과 개발 UI 제외를 검사합니다. 기존 보호 제어·관찰·메모·묶음 회귀도 함께 실행합니다. 실제 실행 수와 빌드/ZIP 지문은 [검증 기록](reports/release-029-validation.json)에 남깁니다.

Windows self-test를 새 탭과 기존 기록/그래프/메모/진단 화면에 맞게 수정해 컴파일합니다. 없어진 Mock 버튼을 GUI 검사에서 찾지 않으며 Mock 동작과 기존 설정 호환은 portable suite에서 계속 검사합니다. 이번 Linux에서는 새 GUI의 실제 Windows 모양·초점 이동·한글 IME·고배율을 직접 확인하지 않았습니다. WPF/XAML 빌드 통과를 실제 화면 확인으로 기록하지 않습니다.

다음은 사용자가 새 배치와 기능 분류를 사용해 본 결과를 반영하고, 0.3.0의 Windows 품질 확인과 배포 검증을 준비하는 작업입니다.
