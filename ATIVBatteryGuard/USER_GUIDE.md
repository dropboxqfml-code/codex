# 사용 안내

ATIV Battery Guard는 현재 배터리 상태와 저장한 사용자 선택을 보여주고, 로컬 진단 자료를 만드는 프로그램입니다. **아직 실제 충전 상한을 80%나 100%로 바꾸지는 않습니다.**

## 이번에 할 일

새 배포 ZIP을 받으면 다음 순서로 진행하세요. 코딩 도구나 명령어 실행은 필요하지 않습니다.

1. ZIP 파일을 **새 폴더에 모두 압축 해제**합니다.
2. 풀린 폴더의 **ATIVBatteryGuard.exe**를 실행합니다. 함께 들어 있는 DLL과 구성 파일은 같은 폴더에 두세요.
3. 프로그램에서 **진단 파일 만들기**를 누릅니다.
4. 완료 후 **진단 파일 위치 열기**를 누릅니다.
5. 열린 폴더에서 가장 최근의 **`diagnostics-*.txt`** 파일을 이 채팅에 첨부합니다.

이번에는 **삼성 분석 ZIP을 다시 수집할 필요가 없습니다.** 새 진단은 이미 확인한 삼성 인터페이스의 정의를 읽어 결과를 기록합니다. 배터리 0%는 현재 노트북의 실제 상태로 표시해도 정상입니다.

## 화면 읽기

- **현재 배터리**: Windows가 알려준 잔량·외부 전원·충전 상태입니다. 현재 노트북의 0%는 사용자가 확인한 실제 상태로 표시합니다.
- **사용자 선택값**: 원하는 80% 보호 모드 또는 일반 100% 모드입니다. 선택을 저장하는 것과 실제 장치 적용은 다릅니다.
- **실제 하드웨어 상태**: 검증된 제어 인터페이스가 없어 미지원으로 표시됩니다. 저장한 선택값으로 바뀌지 않습니다.
- **시뮬레이션**: 화면과 모드 전환을 확인하는 개발용 기능입니다. 실제 충전에는 영향을 주지 않습니다.

앱은 일반 권한으로 실행합니다. 관리자 권한·드라이버 설치·보안 설정 변경은 필요하지 않습니다. 배터리 80%나 충전 중 아님 표시만으로 충전 제한이 작동했다고 판단하지 않습니다.

## 진단 자료

진단 만들기 기능으로 필요한 장치 정보와 삼성 인터페이스의 정의를 로컬 파일에 저장할 수 있습니다. 새 삼성 진단은 제어 함수를 실행하지 않고 클래스 이름·속성·메서드 정의를 확인합니다. 조회 결과가 발견됨이어도 충전 제한을 지원한다는 뜻은 아닙니다.

진단 파일은 자동 전송하지 않습니다. 파일 위치 열기 기능으로 생성된 파일을 확인하고, 필요한 경우에만 사용자가 직접 전달합니다.

삼성 분석 파일 만들기 기능을 사용하는 경우에는 OEM EXE·DLL 복사본이 포함될 수 있다는 확인 내용을 먼저 읽으세요. 이 자료도 파일을 실행하거나 충전 설정을 변경하지 않으며, 자동으로 업로드하지 않습니다.

## 저장 위치

사용자 설정과 로컬 진단 자료는 `%LOCALAPPDATA%\ATIVBatteryGuard` 아래에 저장합니다. 설정을 기억하는 기능은 다음 부팅 때 펌웨어 충전 제한을 적용하는 기능이 아닙니다. 앱은 서비스·자동 시작 항목을 설치하지 않습니다.

복구된 소스의 WPF 빌드와 78개 portable 테스트는 통과했습니다. 새 빌드의 Windows 창 실행과 노트북의 실제 WMI 조회 결과는 위 절차로 확인해야 합니다. 실행용 ZIP과 소스 백업은 저장소의 해당 배포 브랜치 downloads 폴더에 함께 보관합니다.
