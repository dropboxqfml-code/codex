ATIV Battery Guard 0.3.1 사용자 매뉴얼
삼성 940X3G · Windows 10 x64 · 개인용
작성일: 2026-11-26

이 프로그램으로 배터리 상태를 확인하고, 충전 제한을 직접 설정하며,
배터리 변화 기록과 메모를 저장·비교할 수 있습니다.


1. 처음 실행하기

① ZIP 전체를 원하는 폴더에 압축 해제합니다.
② ATIVBatteryGuard.exe를 실행합니다.
③ 배터리 탭에서 ‘현재 설정 확인’을 누릅니다.
④ 확인된 상태를 보고 ‘80% 충전 제한’ 또는 ‘제한 해제’를 선택합니다.

EXE만 따로 옮기지 말고 함께 들어 있는 DLL·config 파일을 같은 폴더에
두세요. 프로그램은 .NET Framework 4.8 환경에서 실행합니다.
일반 사용에 CMD나 별도의 검사 프로그램은 필요하지 않습니다.

이 프로그램에는 코드 서명이 없습니다. SmartScreen 경고가 나타나면
전달받은 파일임을 확인한 뒤 ‘추가 정보 → 실행’으로 허용할 수 있습니다.
‘실행’ 버튼이 없다면 해당 PC의 정책을 확인해야 합니다.


2. 배터리 상태 확인하기

배터리 탭에는 다음 정보가 표시됩니다.

· 배터리: Windows에서 측정한 배터리 잔량
· 전원: 외부 전원 연결 상태
· 상태: 충전 중인지, 충전 중이 아닌지 등의 배터리 상태

정보는 약 10초마다 갱신됩니다. 직접 다시 읽으려면 ‘새로 고침’을 누르세요.
‘새로 고침’은 충전 제한 설정을 바꾸지 않습니다.
잔량이 80%이거나 ‘충전 중 아님’으로 표시된다는 사실만으로 충전 제한이
설정됐다고 판단하지 마세요. 충전 제한 상태는 아래의 ‘마지막 확인’을 봅니다.


3. 충전 제한 설정하기

현재 설정 확인
  장치의 충전 제한 설정을 읽습니다. 이 확인이 완료되면 지원 조건에 따라
  두 설정 버튼을 사용할 수 있습니다. 관리자 확인이 나타나면 자신이 선택한
  동작인지 확인하고 진행합니다.

80% 충전 제한
  전원을 자주 연결해 사용할 때 선택합니다. 현재 잔량을 강제로 80%까지
  방전시키는 기능은 아닙니다.

제한 해제
  배터리를 더 충전하고 싶을 때 선택합니다. 실제 최종 충전량과 충전 속도는
  배터리·충전기 상태에 따라 달라집니다.

버튼 색의 의미
  · 80% 제한이 확인되면 ‘80% 충전 제한’ 버튼이 파란색입니다.
  · 제한 해제가 확인되면 ‘제한 해제’ 버튼이 파란색입니다.
  · 미조회·처리 중·확인 실패 상태에서는 어느 쪽도 강조하지 않습니다.
  · 제한이 켜져 있어도 구체적인 설정값이 확인되지 않았거나 다른 값이면
    80% 버튼을 강조하지 않습니다. 이때는 상태 요약의 문구를 확인하세요.

파란색은 마지막으로 확인한 설정을 뜻합니다. 실시간으로 장치 설정을
계속 조회하는 표시는 아닙니다. 다시 확인하려면 ‘현재 설정 확인’을 누르세요.
절전 복귀 등으로 확인값이 무효화된 경우에도 다시 확인합니다.

작업이 진행 중이면 끝날 때까지 기다립니다. 같은 버튼을 반복해서 누르지
않아도 됩니다. 결과가 불명확하면 ‘작업 결과와 문제 해결’을 펼쳐 확인하세요.
‘작업 결과 저장’으로 해당 결과를 TXT에 보관할 수 있습니다.

앱을 실행하거나 종료하는 것만으로 충전 설정을 자동 변경하지 않습니다.
종료하거나 프로그램 폴더를 삭제해도 설정이 자동으로 해제되지는 않습니다.
해제를 원하면 프로그램에서 직접 ‘제한 해제’를 선택하세요.
Windows 시작 시 자동 실행하거나 설정을 자동 적용하는 기능은 없습니다.


4. 배터리 변화 기록하기

① 기록 탭으로 이동합니다.
② ‘기록 시작’을 누르고 평소처럼 노트북을 사용합니다.
③ 필요한 만큼 기록한 뒤 ‘기록 중단’을 누릅니다.
④ ‘기록 TXT 저장’을 눌러 파일로 보관합니다.
⑤ ‘저장 폴더 열기’에서 저장한 TXT를 확인합니다.

기록은 약 10초 간격으로 모으며 최대 2시간입니다.
‘기록 중단’ 후에도 그래프는 남습니다. ‘기록 비우기’는 현재 창의 기록을
비우며, 이미 저장한 TXT 파일은 삭제하지 않습니다.
저장하지 않은 기록은 프로그램을 종료하기 전에 TXT로 저장하세요.
저장 확인 창이 나타나면 화면의 저장·저장 없이 진행·취소 중 하나를 선택합니다.
기록 기능은 충전 제한 설정을 바꾸지 않습니다.


5. 그래프에서 표본 확인하기

그래프의 가로축은 기록 시작 후 경과 시간, 세로축은 배터리 잔량(%)입니다.
그래프 아래에서 선택한 표본의 상세 정보를 확인할 수 있습니다.

마우스
  그래프를 클릭해 접근하고 데이터 점을 클릭해 표본을 선택합니다.

키보드
  Tab으로 그래프에 접근합니다. Shift+Tab으로 이전 항목으로 이동합니다.
  ← / → : 이전 / 다음 표본
  Home  : 처음 표본
  End   : 마지막 표본

값을 읽지 못한 구간은 빈 구간으로 나타날 수 있습니다. 그래프는 기록된
표본을 보여 주며, 빈 구간을 실제 측정값처럼 채우지 않습니다.


6. 저장한 기록 열기와 A/B 비교

· ‘TXT 열기’로 이 프로그램이 저장한 관찰 TXT를 엽니다. 먼저 연 기록은 A입니다.
· ‘최근 기록’을 펼쳐 목록에서 고른 뒤 ‘선택 기록 열기’를 눌러도 됩니다.
· ‘비교할 TXT 열기’로 두 번째 기록 B를 엽니다.
· ‘비교 닫기’는 B를 닫고, ‘열린 기록 닫기’는 열린 기록 화면을 닫습니다.

A와 B는 각 기록의 시작 후 경과 시간을 기준으로 비교합니다.
서로 다른 날에 기록했다면 같은 가로축 위치가 같은 실제 시각을 뜻하지는
않습니다. 각 그래프의 표본은 마우스와 키보드로 따로 선택할 수 있습니다.
열린 기록을 닫는 것은 원본 TXT 파일을 삭제하는 동작이 아닙니다.

최근 기록 목록은 최대 10개입니다. 목록에 없더라도 원본 TXT가 남아 있으면
‘TXT 열기’로 다시 열 수 있습니다. 파일을 이동했다면 새 위치에서 선택하세요.


7. 기록에 메모 남기기

① 저장된 기록 A 또는 B에서 ‘메모 쓰기’를 펼칩니다.
② 최대 1,000자까지 관찰 내용을 입력합니다. 줄바꿈도 사용할 수 있습니다.
③ ‘메모 저장’을 눌러 이 PC에 보관합니다.

A와 B의 메모는 각각 저장됩니다. ‘메모 다시 읽기’는 저장된 내용을 다시
불러옵니다. 수정 중인 내용이 있다면 확인 창의 안내를 읽고 선택하세요.
기록을 바꾸거나 창을 닫을 때 저장 여부를 묻는 경우에도 취소를 선택하면
편집을 계속할 수 있습니다.

메모는 TXT 본문에 직접 덧붙이는 방식이 아닙니다. TXT만 다른 위치로 옮기면
메모가 자동으로 따라가지 않을 수 있으므로, 함께 옮길 때는 다음 묶음 기능을
사용하세요.


8. 기록과 메모를 함께 보관하거나 옮기기

내보내기
  A: ‘기록·메모 함께 내보내기’
  B: ‘비교 기록·메모 내보내기’
  저장 위치와 새 파일 이름을 정하면 .ativrecord 파일 하나로 보관합니다.
  기존 파일을 덮어쓰지 않으므로 같은 이름이 있으면 다른 이름을 사용하세요.

불러오기
  A: ‘기록·메모 불러오기’
  B: A가 열린 상태에서 ‘비교할 묶음 불러오기’
  .ativrecord 파일을 선택하면 기록과 메모를 로컬 저장 공간으로 복원합니다.

입력 중인 메모도 내보낸 묶음에 포함됩니다. 다만 내보내기는 이 PC의
‘메모 저장’을 대신하지 않으므로, 로컬에도 보관하려면 메모 저장을 누르세요.
다른 위치에서 이어 보거나 백업할 때는 TXT와 메모를 각각 찾는 대신
.ativrecord 파일을 보관하는 방법이 편리합니다.


9. 저장 위치와 백업

화면의 ‘저장 폴더 열기’를 누르면 로컬 저장 공간을 볼 수 있습니다.
기본 위치는 다음과 같습니다.

  %LOCALAPPDATA%\ATIVBatteryGuard

설정, 관찰 TXT, 기록별 메모, 최근 기록 정보, 로그 등이 이 PC에 보관됩니다.
직접 내보낸 .ativrecord 파일은 내보낼 때 선택한 위치에 저장됩니다.
프로그램은 자료를 자동 업로드하지 않습니다.

중요한 기록은 .ativrecord로 내보내 별도 위치에도 보관하세요.
프로그램 ZIP은 실행 파일 묶음이며, 개인 기록을 백업한 파일은 아닙니다.
새 버전이나 매뉴얼 동봉본을 별도 폴더에 풀어도 같은 Windows 사용자 계정의
기존 로컬 자료를 계속 사용합니다. 자료를 유지하려면 저장 폴더를 지우지 마세요.


10. 문제가 있을 때

설정 버튼이 비활성화돼요
  ‘현재 설정 확인’을 먼저 누릅니다. 계속 사용할 수 없다면 표시된 안내를
  읽고 도움말·진단 탭의 ‘장치 정보 확인’을 실행합니다.

상태를 읽지 못했거나 작업 종료를 확인하지 못했다고 나와요
  같은 설정을 반복 요청하지 말고 표시된 상태와 ‘작업 결과와 문제 해결’을
  확인합니다. 필요한 경우 작업 결과를 저장해 원인을 확인할 때 사용하세요.

TXT나 묶음 파일을 열지 못해요
  이 프로그램에서 저장한 형식인지와 파일이 남아 있는지 확인합니다.
  파일을 임의로 편집했거나 저장이 중단됐다면 보관한 원본/백업을 사용하세요.

메모가 저장되지 않거나 충돌이 표시돼요
  창을 닫기 전에 입력한 메모를 복사하거나 기록·메모 묶음으로 보관합니다.
  다른 창에서 같은 기록을 편집 중인지 확인하고, 현재 입력을 보관한 뒤
  필요할 때 ‘메모 다시 읽기’로 저장된 내용을 확인합니다.

진단 결과를 남기고 싶어요
  도움말·진단 → ‘장치 정보 확인’ 후 ‘진단 복사’ 또는 ‘진단 저장’을 누릅니다.
  ‘최근 작업 로그’로 작업 기록을 볼 수 있습니다.
  진단은 충전 설정을 바꾸지 않으며, 저장·복사한 자료도 자동 전송하지 않습니다.

현재 0.3.1은 940X3G / Windows 10에서 개인 사용 검증을 마친 버전입니다.
문제가 없다면 별도의 검사 도구를 반복 실행하지 않고 그대로 사용하면 됩니다.
