ATIV Battery Guard 0.3.0-rc.2 — 남은 실사용 확인

기존 RC2 프로그램을 그대로 사용합니다. 재설치나 새 프로그램 다운로드는 필요 없습니다.
파일/GUI 자동 검사와 최근 기록 선택 유지 검사는 통과했습니다.
검증시작.cmd와 이전 충전 제한·해제·재시작 시험을 반복하지 않습니다.
개인 기록 대신 기존 예제 A/B를 사용합니다. 이 확인은 충전 설정을 바꾸지 않습니다.

1. 한글 조합 중 저장과 닫기 (약 2분)
- 기록 탭에서 예제 A를 열고 메모 쓰기를 펼칩니다.
- 한글 입력기로 '한글 조합 확인'을 직접 입력합니다. 붙여넣기만으로 대신하지 않습니다.
- 마지막 글자에 조합 표시가 남아 있는 상태에서 '메모 저장'을 클릭합니다.
- 기록을 닫았다 최근 기록의 같은 항목을 열어 마지막 글자가 빠지거나 중복되지 않는지 확인합니다.
- 메모에 새 한글을 입력한 직후 프로그램 창의 X를 누릅니다. 저장 확인에서 '취소'를 선택합니다.
- 창과 입력 내용이 유지되는지 확인합니다. 취소 후 원하는 메모를 저장합니다.
- 줄바꿈과 한글 붙여넣기도 한 번 확인합니다.
기대 결과: 마지막 글자·줄바꿈이 유지되고 취소하면 창과 초안이 남습니다.
메모는 1000자 제한이며 키보드 입력기 종류에 따라 조합 표시 모양은 다를 수 있습니다.

2. 미저장 메모 취소 (약 1분)
- A를 연 상태에서 비교 B도 엽니다. 두 메모를 서로 다른 내용으로 수정하고 저장하지 않습니다.
- 열린 기록 닫기를 누르고 저장 확인에서 '취소'를 선택합니다.
- A/B 그래프와 두 초안이 모두 남는지 확인합니다.
- 필요한 내용은 메모 저장으로 저장합니다.
기대 결과: 취소가 기록과 초안을 버리지 않습니다.

3. 두 창의 같은 기록 수정 충돌 (약 3분)
- ATIVBatteryGuard.exe를 한 번 더 실행해 창을 두 개 엽니다.
- 두 창의 최근 기록에서 같은 TXT를 엽니다. '기록 구분' 표시가 같은 항목을 선택합니다.
  같은 .ativrecord를 두 번 가져오면 다른 기록이므로 이 시험에 사용하지 않습니다.
- 두 창 모두 메모를 연 다음, 첫 창은 '첫 창 저장', 둘째 창은 '둘째 창 초안'으로 바꿉니다.
- 첫 창의 메모를 저장한 뒤 둘째 창의 메모 저장을 누릅니다.
- 둘째 창에 다른 창에서 변경됐다는 안내가 뜨고 '둘째 창 초안'이 남는지 확인합니다.
- 둘째 창에서 '기록·메모 함께 내보내기'로 새 이름의 .ativrecord를 저장해 초안을 보관합니다.
  이 내보내기는 로컬 메모의 저장 충돌을 해결하거나 '저장됨'으로 바꾸지 않습니다.
- 둘째 창의 '메모 다시 읽기'를 누르고 '취소'를 선택해 초안이 유지되는지 확인합니다.
- 초안을 파일에 보관한 뒤 다시 읽기에서 아니요(저장 없이 진행)를 선택합니다.
  이제 '첫 창 저장'이 보이는지 확인합니다.
- 필요한 내용을 합쳐 저장합니다. 원래 기록이나 기존 묶음 파일을 덮어쓰지 않습니다.
기대 결과: 뒤의 저장이 첫 창의 내용을 조용히 덮어쓰지 않고 초안을 보존합니다.

4. 반복·일반 사용 (20~30분, 다른 일을 하면서 진행 가능)
- 예제 열기 → A/B 비교 → 메모 저장 → 기록 닫기를 약 10회 수행합니다.
- 이후 프로그램을 20~30분 열어 두고 가끔 탭 전환·그래프 클릭·메모 입력을 합니다.
- 멈춤, 입력 지연, 저장 오류가 반복되는지 확인하고 실제 사용 시간을 적습니다.
- 작업 관리자로 메모리를 비교할 경우 시작/종료 시각의 대략적인 값만 적어도 됩니다.
  일시적 메모리 증가만으로 누수라고 판단하지 않습니다.
기대 결과: 반복할수록 응답성이 계속 나빠지거나 작업이 막히지 않습니다.

결과 전달
별도 '결과작성.txt'의 미실행 항목을 실제 결과에 맞게 바꿔 전달하면 됩니다.
문제가 있으면 단계 번호와 화면 메시지·재현 순서만 적습니다.
개인 기록·전체 경로·계정 정보·메모 본문을 전달할 필요는 없습니다.
이번 순서는 IME/실제 대화상자/일반 사용 확인이며 백신 검사나 서명 완료를 대신하지 않습니다.
기존 미서명 첫 실행 경고는 이미 기록되어 있어 다시 재현할 필요는 없습니다.
