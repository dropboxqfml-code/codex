ATIV Battery Guard 0.3.0-rc.2 — 이번 확인 순서

RC1 결과에서 최근 기록 선택 유지 자동 검사 오류를 발견해 수정했습니다.
이미 확인하신 수동 1·2·3, 현재 배율의 글씨·테두리, 창 크기 변경 후 클릭,
Defender 특이사항 없음 보고는 기록했습니다. 같은 시험을 다시 하지 않아도 됩니다.

이번에는 아래 자동 검사만 다시 실행하세요.
1. RC2 키트 ZIP을 쓰기 가능한 새 로컬 폴더에 모두 풉니다.
2. 검증시작.cmd를 일반 권한으로 실행합니다. SDK 설치는 필요하지 않습니다.
3. validation-results의 새 validation-*.json과 gui-*.json을 전달합니다.
   파일/버전/해시 → 임시 자료 GUI 검사 → 파일 재확인을 수행합니다.
   실제 충전 제어·관리자 helper 실행·정책 변경·자동 전송은 하지 않습니다.
   장치/배터리의 읽기 전용 조회는 포함될 수 있습니다.

RC2는 정식 출시 완료판이 아니며 Windows에서 수정 확인이 남아 있습니다.
미서명 검증판이므로 첫 실행 경고가 나타날 수 있습니다.
Defender 검사 결과와 게시자·Windows 평판 경고를 구분합니다.
보안 기능을 끄거나 예외를 추가하지 않습니다.

아래는 남은 실사용 검증을 위한 참고 순서입니다. 지금 모두 재실행하라는 뜻은 아닙니다.
정확한 배율 숫자·IME 조합 중 동작·취소/동시 수정 충돌·장시간 사용은 미확인입니다.

참고 — 기존 실사용 검증 순서

이 묶음은 0.3.0-rc.2 검증판입니다. 정식 출시 완료를 의미하지 않습니다.
0.2.11의 글씨 정상 표시와 이전 충전·재시작 유지 근거는 인계합니다.
같은 충전 시험을 다시 하거나 과거 자료를 다시 만들 필요는 없습니다.

먼저 할 일

1. ZIP을 다운로드/문서 등 쓰기 가능한 새 로컬 폴더에 모두 풉니다.
   ‘검증시작.cmd’를 더블클릭합니다. 일반 권한으로 실행하며 개발 도구는 필요하지 않습니다.
   앱 파일 확인 → 임시 자료의 GUI 자동 검사 → 검사 후 파일 확인을 수행합니다.
   자동 검사에서는 실제 충전 제어나 관리자 helper를 실행하지 않습니다.
   실제 장치 정보의 읽기 전용 조회는 포함될 수 있습니다.
   GUI 창이 잠시 나타났다가 닫히며 결과는 이 폴더의 validation-results에 새 JSON으로 저장합니다.
   ‘자동 검사 통과’도 아래 수동 사용 확인이나 Defender 검사를 완료했다는 뜻은 아닙니다.

2. ATIVBatteryGuard.exe를 실행해 ‘기록’ 탭을 엽니다.
   예제 폴더의 sample-a.ativrecord를 ‘기록·메모 불러오기’로,
   sample-b.ativrecord를 ‘비교할 묶음 불러오기’로 엽니다.
   두 예제는 실제 측정값이 아니며 파일명·메모에도 검증용으로 표시돼 있습니다.
   그래프·A/B·메모가 보이고 Tab/방향키와 마우스 클릭으로 표본을 선택할 수 있는지 확인합니다.

3. 예제 A의 메모를 ‘한글 입력 검증’과 ‘두 번째 줄’로 바꾸고 저장합니다.
   프로그램을 닫았다 다시 열어 최근 기록에서 같은 TXT를 선택합니다.
   저장한 글자가 유지되는지 확인합니다.
   ‘기록·메모 함께 내보내기’로 새 .ativrecord를 저장하고 다시 불러와도
   그래프와 메모가 같은지 확인합니다. 원본 파일을 덮어쓰지 않습니다.

추가 확인 — 처음 세 가지가 끝난 뒤 진행할 수 있습니다.

[ ] 현재 사용하는 Windows 배율에서 세 탭의 글씨·둥근 테두리가 정상이며 잘리지 않음
[ ] 창을 작게 줄여도 스크롤·Tab/Shift+Tab·그래프 선택이 가능함
[ ] 한글 조합 중/직후 클릭·저장·닫기와 줄바꿈·붙여넣기가 정상임
[ ] 미저장 메모의 닫기/교체에서 저장·저장 없이 진행·취소가 안내대로 동작함
[ ] 두 창에서 같은 TXT의 메모를 수정하면 뒤의 저장 충돌을 안내하고 초안을 유지함
    같은 묶음을 두 번 가져오면 별도 기록입니다. 동시 수정 확인은 최근 목록의 같은 TXT를 엽니다.
[ ] 일반 사용에서 열기·비교·저장을 반복해도 멈춤이나 지속적인 메모리 증가가 관찰되지 않음
[ ] Windows 보안에서 이 검증 폴더를 검사한 결과를 확인함
    사용 중인 보안 기능·정책을 끄거나 예외를 추가하지 않습니다.
    이 묶음의 자동 검사 도구는 Defender 검사를 실행하지 않으며 그 항목을 통과로 기록하지 않습니다.

자동 검사 결과를 확인할 때

validation-results의 validation-*.json에 파일/GUI 결과와 미확인 항목이 들어 있습니다.
해당 GuiReportFile의 gui-*.json에는 구체적인 GUI 검사 오류 코드가 들어 있습니다.
결과는 자동 전송하지 않습니다. 필요하면 결과와 간단한 사용 결과를 직접 전달할 수 있습니다.
파일이 다르거나 자동 검사가 실패하면 통과로 표시하지 않습니다.
GUI 검사 시간 초과에서도 도구는 창이나 프로세스를 강제로 종료하지 않습니다.
실제 충전 제어 중인 앱/helper를 강제 종료하지 않습니다.

현재 검증판에는 Authenticode 서명이 없습니다.
파일 해시는 같은 배포 파일인지 확인하는 수단이며 배포자 인증이나 악성 코드 부재 인증이 아닙니다.
수동 사용·보안 검증 결과와 남은 문제를 반영한 뒤 최종 0.3.0 출시 여부를 결정합니다.
