# Windows 10 실행 경고 현황

2026-11-26 한국 시간. 대상은 940X3G / Windows 10입니다. 사용자 보고:

- CMD 검사 실행 시 ‘알 수 없는 게시자’ 경고.
- EXE 실행 시 ‘인식할 수 없는 앱의 시작을 차단’ 안내.

후속 확인: 사용자가 **Microsoft Defender SmartScreen** 경고라고 확인했습니다. 현재 사용 범위는 본인 노트북 한 대입니다. [개인 사용 시 파일 확인과 실행 허용 절차](SMARTSCREEN_PERSONAL_USE.md)를 추가했습니다. 유료 인증서 구매를 개인 사용의 선행 조건으로 두지 않습니다. 실제 사용자 PC에서 경고 해소는 아직 확인하지 않았습니다.

현재 배포한 RC3 프로그램 및 검사 도구는 미서명 개발 검증판입니다. 코드 서명 인증서/서비스는 아직 보유하지 않았다고 답했습니다. 이번 작업에서 실제 서명·인증서 구매/발급·실행 차단 해소는 하지 않았습니다.

미서명 파일은 검증된 게시자를 표시할 수 없습니다. EXE 경고는 후속 사용자 답변에 따라 SmartScreen으로 기록합니다. 원문/버튼 유무는 아직 받지 않았으며, 별도로 보고한 CMD 게시자 경고까지 같은 종류라고 확정하지 않습니다. CMD 경고는 명령 프롬프트 자체가 미서명이라는 뜻으로 해석하지 않습니다. 실행한 검사 스크립트/자식 프로그램에서 표시했을 수 있습니다.

기존 Defender 검사에서 특이사항이 없었다는 사용자 보고와 게시자/평판 경고는 다른 근거입니다. 기능 검사 통과나 악성 코드 미탐지로 게시자 신원과 Windows 실행 허용이 보증되지는 않습니다.

## 사용 흐름과 남은 일

일반 사용은 압축을 푼 폴더의 ATIVBatteryGuard.exe 실행입니다. CMD는 검사 도구용이므로 평소 프로그램을 사용할 때 필요하지 않습니다. EXE를 직접 실행해도 현재 보고한 차단이 없어지는 것은 아닙니다. 기존 충전/IME/반복 검사를 다시 실행할 필요는 없습니다.

배포자 인증서/서명 서비스가 준비되면 EXE/DLL 4개에 정당한 코드 서명·타임스탬프를 적용하고, 서명된 동일 파일의 Windows 신뢰 상태·Defender·GUI를 검사합니다. 서명은 게시자 식별과 무결성 확인에 도움이 되지만 Windows 평판 경고의 즉시 해소나 모든 정책에서의 실행 허용을 보장하지 않습니다. 인증서가 개인적인 시험 사용의 필수 조건이라는 뜻은 아니며 실제 실행 가능 여부는 장치 정책에 따릅니다.

현재 경고는 미해결 상태로 기록합니다. Defender/SmartScreen 비활성화·예외 등록·정책/실행 정책 변경·서명 우회·임의 인증서 신뢰 등록을 해결 방법으로 적용하지 않았습니다. 자체 서명만으로 외부 게시자 신뢰나 앱 평판을 확보했다고 표시하지 않습니다. 인증서 구매나 외부 파일 전송도 수행하지 않았습니다.
