# 승인된 한정 WMI 조회 후보 실험 — 2026-11-03

**후속 준비 수정:** [Locator-v2 Ready 결과와 Query65-locator-v2](WMI_QUERY_LOCATOR_READY_RESULT.md)를 확인합니다. 이전 실험은 실제 후보 요청 전에 중단됐고 무호출 점검은 준비 전체를 통과했습니다. 같은 승인 범위를 완수하도록 경로 정보 옵션만 보완했으며 원래 요청·최대1회·동일 예약 표식은 그대로입니다. 새 후보/추가 횟수를 승인한 것으로 해석하지 않습니다. 아래는 최초 승인·구현 기록입니다.

사용자는 [검토서](WMI_ONE_SHOT_QUERY_REVIEW.md)의 범위 변경에 대해 다음과 같이 명시적으로 승인했습니다.

> 그래 이번 테스트를 위해서 승인할게. 반드시 필요한 작업만 수행하도록해. 노트북의 보안을 위해서 하드웨어 안전 규칙을 꼭 지켜야해.

이 승인은 별도 도구·같은 계정의 수동 관리자 실행·조회 후보0x65 최대1회에 한정됩니다. 현재 모델에서 명령 의미나 부작용이 입증됐다는 뜻은 아닙니다. 같은 범위에 대한 승인을 다시 요청하지 않습니다. 설정 명령0x66·다른 명령·메인 앱 제어 활성화·삼성 DLL·드라이버/서비스/ACL 변경·자동 권한 상승은 포함하지 않습니다.

## 구현한 제한

- ATIVBatteryGuard.WmiOneShotQuery.exe는 별도 asInvoker x64 net48 콘솔입니다. 메인 앱이 실행하지 않고 UAC/runas도 호출하지 않습니다. 현재 프로세스가 Elevated가 아니거나 토큰을 확인하지 못하면 WMI/OEM 준비를 진행하지 않습니다. 같은 계정 여부는 사용자 실행 절차이며 사용자 이름/SID를 수집해 독립 검증하지 않습니다.
- 기존 관측과 같은 Win32_ComputerSystemProduct.Name과 Win32_BIOS.SMBIOSBIOSVersion만 읽어 940X3G/930X3G·P05ACJ.128.140819.dg와 정확히 비교합니다. 실제 문자열·UUID·시리얼은 출력하지 않습니다. 다르거나 확인 불가면 호출하지 않습니다. 이 비교를 BIOS 진위 검증이나 후보 안전성 입증으로 취급하지 않습니다.
- 고정 WMI 상세 메타데이터·메서드 번호1과 전체 조회 완료·정확히 한 행·Active=True·입력 준비를 모두 확인합니다. 실제 관측한 해당 메서드 행의 상대 키만 로컬 고정 scope에서 사용하며 추측 키·다른 클래스 연계·원격 scope를 사용하지 않습니다.
- 요청은 검토서의21바이트, command0x65·payload80+15개00으로 고정합니다. 인수로 명령·값·경로·쿼리를 받지 않습니다. Core 실험 객체와 실제 SDK 호출 지점 모두 재진입을 막고 자동 재시도하지 않습니다.
- 실제 요청 직전에 로컬 앱 데이터의 고정 예약 파일 WmiQuery65-v1.attempt를 CreateNew·WriteThrough·Flush(true)로 확보합니다. 내용은 고정 예약 문구뿐입니다. 기존 빈 파일·부분 예약도 재사용하지 않고 쓰기 실패 시에는 호출하지 않습니다. 프로세스 재실행과 중복 실행의 추가 시도를 막기 위해 필요한 최소 지속 상태입니다. 삭제·복구·초기화 기능이나 임시 폴더 fallback은 없습니다. 의도적인 삭제·다른 계정·저장소 복원까지 방어한다고 보장하지 않으며 사용자는 표식을 삭제하거나 재실행하지 않아야 합니다.
- System.Management의 비동기 InvokeMethod 지점은 하나입니다. ObjectReady에서는 객체 수만 제한적으로 보관하고 Completed.Status가0이며 출력이 정확히 하나일 때만 고정 outData/Bytes를 읽습니다. 이 값은 비동기 작업의 완료 상태이며 즉시 ExecMethod HRESULT를 별도로 확보했다는 뜻은 아닙니다. ReturnValue를 성공 기준으로 가정하지 않습니다.
- 콜백 캡처는 완료·중복·취소·늦은 도착·읽기/정리 실패를 순수 코드로 검증합니다. 완료를 먼저 확정하고 객체를 정리한 뒤 분리된 snapshot을 게시합니다. 실패 완료 상태에는 출력 getter를 읽지 않고 늦은 객체로 성공을 되살리지 않습니다.
- 부모10초와 작업자 자체의 독립10초 감시가 있습니다. 내부 작업자 인수로 직접 실행해도 자체 감시는 적용됩니다. 프로세스 종료는 이미 시작된 제공자/펌웨어 작업의 취소·복구를 보장하지 않으며 시간 초과는 결과 불명·재시도 금지로 남깁니다. async 옵션의 Timeout을 강제 제한으로 사용하지 않습니다.

DataBuffer와 입력 객체 생성·값 설정은 메모리 내 준비입니다. WMI 저장소 Put·서비스/드라이버/ACL 변경·장치/포트 I/O·삼성 DLL 초기화·unlock은 구현하지 않았습니다. 이 사실이 미검증 후보의 펌웨어 부작용 부재를 보장하지는 않습니다.

## 출력과 해석

최종 보고서는 고정 상태·토큰 상승 상태·호출 요청 여부·메서드/프레임 판정·후보 표식0/1/FF/Other만 보관합니다. 요청됨은 실제 실행·완료 보장이 아닙니다. 원문 응답·기기/계정 식별자·경로·예외 메시지는 출력/저장하지 않습니다. 응답 snapshot은 최종 보고서에 남기지 않습니다.

완료 상태0과 기존의 정확한21바이트·ACK 검증을 통과해도 후보 표식을 실제 보호 OFF/ON/미지원으로 판정하지 않습니다. 어떤 결과에서도 actualMode·지원 상태·제어 버튼을 바꾸지 않습니다. 실제 충전 제어는 계속 Unsupported입니다.

## 노트북 실행 방법

1. [새 실험 ZIP](../downloads/README.md) 전체를 메인 앱과 다른 새 로컬 폴더에 압축 해제합니다.
2. 같은 Windows 계정에서 ATIVBatteryGuard.WmiOneShotQuery.exe를 오른쪽 클릭해 관리자 권한으로 한 번 실행합니다. 다른 계정의 암호를 요구하거나 보안 제품이 차단하면 중단하고 보호를 해제하거나 우회하지 않습니다.
3. 표시된 출력만 복사해 전달하고 Enter로 닫습니다. 예전 TXT·삼성 DLL·파일 목록·권한 비교를 다시 만들 필요는 없습니다.
4. 호출 요청·시간 초과·결과 불명 뒤에는 재실행하지 않고 예약 표식을 삭제하지 않습니다. 무호출 결과도 임의 수정·재시도 없이 그대로 전달합니다.

일반 더블클릭으로 Elevated가 아니면 호출 없이 종료합니다. 미서명 개발 실험판이고 새 도구의 실제 Windows 실행·후보 의미·펌웨어 부작용은 아직 검증되지 않았습니다. 클라우드에서는 실제 Windows/OEM 호출을 실행하지 않습니다.
