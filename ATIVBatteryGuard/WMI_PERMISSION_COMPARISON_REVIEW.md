# 권한 거부 지속 결과와 별도 읽기 비교 도구

2026-11-03 한국 시간 기준입니다. 사용자 제공 samsung-files-20261102T154749를 관측 자료로 읽었으며 원본 TXT는 저장소·배포물에 넣지 않았습니다.

## 확인된 사실과 남은 불확실성

새 TXT에는 PacketPrivacy 연결을 명시한 빌드의 요약과 안내가 있고, WmiAcpiVersion과 WmiAcpiMethod는 여전히 모두 AccessDenied입니다. SABI 이름은 NotFound, Samsung 이름 후보 7개는 모두 Stopped/Manual로 이전과 같습니다. 따라서 암호화 인증 명시만으로 두 속성 조회가 해결되지 않았음을 확인했습니다.

기존 TXT에는 프로세스 토큰 상승 상태가 없으므로 당시 실행이 이미 상승된 상태였는지도 확정할 수 없습니다. 거부가 네임스페이스 연결·쿼리·열거·속성 읽기 중 어디서 발생했는지도 기록되지 않았습니다. 이 결과로 관리자 실행이 해결한다거나 네임스페이스·드라이버·기능이 없다고 단정하지 않습니다.

동일한 일반 권한 파일 목록·TXT·삼성 DLL/EXE를 다시 요청하지 않습니다. 임의 드라이버 시작이나 ACL 변경으로 결과를 바꾸지 않습니다.

## 준비한 별도 도구

ATIVBatteryGuard.WmiAccessCheck는 메인 앱과 별도의 x64 net48 콘솔 프로젝트입니다. manifest는 asInvoker이며 자동 UAC 요청이나 runas 동작이 없습니다. 메인 앱은 이 도구를 실행하지 않습니다. 인수 없이 시작하는 일반 실행 경로는 자체 하위 조회 프로세스를 감시하고 10초에 종료 요청한 뒤 최대 1초 추가 대기합니다. 출력 수집 완료 확인에도 짧은 대기를 적용합니다. 내부 작업자 인수는 부모 전용이며 직접 실행용이 아닙니다.

표준 출력만 사용하고 결과 파일이나 로그를 쓰지 않습니다. 임의 파일 경로·쿼리·명령·서버 이름을 입력받지 않습니다. 실행 파일의 로컬 위치를 확인하고 고정된 자기 자신만 작업자로 실행합니다. 표준 출력/오류 각각 최대 32,768자를 수집하며 오류 채널 원문은 표시하지 않습니다. 시간 초과나 잘못된 출력에서 중간 값을 성공으로 해석하지 않습니다.

프로세스 토큰은 TOKEN_QUERY와 GetTokenInformation(TokenElevation)으로만 읽습니다. 결과는 Elevated / NotElevated / Unknown이며 관리자 그룹 소속으로 대신하지 않습니다. API 실패는 Unknown, 유효한 TokenIsElevated 값은 0이면 미상승·0이 아니면 상승으로 해석합니다. 권한을 조정하거나 사용자 이름·SID·그룹 정보를 읽지 않습니다.

WMI 조회는 기존의 두 고정 투영만 사용합니다.

| 범위 | 읽는 속성 |
| --- | --- |
| 로컬 ROOT\WMI의 WmiAcpiVersion | Active, version |
| 로컬 ROOT\WMI의 WmiAcpiMethod | Active |

## 승인 범위

이번 작업은 그 비교를 수행할 소스·실행 파일·테스트를 준비한 것입니다. 관리자 비교 실행은 아직 승인받거나 수행하지 않았습니다. asInvoker 도구를 준비했다고 권한 상승이 승인된 것으로 해석하지 않습니다. 승인되더라도 메인 앱은 일반 권한으로 유지하고 서비스·드라이버·ACL·삼성 DLL·OEM 메서드·펌웨어 쓰기는 범위 밖입니다.

제안한 비교는 같은 Windows 계정에서 권한 상태만 달리하는 범위입니다. 다른 관리자 계정의 자격 증명이 필요한 경우에는 중단하며 값을 채팅으로 요청하지 않습니다. 이 도구는 계정 식별자를 읽지 않으므로 두 실행이 같은 사용자였는지를 자동으로 확인하지 않습니다. 계정이 달라진 결과를 토큰 상승만의 효과로 해석하지 않습니다.

관리자 비교가 성공할지는 미검증입니다. 일반 실행 결과가 Elevated 또는 Unknown이면 이를 NotElevated 기준 결과로 간주하지 않습니다. 비교 결과가 나와도 다음 실제 보호 상태 읽기는 명령 의미·모델 적합성·입출력 계약 검증이 별도로 필요하며, 현재 충전 제어는 계속 Unsupported입니다.
