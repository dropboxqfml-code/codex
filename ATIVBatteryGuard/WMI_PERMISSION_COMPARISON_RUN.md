# 승인된 WMI 읽기 권한 비교 실행

2026-11-03 한국 시간, 사용자가 같은 Windows 계정에서 고정된 두 속성을 일반 권한과 한 번의 관리자 권한으로 읽어 비교하는 범위를 승인했습니다. 실행 결과는 아직 받지 않았으며 이 문서는 실행 완료 기록이 아닙니다.

## 사용할 도구

[기존에 검증한 비교 도구 ZIP](https://github.com/dropboxqfml-code/codex/raw/a498f767d38f2670a658b3e18f49d3bd7137ad9a/downloads/ATIVBatteryGuard-WMI-PERMISSION-REVIEW.zip)을 그대로 사용합니다. 이미 받은 파일을 다시 받을 필요는 없습니다. ZIP 전체를 메인 프로그램과 다른 로컬 폴더에 풀어 EXE와 Core DLL을 함께 유지합니다.

실행 파일 이름은 ATIVBatteryGuard.WmiAccessCheck.exe입니다. 메인 ATIVBatteryGuard.exe의 관리자 실행은 이번 범위가 아닙니다.

ZIP의 승인 대기 안내와 BUILD-INFO의 administratorComparisonApprovedAtPackaging=false는 승인 전 패키징 시점의 기록입니다. 이번 대화에서 승인한 아래 한정 비교에 사용할 수 있으며 실행 파일 자체를 바꾸거나 재설치할 필요는 없습니다.

## 실행 순서

1. ATIVBatteryGuard.WmiAccessCheck.exe를 일반적으로 더블클릭해 한 번 실행합니다. 창을 닫기 전에 결과를 복사해 둡니다. 현재 프로세스 토큰 상승 상태가 NotElevated인지 확인합니다.
2. 첫 결과가 Elevated 또는 Unknown이거나 시간 초과·결과 수신 실패라면 일반 권한 기준 결과로 취급하지 말고 그 상태를 전달합니다. 반복 실행하거나 다른 설정으로 바꾸지 않습니다.
3. 첫 결과가 NotElevated라면 창을 닫고 같은 폴더의 같은 EXE를 오른쪽 클릭해 관리자 권한으로 한 번 실행합니다. 같은 계정의 UAC 동의 창은 이번 승인 범위입니다. 다른 관리자 계정의 자격 증명을 요구하면 중단합니다.
4. 두 번째 출력의 토큰 상태가 실제 Elevated인지 확인합니다. 이름만 관리자 실행이라고 해서 상승된 결과로 간주하지 않습니다. 시간 초과·출력 실패도 그대로 결과이며 자동 재실행하지 않습니다.

각 실행에서 다음 항목만 복사해 전달하면 됩니다.

- 일반 / 관리자 중 어느 실행인지
- 현재 프로세스 토큰 상승 상태
- WmiAcpiVersion의 조회 상태와 단계·오류 분류
- WmiAcpiMethod의 조회 상태와 단계·오류 분류

일반/관리자 비교를 위해 기존 samsung-files TXT·삼성 DLL/EXE·설치 파일 목록을 다시 만들거나 제출할 필요는 없습니다. 사용자 이름·계정 암호·SID·파일 경로는 전달하지 않습니다.

## 승인 경계와 해석

같은 로컬 ROOT\WMI의 Active/version 속성 읽기만 수행합니다. 서비스·드라이버·ACL·보안 설정·삼성 DLL·OEM 메서드·펌웨어 쓰기는 포함하지 않습니다. 다른 계정으로 바뀌면 권한 상승만의 효과로 비교할 수 없으므로 이번 절차를 중단합니다.

관리자 비교가 성공할지는 미검증입니다. 일반/상승 결과의 차이가 있어도 이는 그 실행 시점의 접근 결과이며 배터리 보호 ON/OFF나 충전 명령 지원의 증거가 아닙니다. 실제 충전 제어는 계속 미지원입니다.
