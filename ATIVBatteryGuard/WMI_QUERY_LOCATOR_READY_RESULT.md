# 승인된 1회 조회 도구의 경로 정보 수정 — Query65-locator-v2

**결과 수신·실험 완료:** [ResponseReceived·ValidFrame·표식FF](WMI_ONE_SHOT_QUERY_RESULT.md)를 확인했습니다. 기존1회는사용됐고아래실행절차를다시수행하지않습니다. 표식을그대로유지하며현재는일반앱오프라인검토단계입니다. 아래는배포당시기록입니다.

## 새 실기 결과와 의미

사용자 노트북의 Locator-v2 출력은 **Elevated · Complete · Ready · None**입니다. OEM 호출과 예약 접근은 없습니다. 원본 TXT는 저장소나 배포물에 넣지 않습니다.

이 실행은 고정 모델/BIOS, 상세 WMI 정의와 메서드 번호1, 전체 열거 완료·정확히 한 활성 대상·경로 검사, 대상 다시 읽기, 입력 매개변수/CIMTYPE와 메모리 DataBuffer 준비까지 통과했습니다. 이전 대상 열거 단계의 중단은 이번 실행에서는 재현되지 않았습니다. 옵션 변경만이 원인이었다는 인과나 펌웨어 명령의 의미·안전성까지 입증한 결과는 아닙니다.

따라서 같은 준비 점검이나 과거 자료를 다시 요청하지 않고, 검증된 옵션을 기존 승인 실험의 준비 코드에 반영합니다. 저장된 Ready TXT를 실행 허가나 호출 대상 정보로 사용하지 않으며 수정 도구가 모든 조건을 다시 검사합니다.

## 기존 승인 범위와 유지한 제한

[명시적 승인 기록](WMI_ONE_SHOT_QUERY_APPROVAL.md)은 별도 도구·같은 계정의 수동 관리자 실행·고정 후보0x65 최대1회이며, 같은 범위의 승인을 다시 요청하지 않는다고 명시합니다. [이전 실험 결과](WMI_ONE_SHOT_PREFLIGHT_RESULT.md)는 사전 검증에서 끝나 예약/채널에 진입하지 않았습니다. 이번에는 그 승인 범위의 실제 요청을 준비하도록 필요한 옵션만 수정합니다.

이전 보고에서 요청이 없었다는 사실은 기존 예약 파일 부재나 다른 실행 부재를 보장하지 않습니다. **기존 WmiQuery65-v1.attempt를 같은 위치에서 그대로 사용**하며, 표식이 있거나 안전하게 확보하지 못하면 호출하지 않습니다. 새 버전 이름이나 새 압축 해제 폴더가 횟수 제한을 초기화하지 않습니다. 예약 삭제·복구·이름 변경·다른 계정/위치 우회는 없습니다.

고정 요청은 기존21바이트 `43 58 65 00 00 80 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00`입니다. 메서드 번호1과 후보 명령0x65를 혼동하지 않으며 첫 입력0x80도 충전 상한80%라는 뜻이 아닙니다. 원래 요청·정책·SDK 호출/콜백·출력 처리·예약 로직은 변경하지 않았습니다.

## 실제 변경

- 기존 WmiOneShotQuery의 메서드 대상 SELECT에만 EnsureLocatable=true를 지정했습니다. 모델/BIOS 쿼리 옵션은 기존대로 유지합니다.
- 단일 활성 대상·클래스·경로 길이·입력 형식 검사를 유지합니다. 추측 키, 다른 모델, 다른 쿼리나 추가 명령은 없습니다.
- 부모 화면에 **Query65-locator-v2** 고정 수정판 표시만 추가했습니다. 메인 앱과 분리된 asInvoker, 같은 계정의 수동 관리자 실행과 부모/작업자의 독립10초·사전 검증6초 제한을 유지합니다.
- 요청 직전 같은 영속 표식을 원자적으로 확보하고 최대1회 요청합니다. 오류·시간 초과·결과 불명에서도 자동 재시도하지 않습니다. 프로세스 종료가 이미 시작된 제공자/펌웨어 작업의 취소나 복구를 보장하지는 않습니다.

이 수정판은 **실제 OEM 조회 후보를 최대1회 요청할 수 있는 한정 실험 도구**입니다. 후보의 현재 모델 의미와 예상하지 못한 펌웨어 부작용은 아직 검증되지 않았습니다. 설정 명령0x66·다른 명령·삼성 DLL·장치/포트 I/O·드라이버/서비스/ACL/보안 정책 변경은 없습니다. 네트워크 통신도 없습니다.

## 새 수정본 확인 방법

1. [ONE-SHOT-LOCATOR ZIP](../downloads/README.md) 전체를 새 로컬 폴더에 압축 해제합니다. 삼성 원본 DLL은 필요하지 않으며 배포물에 포함하지 않습니다.
2. 같은 Windows 계정에서 **새 폴더의 ATIVBatteryGuard.WmiOneShotQuery.exe만 수동 관리자 권한으로 한 번 실행**합니다. 다른 관리자 계정의 암호가 필요하거나 보호 기능이 차단하면 중단하고 우회하지 않습니다.
3. 창의 **Query65-locator-v2** 표시를 확인하고 출력만 복사해 전달합니다. Enter로 닫은 후 다시 실행하지 않습니다. 기존 표식이 있다는 결과도 그대로 전달하며 표식을 건드리지 않습니다.

이전 버전 EXE를 임의로 다시 실행하지 않습니다. 과거 TXT·삼성 DLL·EXE·파일 목록·일반/관리자 비교·무호출 준비 점검을 다시 제출할 필요는 없습니다.

## 결과의 한계

호출 요청됨은 실제 실행·완료 보장이 아닙니다. 비동기 완료 상태와 응답 형식 검증을 통과해도 후보 표식0/1/FF/Other만 보고합니다. 원문 응답·인스턴스/계정 식별자·경로·원문 오류는 보고하지 않습니다.

표식을 보호 OFF/ON/미지원이나 실제 충전 상한으로 바꾸지 않으며 메인 앱의 actualMode·지원 상태·제어 버튼도 활성화하지 않습니다. 실제 충전 제어는 계속 Unsupported입니다. 실제 후보 응답은 아직 미관측입니다.

## 검증과 배포

전체 솔루션과 portable 테스트를 빌드하고, 가상 backend와 임시 더미 예약 파일로 실패 준비의 무예약, 요청 전 영속 예약, 성공/실패 뒤 새 실험 객체의 추가 요청 차단을 검증합니다. 실제 Windows/OEM/펌웨어는 클라우드에서 실행하지 않습니다.

이번 전체331개와 Python 배포 검증15개가 통과했고, 여섯 프로젝트 및 테스트 프로젝트 빌드는 각각 경고·오류0개입니다. 독립 소스 검토에서도 추가 차단 문제를 발견하지 못했습니다.

패키저는 원래 정책·예약·실험·콜백 코드와 실제 호출/출력 처리 구간을 고정 기준과 대조합니다. 지정한 옵션과 화면 표시 이외의 변경, 이전 바이너리 혼입, 불일치 소스와 허용되지 않은 파일은 거부합니다. 새 ZIP은 기존 배포를 덮지 않으며 소스와 SHA-256을 함께 제공합니다. 정확한 이번 결과는 [검증 기록](VALIDATION.md)에 남깁니다.
