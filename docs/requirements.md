# v0.1 요구사항 및 범위

이 대화에 제공된 요구사항을 기준으로 구현했습니다. 별도의 이전 요구사항 문서는 현재 저장소나
대화에 포함되어 있지 않으므로 추가 내용을 추정하지 않았습니다.

| 요구사항 | 구현 | 검증 방법 |
| --- | --- | --- |
| 폴더 선택 / 재귀 옵션 | 로컬 전용 Qt 폴더 선택, os.walk | 비재귀·재귀 검색, GUI 옵션 |
| 완전 동일 파일 | 스트리밍 SHA-256 | 다른 이름·확장자의 바이트 복사 |
| 교차 확장자 픽셀 동일 | EXIF 회전 후 RGBA·크기 SHA-256 | PNG/BMP 및 회전 TIFF |
| 유사 이미지 | 64비트 pHash, 거리 기본 6 | JPEG 재압축, 임계값·연결 관계 |
| 그룹별 썸네일 | 작업 스레드에서 PNG 생성, Qt 표시 | 실제 검색 결과의 행·아이콘 |
| 파일 정보 | 이름, 전체 경로, 크기, 해상도 | 이미지 기록과 GUI 행 |
| 보관·보류·삭제 대상 | 기본 보류, SQLite 저장 | 변경 내용별 복원, GUI 선택 |
| 확인 후 휴지통 | 기본 아니요, 전체 경로, Send2Trash | 확인 취소/동의, backend 실패, 변경 보호 |
| 진행률 및 취소 | phase/current/total, Event | 분석·비교 취소, GUI 취소 |
| GUI 멈춤 방지 | QThread, 시그널, 종료 대기 | 이벤트 루프 heartbeat, 종료 도중 취소 |
| Windows exe | PyInstaller onedir 빌드 스크립트 | Windows 실행 안내; Linux에서는 빌드하지 않음 |

미포함: 자동 대표 이미지 선택, 영구 삭제, 휴지통 내 복원 UI, RAW/HEIC 코덱 추가,
애니메이션·다중 페이지 비교, 색상 관리, 폴더 감시, 초대형 컬렉션 색인 최적화.
