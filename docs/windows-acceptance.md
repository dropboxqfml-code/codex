# Windows 수동 인수 테스트

테스트 대상은 **Actions에서 받은 번들 exe**입니다. Python과 uv가 없는 Windows 10/11 x64
PC 또는 VM에서 실행합니다. 원본 사진 대신 임시 시험용 사본만 사용하세요.
CI의 자동 검사 통과는 이 수동 검증 완료를 의미하지 않습니다.

## 시험 데이터 준비

`한글 테스트 폴더` 아래 다음 파일을 만듭니다. 일반 사용자는 그림판의 ‘다른 이름으로 저장’과
탐색기의 복사 기능으로 준비할 수 있습니다.

1. 모양·색상이 있는 원본 PNG와 다른 이름의 바이트 사본. 사본의 확장자를 `.bin`으로 바꾸어도
   파일 내용은 바꾸지 않습니다.
2. 원본을 그림판에서 BMP로 저장한 파일. 저장 과정에서 픽셀이 바뀌지 않은지 확인하세요.
3. 원본을 JPEG로 저장한 파일. 픽셀이 바뀌어 픽셀 동일이 아닌 유사 판정일 수 있습니다.
4. 다른 사진, 일반 텍스트, 깨진 `.png`, 애니메이션 GIF, 하위 폴더의 원본 사본.

검색 후 정보와 그룹을 확인합니다. 단색 이미지만으로 유사도 품질을 판단하지 마세요.
그룹은 연결 관계이므로 그룹 안 모든 쌍이 같은 이미지라는 뜻은 아닙니다.

삭제 시험은 사본에만 수행합니다. 검색 후 보관 한 장·보류 한 장·삭제 대상 한 장을 지정해
‘아니요’와 ‘예’를 각각 시험하고 실제 휴지통 항목 및 복원을 확인하세요. 변경 보호 시험은
다시 검색한 후 파일 내용을 수정하고 기존 결과로 이동을 시도합니다.

오류 발생 시 커밋, Artifact 실행번호, Windows 버전, 재현 단계, ‘문제 보기’ 내용을 기록하세요.
개인 사진·전체 경로가 노출되는 스크린샷은 공유 전에 검토하세요.

## v0.2.0 두 폴더 비교 추가 항목 (수동 검증 미완료)

- [ ] 동기화되지 않는 A/B 로컬 시험 폴더를 준비하고 두 폴더 모드를 선택한다. 실제 개인 사진을 CI에 올리지 않는다.
- [ ] 각 하위 폴더 옵션 기본 꺼짐, 독립 동작, 역할 바꾸기 확인과 작업 중 비활성화를 확인한다.
- [ ] 같은/중첩/대소문자 별칭/정션·링크/원격 폴더 선택 시 명확히 차단되는지 확인한다.
- [ ] A 내부 또는 B 내부에만 있는 중복은 보고하지 않는지 확인한다.
- [ ] 다른 이름의 같은 바이트, PNG↔BMP 픽셀, JPEG 재압축/축소 후보의 종류와 거리를 확인한다.
- [ ] B 하나가 A 여러 장과 매칭될 때 다른 A를 열람하고 B 상태가 하나로 유지되는지 확인한다.
- [ ] 좌우 썸네일/큰 미리보기, 경로·크기·해상도·확장자·시간, 상태/유형/파일명 필터를 확인한다.
- [ ] 모든 새 B 후보는 미결정이며 A에는 이동/선택 액션이 없는지 확인한다.
- [ ] 보관/보류는 유지하고, B 휴지통 예정만 자세한 경로 확인 후 이동되는지 확인한다.
- [ ] 최종 아니요 및 유사 후보의 두 번째 아니요에서 모든 파일이 유지되는지 확인한다.
- [ ] 검색 후 A 또는 B를 변경·삭제하면 이동이 차단되는지, 실패 후 후속 이동이 중단되는지 확인한다.
- [ ] 실제 휴지통에서 시험 B 사본을 복원하고 A 및 미선택 B의 바이트가 그대로인지 확인한다.
- [ ] 재검색 캐시와 보관/보류 복원, 변경 시 미결정, 휴지통 예정 자동 복원 금지를 확인한다.
- [ ] 캐시·검토 기록 지우기 확인 시 원본/단일 모드 선택 기록이 유지되는지 확인한다.
- [ ] 네트워크 어댑터 비활성화 PC에서 양 모드 전체 기능을 반복하고 WFP/ETW/패킷 캡처를 별도로 수행한다.
- [ ] 표준 사용자 권한, 긴 경로, 높은 DPI, 대형 이미지, 실제 대량 폴더의 반응·취소·종료를 확인한다.

자동 CI의 새 frozen-smoke 항목과 두 화면 스크린샷은 위 사람이 수행하는 검증을 대신하지 않습니다.
