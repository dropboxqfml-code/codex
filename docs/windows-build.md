# Windows 실행 파일 제작

PyInstaller는 교차 컴파일 도구가 아닙니다. 반드시 Windows 10/11 x64에서 Python 3.12 x64로
실행하세요. Linux에서 만든 실행 파일은 Windows `.exe`가 아닙니다.

## 빌드

저장소 루트 PowerShell에서 uv를 설치한 뒤 다음을 실행합니다. `uv.lock`에는 PyInstaller도 포함됩니다.

```powershell
uv sync --locked
uv run --locked pytest -q
uv run --locked python scripts/build_windows.py
```

결과는 `dist\Image Duplicate Finder\Image Duplicate Finder.exe`와 같은 디렉터리의 Qt DLL 등입니다.
**디렉터리 전체**를 배포하세요. 초기 버전은 단일 파일 압축에 따른 임시 추출·시작 지연을 피하기
위해 onedir 모드를 사용합니다. `build`와 `dist`는 생성 출력입니다. 앱은 실행 파일 옆에 DB를 쓰지
않고 사용자별 앱 데이터 폴더를 사용하므로 읽기 전용 설치 폴더에서도 동작할 수 있습니다.

빌드 스크립트는 Windows 이외에서 실행하면 오류로 종료합니다. 코드는 서명하지 않습니다.
배포 시 SmartScreen 경고가 나올 수 있으며, 공개 배포 전 인증서 서명과 라이선스 고지를 검토하세요.
PySide6/Qt, Pillow와 다른 번들 라이브러리의 라이선스·고지 의무를 확인하고 필요한 고지를 동봉하세요.

## Windows 수동 인수 테스트

1. Python이 설치되지 않은 별도 Windows x64 계정/PC에서 디렉터리를 풀어 exe를 실행합니다.
2. 한글·공백이 있는 임시 폴더에 같은 파일 사본, 같은 픽셀의 PNG/BMP, 재압축 JPEG,
   다른 사진, 손상 PNG, 하위 폴더를 준비합니다.
3. 재귀 옵션, 그룹 썸네일/경로/크기/해상도, 유사도 거리 변경, 진행률과 취소를 확인합니다.
4. 검색 중 창 이동과 닫기가 정상인지 확인합니다. 한 프레임의 큰 이미지 처리가 끝날 때까지는
   취소 완료가 지연될 수 있습니다.
5. 보관 없는 그룹의 삭제 차단, 확인 대화상자 ‘아니요’, 변경 파일 삭제 차단을 확인합니다.
6. **테스트용 사본만** 삭제 대상으로 지정해 ‘예’를 누르고 실제 Windows 휴지통에서 복원을 확인합니다.
7. 앱 재실행·재검색 후 선택 복원을 확인합니다. 이동 후 없는 파일은 다시 나오지 않아야 합니다.
8. 읽기 전용 폴더와 휴지통 미지원 드라이브의 실패가 표시되며 영구 삭제되지 않는지 확인합니다.

클라우드 Linux에서의 Qt offscreen 테스트는 위 Windows 네이티브 테스트를 대체하지 않습니다.
