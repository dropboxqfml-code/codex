# 6517A v0.9.3 비교 진단 설정

[설정 ZIP 다운로드](./6517A-Comparison-Settings.zip?raw=true) · [SHA-256](./6517A-Comparison-Settings.zip.sha256)

기존 공개 v0.9.3에서 불러오는 설정 모음입니다. 새 실행 파일이나 교정 데이터 복구 기능을 포함하지 않습니다.

| 파일 | 범위 조건 |
|---|---|
| A-fixed-200nA.json | AUTO OFF · 고정 200 nA |
| B-auto-single-200nA.json | AUTO ON · 하한=상한=200 nA |
| C-auto-switching-2to200nA.json | 기존 AUTO 2–200 nA 조건, 재현용 |

A/B는 AUTO ON/OFF만 다르며 영점보정 범위는 모두 200 nA입니다. 공통 조건은 0·0.1·0.5 V, 각 30초, NPLC 10, 판독 간격 1초, Software trip 10 nA입니다.

ZIP을 별도 폴더에 풀고 v0.9.3에서 **설정 불러오기 → A 파일 → 연결 → ARM → START** 순서로 진행합니다. A 종료·출력 OFF 확인 후 연결을 종료하고 B 파일로 비교합니다. 파일을 불러온 뒤 기존 **nA 범위 비교 진단값** 버튼을 누르면 예전 조건으로 바뀝니다.

설정의 장비 주소와 사용자 확인 항목은 준비에 사용한 기존 실행 설정을 유지합니다. 현재 연결·설정을 검토하고 시작합니다. 교정 상태는 그대로 기록하고, 진단 자료는 정상 정확도 통계에서 제외합니다. 같은 초과전류가 재현되면 중단 및 출력 OFF를 유지합니다.

설정 호환성·모의 실행은 확인했으며 실제 장비의 중단 해소와 측정 정확도는 미확인입니다. 자세한 순서는 ZIP 안의 READ_ME_KO.txt를 참고하세요.
