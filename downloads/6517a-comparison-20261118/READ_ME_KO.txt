6517A 비교 진단 설정 — 기존 v0.9.3에서 사용

목적
관측된 2 nA → 200 nA 자동 전환을 피하는 조건부터 측정합니다.
장비 교정 값은 변경하지 않습니다. 실제 장비에서 중단이 해소됐는지는 시험으로 확인합니다.

파일
A-fixed-200nA.json: AUTO OFF, 고정 200 nA, 영점보정 200 nA.
B-auto-single-200nA.json: AUTO ON, 하한=상한=200 nA, 영점보정 200 nA.
C-auto-switching-2to200nA.json: 기존 AUTO 2~200 nA 전환 조건. 재현용이므로 우선 실행할 필요는 없습니다.

A와 B는 AUTO ON/OFF 설정만 다릅니다.
공통: 0, 0.1, 0.5 V / 각 30초 / NPLC 10 / 판독 간격 1초 / Software trip 10 nA.
주소·시료 정보·사용자 확인 항목은 최근 업로드한 실행 설정을 유지했습니다.

실행
1. 이 ZIP을 다운로드 폴더 등의 별도 폴더에 풉니다.
2. 기존 v0.9.3의 Start-GUI.cmd를 실행합니다.
3. 장비 연결을 종료한 상태에서 '설정 불러오기'로 A-fixed-200nA.json을 엽니다.
   불러온 설정으로 바로 진행합니다. 기존 'nA 범위 비교 진단값' 버튼을 누르면 이전 2~200 nA 조건으로 바뀝니다.
4. 현재 장비·주소와 설정을 확인하고 연결 → ARM → START로 진행합니다.
5. 종료 후 출력 OFF를 확인하고 A 결과의 진단 ZIP을 별도 이름으로 저장합니다.
6. A의 결과를 확인한 뒤 연결 종료 → B 설정 불러오기 → 연결 → ARM → START로 같은 조건을 비교합니다.

결과 해석
A 완료 / B 완료: 이번 두 조건에서는 관측된 범위 전환을 제거한 대조가 가능합니다.
A 완료 / B 중단: 같은 범위에서 AUTO 활성화 경로의 차이를 조사할 수 있습니다.
A 중단: 고정 범위에서도 이상 보고값이 재현된 것이므로 단순 범위 전환만을 원인으로 볼 수 없습니다.
어느 경우도 전체 AUTO 문제의 해결이나 측정 정확도 합격을 뜻하지 않습니다.

교정 상태 256은 기록하고 비교 진단 표시를 유지합니다.
모든 진단 판독을 정상 통계에서 제외하므로 요약 N=0은 이 모드의 정상 처리입니다.
원시 전류와 계산 가능한 저항은 기존 CSV·analysis.txt에 남습니다.
기존 중단 조건은 유지합니다. 정착 중이어도 보고 전류가 10 nA 이상이면 OFF로 중단합니다.

이 파일은 설정 모음입니다. 새 프로필 선택 UI·상세 trip 로그의 코드 개선안은 별도로 로컬 검증 중이며 게시하지 않았습니다.
