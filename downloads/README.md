# ATIV Battery Guard Windows preview

Download ATIVBatteryGuard-PREVIEW.zip from this folder. Extract all files and double-click ATIVBatteryGuard.exe.

This preview targets Windows 10 x64 / .NET Framework 4.8. It was cross-compiled with the actual WPF XAML. Windows runtime and GUI validation have NOT been performed. Actual 80% charging control is NOT implemented.

이 폴더의 ZIP을 다운로드하고 모두 압축을 푼 뒤 ATIVBatteryGuard.exe를 두 번 클릭하세요. 개발 도구는 필요하지 않습니다. 실제 80% 충전 제한 기능은 아직 없으며 Windows 실행 확인이 필요한 시험 버전입니다.
