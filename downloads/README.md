Download ATIVBatteryGuard-DIAGNOSTICS.zip, extract all files into a new folder and double-click ATIVBatteryGuard.exe.

Use the new top button 진단 파일 만들기, wait for completion, then 진단 파일 위치 열기. Share the newest diagnostics TXT only if you choose to. Collection is read-only and files are never uploaded automatically. No developer tools or administrator rights needed. Windows10x64/.NETFramework4.8 required.
