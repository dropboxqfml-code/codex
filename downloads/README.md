# 실행 파일 배포 보류

사용자가 삼성 파일 정보 확인판 다운로드 중 **Trojan:Win32/Wacatac.B!ml** 차단을 보고했습니다. 탐지 원인과 오탐 여부는 아직 확인되지 않았습니다. 기존 실행 파일의 다운로드·실행 안내를 철회합니다. Defender 차단·격리를 유지하고 허용/예외 등록이나 보안 기능 해제를 하지 마세요.

새 실행용 ZIP은 배포하지 않습니다. 미서명 또는 실제 Defender 검사 증거가 없는 빌드는 패키징 단계에서 거부합니다. Windows 실기 검사와 게시자 서명 인증서는 현재 개발 환경에 없어 검증 통과를 주장할 수 없습니다.

[보안 대응·배포 검증 변경](../ATIVBatteryGuard/WINDOWS_SECURITY_RELEASE.md) · [개발 검토용 자체 소스](ATIVBatteryGuard-SOURCE.zip)

소스는 실행 파일이 아니며 비기술 사용자에게 직접 빌드하도록 요구하지 않습니다. 과거 Git 커밋의 다운로드 주소는 남아 있을 수 있습니다. 최신 목록에서 실행 ZIP을 제거한 것은 과거 파일의 회수나 탐지 해소를 의미하지 않습니다. 다른 과거 ZIP을 대안으로 실행하도록 권하지 않습니다.
