# ATIV Battery Guard — 배터리 진단 결과 해석판

[현재 실행용 ZIP](ATIVBatteryGuard-DIAGNOSTIC-ASSESSMENT.zip) · [현재 소스](ATIVBatteryGuard-SOURCE.zip) · [구조·출처·검증 기록](../ATIVBatteryGuard/WINDOWS_BATTERY_QUERY.md)

사용자가 전달한 진단에서 Windows 표준 조회 성공과 `0x80000000`을 확인했습니다. 시스템 배터리 표시만 있고 표준 충전·방전 요청 지원 비트는 없습니다. 삼성 OEM 충전 상한 전체가 불가능하다는 뜻은 아닙니다. 실제 제어는 계속 미지원입니다.

새 버전은 같은 결과의 의미를 메인 화면과 진단 TXT에 설명합니다. 전체 조회·부분 실패·지원 표시를 구분하고 재조회 시 이전 결과를 지웁니다. 이번 실행에서만 결과를 보관하며 과거 노트북 진단을 현재 측정값으로 넣지 않습니다.

사용할 경우 기존 앱을 닫고 ZIP을 새 폴더에 모두 압축 해제한 뒤 ATIVBatteryGuard.exe를 실행합니다. **진단 파일 만들기**를 선택하면 **표준 Windows 요청 지원**에 해석이 표시됩니다. 이미 전달한 진단은 다시 보낼 필요가 없습니다. 삼성 실행 파일이나 DLL도 필요하지 않습니다.

GENERIC_READ, QUERY_TAG(대기 0), QUERY_INFORMATION(BatteryInformation)만 사용합니다. SET 요청이나 OEM 메서드는 호출하지 않습니다. 자체 보조 프로세스에 10초 제한을 적용하고 최대 8개 인터페이스만 확인합니다. 장치 경로·태그·시리얼번호·고유 ID는 결과에 포함하지 않습니다. 보조 조회는 상세 진단 버튼을 선택했을 때만 실행합니다.

회귀 테스트 138개 통과·실패 0개·건너뜀 0개, WPF 빌드 경고·오류 0개입니다. 실행 파일의 x64/net48/BAML/일반 권한 manifest와 OEM 수집 타입 부재·조회 타입 포함을 확인했습니다. 이전 조회판의 실제 Windows 정상 조회는 확인됐으며 이번 해석 화면은 아직 노트북에서 실행하지 않았습니다. 시간 초과·종료 경로의 실제 Windows 시험도 수행하지 않았습니다.

배포에는 자체 앱·소스·연구 요약만 들어 있으며 삼성 원본 파일·사용자 업로드·외부 문서 원본은 포함하지 않습니다. main과 게시된 환경은 변경하지 않았습니다.
