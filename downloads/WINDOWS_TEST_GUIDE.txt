이미지 모니터 Windows 시험 안내

이번 오류: PowerShell이 uv 명령을 찾지 못했습니다.
시험 프로그램은 아직 시작되지 않았습니다.
이 새 시험판은 uv 준비부터 자동으로 진행합니다.

사용자가 할 일 (3단계)
1. 새 ZIP을 다운로드하고, 새 폴더에 '모두 압축 풀기'를 합니다.
2. 안의 image-monitor 폴더에서 RUN_WINDOWS_TEST.cmd를 더블클릭합니다.
3. 처음 준비에는 몇 분 걸릴 수 있습니다. 시험 브라우저가 열리면 다른 창으로
   전환하지 말고 그대로 기다립니다. 끝나면 결과 TXT가 메모장으로 열립니다.

결과 전달
- 성공이면 채팅에 '성공'이라고만 알려주세요.
- 실패이면 같은 폴더의 WINDOWS_TEST_RESULT-숫자-숫자.txt 파일 하나만 보내주세요.
  추가 명령을 실행하거나 여러 번 재시도할 필요가 없습니다.
- 결과 TXT가 없으면 화면에 보이는 오류 문구만 알려주세요.

자동으로 하는 일
- uv가 없으면 공식 WinGet 패키지로 설치
- Python 3.12.14와 잠금 의존성 준비
- 전용 Edge 브라우저에서 합성 이미지 한 장의 실제 우클릭 저장 시험
- 결과를 TXT로 저장하고 메모장으로 열기

알아둘 점
- PowerShell에 명령을 붙여넣거나 MD 파일을 열 필요가 없습니다.
- WinGet이나 Edge가 없으면 결과 TXT에 해당 단계가 기록되고 멈춥니다.
- 개인 브라우저 프로필은 사용하지 않습니다.
- 실제 사이트 감시나 이미지 수집은 아직 시작하지 않습니다.
- 시험이 중단된 경우 자동 재시도나 자동 복구는 하지 않습니다.
