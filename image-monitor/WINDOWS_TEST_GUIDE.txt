이미지 이어서 저장 시험 (v10)

첫 번째 이미지의 실제 저장과 검증은 성공했습니다.
이번에는 저장한 파일을 유지하면서 남은 이미지를 이어서 저장합니다.

1. 이전 시험용 Chrome 창이 열려 있으면 닫고,
   새 ZIP을 다른 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RETRY_POST_SAVE_TEST.cmd를 더블클릭합니다.
   열린 전용 Chrome에서 '저장 시작'을 한 번 누릅니다.
3. 자동으로 열린 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나를 보내주세요.
   성공·실패 모두 같은 TXT 하나면 됩니다.

도중에 '잠시 멈췄습니다'가 표시되면 같은 Chrome 창의 '계속 저장'을 누르세요.
저장이 끝날 때까지 전용 Chrome 창을 그대로 두시면 됩니다.
명령어 입력은 필요 없습니다. 안내 TXT는 폴더 안에 이 파일 하나입니다.
