목록 감시 화면 (v17)

지난 완료 확인은 성공했습니다. 이미지 두 개와 메타데이터가 유지됐고 보류 표시도 정리됐습니다.
이번 버전은 화면에서 목록 감시를 시작하고 일시정지·중지할 수 있습니다.

1. ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_MONITOR.cmd를 더블클릭합니다.
3. 열린 화면에서 '감시 시작'을 누릅니다. 다른 작업을 계속하셔도 됩니다.
4. 원하는 때에 화면의 '프로그램 종료'를 누르면 결과 TXT가 자동으로 열립니다.
   그 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나만 보내주세요.

실행 직후에는 멈춘 상태로 열립니다. 기본 간격은 60초입니다.
간격은 감시를 중지한 상태에서 60~300초로 바꿀 수 있습니다.
새 감시는 시작 시점을 기준으로 별도로 기록합니다. 이전 시험 기록과 저장 파일은 유지됩니다.
첫 확인에서는 기준점을 만들고, 이후 새로 보이는 글의 후보를 기록합니다.
현재 버전은 목록 후보 기록까지 연결했으며 이미지 자동 저장은 다음 연결 단계입니다.
일시정지·중지는 진행 중인 확인을 안전하게 마친 뒤 적용됩니다.
끝낼 때는 화면의 '프로그램 종료' 버튼을 사용해 주세요.
오류나 확인 필요 표시가 나오면 반복 실행하지 말고 종료 후 결과 TXT만 보내주세요.
안내 TXT는 image-monitor 폴더 안에 이 파일 하나만 들어 있습니다.
