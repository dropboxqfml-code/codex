저장 이미지 확인 (v20)

지난 저장은 성공했습니다. JPEG 한 개의 저장·파일 검증·브라우저 종료와 보류 해제를 확인했습니다.
이번에는 이미 저장된 이미지를 감시 화면에서 확인합니다.

1. ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_MONITOR.cmd를 더블클릭합니다.
3. 화면 아래 '저장 결과'에서 001.jpg 이미지가 표시되는지 확인합니다.
   필요하면 아래로 조금 스크롤합니다. 파일 확인은 자동으로 진행됩니다.
4. '프로그램 종료'를 누르고 자동으로 열린 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나만 보내주세요.

이번에는 '감시 시작', '후보 내용 확인', '저장 시작'을 누를 필요가 없습니다.
새 이미지를 저장하거나 게시글을 다시 열지 않으므로 다른 작업을 계속하셔도 됩니다.
현재 열람 대상은 지난 시험에서 확인한 후보 한 글의 저장 파일입니다.
기존 이미지·메타데이터·기준점·후보·완료 기록은 유지됩니다.

'확인 필요', '저장 중 또는 보류', '저장 결과 없음'이 표시되거나 이미지가 보이지 않으면
반복 실행하지 말고 '프로그램 종료' 후 결과 TXT만 보내주세요.
안내 TXT는 image-monitor 폴더 안에 이 파일 하나만 들어 있습니다.
