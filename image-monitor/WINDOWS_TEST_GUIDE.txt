이미지 모니터 Windows 시험 안내 (v3)

보내주신 결과에서 uv 설치는 성공했습니다.
새 설치 경로를 읽지 못한 자동 실행기를 수정한 시험판입니다.

사용자가 할 일 (3단계)
1. 새 ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_WINDOWS_TEST.cmd를 더블클릭합니다.
3. 시험 브라우저가 열리면 다른 창으로 전환하지 말고 기다립니다.
   끝나면 결과 TXT가 메모장으로 자동으로 열립니다.

결과 전달
- 성공이면 '성공'이라고만 알려주세요.
- 실패이면 같은 폴더의 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나만 보내주세요.
- TXT가 없으면 화면에 보이는 오류 문구만 알려주세요.

PowerShell에 명령을 붙여넣거나 uv를 직접 재설치할 필요가 없습니다.
설치된 uv를 먼저 찾고, Python과 의존성 준비 후 시험합니다.
개인 브라우저 프로필은 사용하지 않으며 실제 사이트 수집은 시작하지 않습니다.
