확인한 새 글의 이미지 저장 시험 (v15)

지난 시험은 성공했습니다. 두 글의 작성 시각을 확인했고 한 글에서 이미지 2개를 읽었습니다.
이번에는 그 글 하나의 이미지를 실제 우클릭과 Windows 저장 창으로 저장합니다.

1. ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_CANDIDATE_SAVE_TEST.cmd를 더블클릭합니다.
3. 열린 Chrome 창에서 '저장 시작'을 한 번 누르고 기다립니다.
   저장 중에는 다른 창을 클릭하지 말고 이 Chrome 창을 그대로 두세요.
4. 자동으로 열린 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나를 보내주세요.
   성공·실패 모두 같은 TXT 하나면 됩니다.

이전에 확인한 글을 자동으로 선택하므로 주소나 명령어 입력은 필요 없습니다.
프로그램 준비 후 저장은 보통 약 1분 걸립니다.
같은 글로 고정하며 다시 실행해도 정상 저장 파일을 다시 받지 않습니다.
첨부 원본명이 불명확한 경우에는 미확정으로 기록하고 순번 이름으로 저장합니다.
이번에는 한 글만 저장하며 계속 감시하지 않습니다.
오류가 나면 반복 실행하지 말고 저장 창과 브라우저를 그대로 둔 채 결과 TXT만 보내주세요.
안내 TXT는 image-monitor 폴더 안에 이 파일 하나만 들어 있습니다.
