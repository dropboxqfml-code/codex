후보 내용 확인 (v18)

지난 시험은 정상 종료됐습니다. 목록 확인 2회와 새 후보 3개 기록을 확인했습니다.
이번에는 이미 기록된 후보의 작성 시각과 본문 이미지 정보를 확인합니다.

1. ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_MONITOR.cmd를 더블클릭합니다.
3. 열린 화면에서 '후보 내용 확인'을 한 번 누릅니다.
   '감시 시작'은 누르지 않아도 됩니다. 다른 작업을 계속하셔도 됩니다.
4. 내용 확인이 끝나 멈춘 상태가 되면 '프로그램 종료'를 누릅니다.
   자동으로 열린 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나만 보내주세요.

한 번에 기존 후보를 최대 두 개 확인합니다. 후보 사이에는 최소 60초를 기다립니다.
서버가 더 긴 대기를 요청했다면 화면의 남은 시간을 지킵니다.
화면에서 확인 건수, 작성 시각의 기준점 전후 판정, 본문 이미지 수를 볼 수 있습니다.
내용 확인 뒤 목록 감시는 자동으로 시작되지 않습니다. 이미지 자동 저장도 아직 연결하지 않았습니다.

실행 직후에는 멈춘 상태입니다. 기존 기준점·후보·시험 기록과 저장 파일은 유지됩니다.
후보 내용 확인은 목록을 다시 읽거나 새 기준점을 만들지 않습니다.
확인할 후보가 없어 버튼을 누를 수 없으면 그대로 '프로그램 종료' 후 결과 TXT만 보내주세요.
중지·종료는 현재 확인과 브라우저 정리를 마친 뒤 적용됩니다.
오류나 확인 필요 표시가 나오면 반복 실행하지 말고 종료 후 결과 TXT만 보내주세요.
안내 TXT는 image-monitor 폴더 안에 이 파일 하나만 들어 있습니다.
