감시 후보 이미지 저장 (v19)

지난 내용 확인은 성공했습니다. 두 후보 모두 기준 시각 이후 작성됐고 본문 이미지가 한 개씩 있었습니다.
이번에는 그중 한 글의 이미지를 실제 Chrome 저장 창으로 저장합니다.

1. ZIP을 새 폴더에 '모두 압축 풀기' 합니다.
2. image-monitor 폴더의 RUN_MONITOR_SAVE.cmd를 더블클릭합니다.
3. 전용 Chrome이 열리면 화면의 '저장 시작'을 한 번 누릅니다.
   저장이 끝날 때까지 그 Chrome 창을 앞에 두고 마우스·키보드를 잠시 사용하지 마세요.
4. 자동으로 열린 WINDOWS_TEST_RESULT-숫자-숫자.txt 하나만 보내주세요.

목록 감시나 후보 내용 확인을 다시 실행할 필요는 없습니다. 명령어 입력도 필요하지 않습니다.
앞 확인이나 서버가 요청한 대기 시간이 남아 있으면 실제 저장을 시작하지 않습니다.
대기 안내가 나오거나 오류가 생기면 반복 실행하지 말고 결과 TXT만 보내주세요.
전용 Chrome이 남아 있다면 결과 확인 전까지 추가 저장·재실행을 하지 마세요.

이번 저장은 확인한 후보 한 글에 고정됩니다. 다시 실행해도 다른 후보로 넘어가지 않습니다.
이미지 저장에는 실제 우클릭과 Windows 저장 창을 사용합니다. 다른 창으로 전환하면 안전하게 멈춥니다.
새 결과는 사용자 계정의 AppData/Local/ImageMonitorMonitorSave 아래에 별도로 저장됩니다.
이전 감시 기준점·후보·상세 기록과 기존 시험 이미지·메타데이터는 유지됩니다.
저장 대상의 현재 제목·작성 시각·이미지 정보가 바뀌었으면 저장을 중단합니다.
전체 후보의 이미지 자동 저장은 아직 연결하지 않았습니다.

RUN_MONITOR_FINISH.cmd는 완료된 저장의 파일 재검증·종료 정리용입니다.
이번 시험에서는 실행할 필요가 없습니다. 미완료 이미지를 재저장하는 명령이 아닙니다.
안내 TXT는 image-monitor 폴더 안에 이 파일 하나만 들어 있습니다.
