# 실제 사이트 DOM 확인 기록

## 2026-11-15: 클라우드 탐색 연결 실패

대상 검색 URL:

`https://gall.dcinside.com/board/lists/?id=comic_new6&s_type=search_subject_memo&s_keyword=ai`

프로젝트의 잠금 의존성에 포함된 Playwright와 설치된 `/usr/bin/chromium`을 사용해,
새 임시 브라우저 컨텍스트에서 일반 페이지 탐색을 한 번 시도했습니다.

결과는 `Page.goto: net::ERR_TUNNEL_CONNECTION_FAILED`입니다. HTTP 응답과 사이트 DOM을
받기 전의 연결 실패이므로 HTTP 403/429, 사이트 접근 차단 또는 DOM 변경으로 판정하지 않습니다.
다른 프로토콜·프록시·접근 경로나 정책 변경으로 재시도하지 않았습니다.

따라서 이번 실행에서 확인된 실제 게시글·본문 선택자·작성자/날짜 속성·첨부 목록 구조나
본문/첨부 공통 식별자는 없습니다. 게시글과 첨부 링크를 열거나 직접 이미지 요청을 보내지
않았으며 응답 바이트 저장과 스크린샷도 사용하지 않았습니다.

## 구현과 검증의 구분

합성 HTML을 사용하는 파서 검사는 실제 사이트 호환성 검증과 구분해야 합니다.
특정 본문 선택자 또는 URL의 식별자 규칙을 실제 사이트에서 확인된 것으로 표시할 근거는
아직 없습니다. 본문이 없거나 중복되면 페이지 전체 이미지 수집으로 대체하지 않습니다.

실사이트 어댑터의 검증 범위를 넓히려면 정상 탐색이 가능한 환경에서 본문·첨부 DOM과
공통 식별자 근거를 별도로 확인해야 합니다. 이름·개수·순서만으로 원본 첨부명을 확정하지
않으며, 불확실한 대응은 원본명 `null`과 사유로 보존합니다.
