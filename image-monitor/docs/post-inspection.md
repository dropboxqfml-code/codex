# 본문 분석과 관찰 결과 대기열

`post-demo --db <새 DB 경로>`는 합성 게시글을 분석하고 SQLite에 저장한 뒤 새 연결로
다시 읽습니다. 브라우저나 이미지 저장 작업자를 시작하지 않습니다.
본문 순서와 첨부 순서가 다른 경우, 같은 이미지 반복, 본문에 없는 첨부 파일,
대응 근거가 없는 이미지를 포함합니다. 기존 DB는 덮어쓰지 않습니다.

## 본문과 파일명 처리

본문은 유일한 컨테이너에서만 읽습니다. 없는 본문이나 중복된 본문을 페이지 전체 이미지
수집으로 대체하지 않습니다. 댓글·광고·프로필·추천 영역과 동영상의 이미지, 본문 디시콘은
제외 사유를 보존합니다. 크기만으로 이미지를 제외하지 않습니다.
스크롤 후 `complete`, 자연 크기와 `decode()`를 확인하며 로딩 실패는 별도 미해결 이미지로
남깁니다. 미해결 이미지가 있으면 저장 대기열 등록을 허용하지 않습니다.

첨부 이름은 명시적인 DOM 참조나 검증된 공통 식별자가 유일하게 대응할 때만 확정합니다.
순서·개수·동일한 파일명은 대응 근거가 아닙니다. 중복·충돌·잘린 이름을 구분하며,
확정하지 못한 이름은 null로 기록합니다. 이름 대응 실패만으로 정상 본문 이미지를 버리지 않습니다.
실제 저장 창의 제안 이름과 최종 저장명은 아직 읽지 않았으므로 분석 단계에서는 null입니다.

같은 표시 URL은 한 작업으로 묶고 모든 본문 출현 순서를 관찰 결과에 남깁니다.
현재 작업 키는 정확한 표시 URL의 해시입니다. 이는 파일명 매칭 근거나 이미지 바이트 해시가
아니며, URL이 바뀌면 새 작업이 될 수 있습니다. 실제 사이트의 안정적인 파일 식별자 규칙은
실제 DOM 증거를 확인한 후 추가합니다.

## SQLite 연결

`enqueue_snapshot`은 등록 가능한 관찰 결과만 `persist_post_snapshot`에 전달합니다.
합성 검증 결과는 명시적인 합성 모드가 필요하며, 미검증 실사이트 결과는 등록하지 않습니다.
관찰 결과·게시글·감시 범위·이미지 작업·작업 대응 관계를 한 트랜잭션으로 저장합니다.
감시 범위는 호출자가 제공한 값이며 검색 목록에서 해당 글을 찾았다는 증거가 아닙니다.
목록 체크포인트를 갱신하지 않습니다.

기존 작업 ID·파일 슬롯·최초 날짜 경로와 재시도 상태는 유지합니다. 이전 관찰 결과는 수정하지
않으며 본문 순서가 바뀐 새 관찰 결과와 별도로 조회할 수 있습니다. 활성 작업의 URL은 바꾸지 않습니다.
파일 확정·metadata.json 생성·실제 저장 작업자는 이 연결에 포함되지 않습니다.

DB v2는 관찰 결과와 작업 대응 테이블을 추가합니다. 알려진 v1 스키마가 정확히 일치할 때만
단일 트랜잭션으로 추가 마이그레이션합니다. 알 수 없는 객체가 있는 DB는 수정하지 않고
거부합니다. 읽기 전용 v1 상태 조회는 계속 지원하며 마이그레이션하지 않습니다.

## 실제 사이트 구조 확인

클라우드 탐색은 연결 단계에서 실패했습니다. [관측 기록](live-dom-observations.md)에
실행 URL과 실패 경계를 기록했습니다. 일반·마이너·미니의 게시글 URL 형식은 검사하지만,
세 갤러리 종류의 실제 DOM 호환성을 검증했다고 주장하지 않습니다.

`site-inspect`는 설치된 브라우저의 별도 임시 컨텍스트로 설계안의 예제 게시글 한 개를
읽습니다. 화면을 띄우지 않고 다운로드를 거부하며, 첨부 링크 클릭·추가 첨부 요청·응답 바이트
추출·네이티브 저장을 실행하지 않습니다. HTTP 차단이나 오류에서 우회·반복 요청을 하지 않습니다.

현재 선택자 프로필은 실험용이며 결과는 항상 미검증 상태입니다. 본문·첨부의 구조,
후보·제외·로딩 오류·메타데이터를 검사 보고서에 남깁니다. 공유 TXT는 URL의 민감한 값과
로컬 보고서 경로를 정리합니다. 개인 브라우저 프로필·쿠키·인증 헤더는 수집하지 않습니다.

Windows 사용자의 작업은 ZIP 최상위 `WINDOWS_TEST_GUIDE.txt`에 정리합니다.
`RUN_SITE_INSPECTION.cmd`는 결과 TXT를 자동으로 엽니다. 이 검사의 성공은 관찰 결과가
생성됐다는 뜻이며 실사이트 어댑터 검증 완료나 이미지 저장 성공을 의미하지 않습니다.
