Image Duplicate Finder v0.1 - Windows x64

Python이나 uv를 설치할 필요가 없습니다.
다운로드한 Artifact ZIP을 완전히 압축 해제한 뒤
Image Duplicate Finder 폴더의 Image Duplicate Finder.exe를 실행하세요.
_internal 폴더를 포함한 전체 폴더가 필요합니다. exe만 복사하지 마세요.

폴더 선택 -> 검색 시작 -> 그룹 확인 -> 보관/보류/삭제 대상 선택.
최초 선택은 모두 보류입니다. 삭제할 그룹마다 보관 이미지를 하나 이상 지정하세요.
휴지통 이동 버튼을 누르고 전체 경로를 검토한 후 예를 눌러야 이동합니다.
복원은 Windows 휴지통에서 합니다. 검토 중 원본 폴더를 다른 앱에서 수정하지 마세요.
유사 그룹의 모든 이미지가 같은 것은 아닙니다. 자동 삭제는 하지 않습니다.

이 빌드는 코드 서명되지 않았습니다. SmartScreen 또는 백신 경고가 나올 수 있습니다.
공식 저장소의 예상 커밋/워크플로에서 받은 파일인지 확인하세요.
Defender를 끄거나 폴더 전체를 예외 처리하지 마세요. 탐지 시 실행을 중단하고
보호 기록을 확인한 뒤 배포자에게 빌드 번호와 탐지 이름을 알려주세요.
